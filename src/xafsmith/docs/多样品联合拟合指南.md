# 多样品联合拟合指南（一步一步）

> 适用：一组同一体系、同一吸收边的样品——时间序列、电位序列、温度序列、组成序列——想知道“结构参数怎样随序列变化”。
> 本指南把整个流程按顺序拆成 9 步，每一步写清：**在哪个页面、点什么、看什么、怎样算“可以进入下一步”**。
> 界面细节以《图形界面使用指南》第 11、12、16 节为准；模型文件写法见《数据标准》4.1。

---

## 0　先想清楚：你要回答什么问题

联合拟合不是“更高级的拟合”，它是**在一个明确假设下**的拟合：**名字相同的参数，在所有样品里是同一个数**。
先判断你的问题适合哪条路：

| 你的问题 | 合适的做法 | 说明 |
|---|---|---|
| 每个样品各自的结构是什么，彼此无关 | **逐个单独拟合**（同一模型批量运行） | 第 3 步就是它；不需要联合 |
| 一组样品里，某些量（ΔE0、某个键长）物理上应当相同，想更稳地定出**会变的量**（σ²、N）的趋势 | **联合拟合** | 本指南的主线 |
| 弱的外壳层在单独拟合里定不下来 | **联合拟合**（共享距离与 ΔE0） | 结论要连同“共享距离”的假设一起写 |
| 样品是几种已知物相的混合，想求比例 | **LCF**（线性组合） | 不是 EXAFS 壳层拟合 |
| 样品之间结构本来就完全不同 | 单独拟合 | 联合只是把几个单独拟合放在一起，没有好处 |

> 一句话：**联合拟合 = 单独拟合 + “哪些参数相同”的假设**。假设对，参数更少、误差更小、趋势更清楚；假设错，会把真实的差别抹平。
> 所以正确的顺序永远是：**先单独、后联合；联合之后再用 F 检验检查假设**。

## 1　准备：开拟合之前的检查清单

全部打勾再往下走。

| ☐ | 检查项 | 在哪里做 |
|---|---|---|
| ☐ | 所有样品是**同一吸收边、同一测量模式**（透射与荧光不要混在一组里比较振幅） | 数据登记（`meta.csv` 的 `edge_key`、`mode`） |
| ☐ | 每个样品都用参比箔校准过，ΔE 合理 | 校准与处理 → 校准结果 |
| ☐ | 多次扫描已检查后再合并，异常扫描已剔除并写了理由 | 载入与检查；`output/qc/qc_report.csv` |
| ☐ | **所有样品用同一套处理参数**：E0 定义、归一化范围、rbkg、k 权重、FT 的 k 范围与窗 | 校准与处理 → 处理参数（换样品不换定义） |
| ☐ | 每个样品都已算出 χ(k) | χ(k) 与 FT |
| ☐ | 已有 FEFF 路径（由 CIF 或手写结构计算） | FEFF 路径 |
| ☐ | **S0² 已由结构已知的标样确定**（下面第 2 步） | EXAFS 拟合 |
| ☐ | 已检查邻近吸收边，确定了 k 上限 | 吸收边查询；《XAFS处理规范》 |
| ☐ | （为了趋势图）`meta.csv` 里每个样品填了 **`seq`**（数字，如约化时间 50 / 100 / 200 / 300） | 用 Excel 或文本编辑器打开 `data/meta.csv`，在 `seq` 列填数字；同一样品的多次扫描（多行）填同一个数 |

`seq` 不填也能拟合；只是趋势图的横轴会退回到“测量时间”（距第一个样品的小时数），时间也没有就按样品顺序排。

## 2　第一步：用标样定 S0²

S0² 和配位数 N 完全相关（振幅 = N × S0²），**必须先在 N 已知的标样上定出来**，样品里再固定。

1. **EXAFS 拟合** 页，“拟合方式”选 **单个数据集**；数据选标样（如金属箔或结构已知的氧化物），FEFF 目录选该标样的计算。
2. 路径只勾第一壳层；N 填晶体结构的配位数（固定）；参数表里 `s02` 打勾 vary。
3. 拟合 → 看质量检查全绿、R 因子 < 0.02 左右。
4. 记下 S0² ± 误差（例如 0.82 ± 0.05），填到 **校准与处理 → 处理参数 → S0²**，或记在 `notes/`。

**进入下一步的条件**：S0² 在 0.7–1.0 之间且误差合理；否则先查标样本身（纳米晶、无序的标样 σ² 偏大，见《处理规范》经验 6）。

---

## 3　第二步：选一个代表样品，单独拟合，定下模型

在联合之前，**模型（用哪些路径、哪些壳层）要先在单个样品上定好**。

1. 选数据质量最好、最有代表性的样品（通常是 k 范围最长、噪声最低的那一个）。
2. **单个数据集** 模式下：
   - 拟合范围：kmin、kmax 按信噪比与邻近边定；k 权重勾 1、2、3；Rmin、Rmax 包住要拟合的峰。
   - 路径：先只用第一壳层；`s02` 取消 vary，value 填第 2 步的值。
   - 参数：通常 `e0`、`dr1`、`ss1` 自由；N 先固定为结构值，或用参数（如 `n1`）让它变（N 与 σ² 强相关，二者最好不要同时都放开太多壳层）。
3. 每加一个壳层：
   - 看 R 因子、χ²_ν 是否明显改善；
   - 到 **拟合历史 → F 检验 / 模型比较表** 比较加壳层前后，**p < 0.05 才算显著**；
   - 运行 **稳健性检查**，确认参数在改变 kmin / kmax / Rmax 时稳定。
4. 定下来后点 **保存结果**（模型进入 `models/`），起一个清楚的模型名，如 `TaO_2shell`。

**进入下一步的条件**：这个样品的拟合通过质量检查，每个壳层都通过 F 检验，变量数 ≤ N_idp/2。

---

## 4　第三步：同一模型，逐个样品单独拟合（为“共享什么”找依据）

这一步回答联合拟合最关键的问题：**哪些参数在样品之间真的相同？**

1. EXAFS 拟合页左栏顶部展开 **运行已保存的模型** → 选第 3 步的模型 → “样品”里多选全部样品 → **运行**。
   模型依次用于每个样品，结果都进入 **拟合历史**。
2. 在拟合历史里逐个查看，把每个参数的 **值 ± 误差** 抄成一张表（或保存后看 `output/fits/exafs_fits.csv`）：

| 参数 | 样品 A | 样品 B | 样品 C | 样品 D | 判断 |
|---|---|---|---|---|---|
| ΔE0 (eV) | 3.1 ± 0.9 | 2.7 ± 1.0 | 3.4 ± 0.8 | 2.9 ± 1.1 | 在误差内一致 → **可共享** |
| R₁ (Å) | 1.94 ± 0.01 | 1.94 ± 0.01 | 1.95 ± 0.01 | 1.94 ± 0.01 | 一致 → **可共享** |
| σ²₁ (Å²) | 0.0060 ± 0.0008 | 0.0071 ± 0.0009 | 0.0089 ± 0.0010 | 0.0098 ± 0.0011 | 有趋势 → **各自独立** |

（表中数字只是示意，不是任何真实样品的结果。）

3. **判断规则**：
   - 两个样品的差 > 约 2 倍合成误差（√(σ_A² + σ_B²)）→ **不能共享**；
   - 都在误差内一致 → **可以共享**（是假设，后面第 6 步再用 F 检验确认）；
   - 你要研究的那个量（例如时间序列里的 σ² 或 N）**不要共享**——共享了就只剩一个值，趋势被你自己抹掉了。

**进入下一步的条件**：写下“共享：…；独立：…”的清单，并把理由记进 `notes/`。

---

## 5　第四步：搭联合拟合（拟合页左栏，逐张卡片）

### 5.1　卡 1　数据与 FEFF

1. **拟合方式** 切到 **多个数据集联合**。
2. **数据** 多选全部样品（至少 2 个）。每个样品会得到一个**数据集 id**（取自文件名，如 `IrTa-100`），后面参数名的后缀就用它。
3. **FEFF 目录**：所有数据集共用一份选择（同一结构模型）。

### 5.2　卡 2　拟合范围

1. 这里是**所有数据集的共同范围**，一般直接用第 3 步定下的值。
2. 下方显示 **Σ N_idp**（各数据集 N_idp 之和）。**变量数上限 = Σ N_idp / 2**。
3. 某个样品噪声特别大、k 要截短：到卡 3 该数据集的标签页，在 **覆盖拟合范围** 里填它自己的 kmax（留空 = 用共同值）。

### 5.3　卡 3　路径（每个数据集一个标签页）

1. **先把第一个数据集的路径表设好**：勾选路径，填 N、s02、e0、deltar、sigma2 的参数名（与第 3 步的模型相同）。
2. 点 **把本页路径表复制到其他数据集**：所有数据集的路径表变得一模一样——此时**所有参数都是共享的**（名字都相同）。
3. 打开 **勾选同步到所有数据集**（可选）：之后在任一页勾选 / 取消一条路径，其他页同一路径跟着变；只同步勾选，不改表达式。
4. **把要独立的参数改成各自的名字**（第 4 步清单里“独立”的那些）：
   - **σ²**：点 **σ² 各数据集独立**，一键把共享的 σ² 名字改成 `ss1_<数据集 id>`（每个数据集一个），参数表自动建好，初值、vary、上下限照抄原参数。再点一次不会重复加后缀。被别的参数表达式引用的 σ² 名字不会改（否则那个表达式就断了），需要时手动改。
   - **N、ΔR、ΔE0**：没有一键按钮，在各数据集页手动改名。命名建议见下表。
5. 用了 **σ² 温度模型**（Debye / Einstein，多温度数据）时，σ² 由一个共享的 θ 决定，“σ² 各数据集独立”按钮会变灰——两者用意相反，二选一。

**命名约定（推荐）**

| 意图 | 写法 | 例子 |
|---|---|---|
| 全组共享 | 同一个名字 | 所有数据集都写 `e0`、`dr1` |
| 每个样品独立 | 名字 + `_` + 数据集 id | `ss1_IrTa_50`、`ss1_IrTa_100`… |
| 部分样品共享 | 自己定组名 | 前两个写 `dr1_early`，后两个写 `dr1_late` |
| 由别的参数决定 | 表达式 | `ss2` 写 `ss1_IrTa_50*1.5` |

### 5.4　卡 4　参数（一张共享参数表）

1. 表里的名字是所有数据集已勾选路径用到的参数的并集。
2. `s02`：**取消 vary**，value 填第 2 步的标样值（或用软约束：value = 标样值，sigma = 标样误差）。
3. 其余参数给合理的初值与上下限：ΔE0 −15 ~ 15 eV，ΔR −0.5 ~ 0.5 Å，σ² 0 ~ 0.05 Å²。
4. 看页面上的 **变量数**：超过 Σ N_idp/2 会变成橙色——减少独立参数，或缩小模型。

**变量数怎么算（示意）**：4 个数据集，每个 kmin 3、kmax 11、Rmin 1、Rmax 2 → 每个 N_idp ≈ 2×8×1/π ≈ 5.1，Σ N_idp ≈ 20，上限 ≈ 10。
共享 `e0`、`dr1`（2 个）+ 每个样品一个 σ²（4 个）= 6 个变量 → 可以。若再让 N 每个样品独立（+4 = 10）就到了上限，可靠性明显下降。

### 5.5　共享什么、不共享什么（常用起点）

| 参数 | 通常 | 什么时候要分开 |
|---|---|---|
| S0² | **固定**为标样值（全组一个） | 测量模式不同（荧光有自吸收）时不能和透射共用 |
| ΔE0 | **共享**（同一边、同一 FEFF、同一 E0 定义） | 单独拟合里差别 > 2σ；或吸收原子的化学环境变化很大 |
| ΔR（第一壳层） | 结构不变时**共享** | 你要研究键长变化时独立；注意 ΔR 与 ΔE0 强相关，键长结论要谨慎 |
| σ² | **各自独立**（时间 / 电位序列里通常就是要看的量） | 多温度数据可用 Debye / Einstein 模型，共享一个 θ |
| N | 先**固定**为结构值 | 研究配位数变化时独立；N 与 σ² 强相关，不要同时放开太多 |
| 弱外壳层的距离 | **共享**（这是联合拟合能定出弱壳层的原因） | 结论必须写明“在共享距离的假设下” |

## 6　第五步：运行并看结果

1. 左栏底部填 **模型名**（如 `TaO_joint_ssfree`），点 **拟合**（Ctrl+Enter）。
2. **右栏顶部 = 联合指标**：联合 R 因子、χ²_ν、Σ N_idp、变量数、数据集数。
3. **查看数据集** 下拉：切到每个数据集，看它自己的 k / R 拟合图、R 因子、N_idp、**χ² 占比**。
   - 某个数据集 χ² 占比远大于其他、或出现“每个拟合点的残差 … 是 … 的 N 倍（失配）”警告：**它的失配会放大所有参数的误差**。先查这个数据集——范围、噪声、模型是否不适合它。
4. 标签页：
   - **参数**：所有参数的值 ± 误差（联合的）。
   - **路径**：当前数据集每条路径的 N、R、σ²、ΔE0。
   - **质量检查**、**诊断**：当前数据集的（逐个数据集都切过去看一遍）。
   - **趋势**：见第 8 步。
   - 多数据集**暂不支持稳健性检查**：对关键样品，用第 4 步的单独拟合做稳健性检查。
5. 想用这次的结果当下次的初值：**采纳拟合值到参数**。
6. 满意后 **保存结果**：写结果表（每条路径一行，带 `dataset` 列）、模型 JSON、报告、每个数据集一张拟合图，以及趋势表 `output/fits/<模型>_trend.csv`。

**进入下一步的条件**：每个数据集的拟合图都合理、没有严重失配警告；联合结果落在第 4 步单独拟合的误差范围内（不落在里面，说明共享假设可能不对）。

---

## 7　第六步：用 F 检验检查假设（最容易漏的一步）

联合拟合的结论依赖“共享什么”。**每个关键假设都要做一次 F 检验**。做法都是：拟合两个**嵌套**模型（小模型是大模型的特例），都留在拟合历史里，然后比较。

**怎样得到两个模型**：拟合并保存第一个 → 在左栏改动（改参数名 / 勾选）→ 换一个**新模型名** → 再拟合 → 两个结果都在 **拟合历史** 里。

| 要回答的问题 | 小模型 | 大模型 | 结论 |
|---|---|---|---|
| ① 这个壳层在整个系列里存在吗？ | 所有数据集**都不勾**该路径 | 所有数据集**都勾** | p < 0.05 才能说“观察到” |
| ② 某个样品自己需要这个壳层吗？ | 只在这个数据集去掉该路径 | 全部都有 | 在共享距离的假设下成立；结论要写明假设 |
| ③ σ²（或 N、ΔR）在样品之间真的不同吗？ | 所有数据集**共用一个** `ss1` | 每个数据集**各自一个**（σ² 各数据集独立） | **p > 0.05 时，σ² 的“趋势”不能由拟合支撑** |

**比较**：拟合历史 → **模型比较表**，勾选这两个拟合 → **比较**（或上方 F 检验：选简单模型和复杂模型 → 比较）。
注意：两个模型必须用**相同的数据和拟合范围**、软约束相同；软件发现不同会在 note 列或结果上方提示。**软件不检查嵌套关系，需要你保证**。

---

## 8　第七步：看趋势

结果区 **趋势** 标签页（联合拟合 ≥ 2 个数据集时出现）：

1. **面板**：N、R、σ²、ΔE0、边位置 E0，缺省显示 N、R、σ²、边位置。
2. **路径**：选要画的路径（缺省全部已用路径）。
3. **横轴**：`meta.csv` 的 `seq`（全部样品都填了才用）→ 否则测量时间（小时）→ 否则样品顺序。页面会提示哪个样品缺 `seq`。**横轴标题**可以改（如 “Reduction time (s)”）。
4. 下方是趋势表；**保存趋势表** 写 `output/fits/<模型>_trend.csv`。

**怎么读这张图（重要）**

- 误差棒是 **1σ**（协方差矩阵按 √χ²_ν 缩放，Larch）。
- **N 固定**（N 栏空、写数字，或只由固定参数决定）的路径**没有误差棒**——不是误差为零，而是它没有被拟合。
- **共享参数**在所有样品上是**同一个拟合值**，画出来是一条水平线。**水平线不代表“没有变化”**，只代表你假设它不变；页面和图注会注明哪些是共享的。
- **边位置 E0** 是归一化得到的**实测值**，不是拟合结果，可以作为与模型无关的旁证。
- 趋势是否显著，看第 7 步问题 ③ 的 F 检验，不是看点是不是“看起来在升高”。

---

## 9　第八步：导出图

1. **图片导出** 页，顶部选 **趋势图**。
2. 选联合拟合（缺省最近一个）、面板、路径、横轴标题；尺寸（单栏 85 mm / 1.5 栏 / 双栏 / 汇报 16:9）、配色、格式（TIFF / PNG / SVG / PDF）、文件名。
3. **保存到 output/figs/journal/**：图与英文图注（.txt）一起保存；图注写明模型、数据集数、吸收边、横轴来源、误差含义、共享参数与固定 N。
4. **导出 Origin 工程 (.opju)**：每条曲线写成 X / Y / yErr 三列，线 + 实心圆点 + 误差棒。（误差棒线宽与端帽宽目前用 Origin 缺省，尚未按统一样式设置。）
5. 每个数据集的 k / R 拟合图：图片导出 → χ(k) 或 |χ(R)| → 勾 **叠加拟合曲线**；或保存结果时自动生成的 `output/figs/<模型>_<数据集>_fit.png`。

---

## 10　第九步：记录与写结论

1. 在 `notes/` 写一条记录：模型名、共享 / 独立清单与理由、S0² 来源、F 检验结果（三个问题各自的 p）、趋势表文件名。
2. 写结论时分三类：
   - **实测**：边位置 E0 的移动、R 空间峰高的变化（与模型无关）。
   - **拟合结果**：“在共享 ΔE0 与 R₁ 的假设下，σ²₁ 从 … 增加到 …（F 检验 p = …）”。
   - **推测**：结构上的解释（无序增加、局部重构等）需要其他表征支持。
3. **不能说的**：没通过 F 检验的壳层“被观察到”；没通过问题 ③ 的参数“有趋势”；共享参数“没有变化”。

## 11　常见问题与排错

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 所有样品的 σ² 完全一样 | σ² 名字相同 → 被共享 | 点 **σ² 各数据集独立**，或手动改名 |
| 变量数变橙色 | 独立参数太多 | 把差别不显著的参数改回共享；减少壳层；放宽 k 范围（提高 N_idp） |
| 某个数据集 χ² 占比特别大 / 失配警告 | 这个样品不适合当前模型或范围 | 单独检查它：k 范围、噪声、是否需要不同的路径 |
| 联合结果落在单独拟合误差之外 | 共享假设不对 | 把那个参数改成独立，做 F 检验 |
| ΔE0 超过 ±10 eV | E0 定义或模型有问题 | 检查处理参数里的 E0 定义是否全组一致 |
| 趋势图横轴是“Measurement time (h)” | 有样品没填 `seq` | 在 `meta.csv` 补 `seq`（页面提示缺哪个） |
| 趋势图横轴是“Dataset” | `seq` 和 `time` 都不全 | 同上 |
| 某条路径没有误差棒 | N 固定 | 正常；要拟合 N 就把 N 写成参数名 |
| 同一个样品放进了两个数据集 | 同一数据计入两次 → 误差被低估 | 去掉一个（软件会警告） |
| 点“σ² 各数据集独立”没反应 | 没有在 ≥ 2 个数据集中共用的 σ² 名字，或用了 σ² 温度模型 | 看提示；温度模型和独立 σ² 二选一 |
| 稳健性检查是灰的 | 多数据集暂不支持 | 对关键样品做单独拟合的稳健性检查 |
