# XAFSmith 图形界面使用指南（只用鼠标）

> ⚠️ **免责声明**：本软件按“现状”提供，作者不对使用本软件得到的结果负责。请自行核验结果，**建议将关键结果与 Athena / Artemis 的结果对比**。
> 📖 **引用**：论文中使用本软件，请引用本仓库：Eggy & Claude. XAFSmith, https://github.com/Wiolic/XAFSmith ；同时引用 Larch 与 FEFF（窗口底部“免责声明与引用”可一键复制）。

本指南面向不写程序、不输入命令的用户：懂 XAFS 原理，按下面顺序点鼠标，就能完成
**登记数据 → 校准与处理 → FEFF → EXAFS 拟合 → LCF / XANES → 汇总、期刊图、SI** 的全流程。
不熟悉 XAFS 原理的，先读“使用指南”页里的 **XAFS 基础讲义**；第一次做拟合，读 **零基础拟合教程**。

## 一、安装（只需一次）

1. 安装 Python 3.11 或 3.12：打开 https://www.python.org/downloads/windows/ ，下载安装包，
   安装时**勾选 “Add python.exe to PATH”**，然后一路“下一步”。
2. 在 GitHub 页面 https://github.com/Wiolic/XAFSmith 点绿色的 **Code → Download ZIP**，解压到任意位置。
3. 双击解压文件夹里的 **`installer.py`**，弹出 **XAFSmith 安装向导**（中英文）：
   - **安装位置**：默认 `C:\Users\<你>\AppData\Local\Programs\XAFSmith`，可点“浏览…”改到其他磁盘；
   - **创建桌面快捷方式**、**创建开始菜单快捷方式（含卸载）**、**安装完成后立即启动**：按需勾选；
   - 勾选 **我已阅读并同意**，点 **安装**，等待进度条走完（需要联网，5–15 分钟）。
   - 如果双击 `installer.py` 没有反应或用记事本打开了：右键 → 打开方式 → Python；或重装 Python 时确认勾选了 “Add python.exe to PATH” 与 “py launcher”。
4. 安装完成后，解压的那个文件夹可以删除。

以后每次使用：**双击桌面（或开始菜单）上的 XAFSmith**。XAFSmith 是原生桌面程序，几秒内打开，不需要浏览器；关闭窗口即退出。
卸载：开始菜单 → XAFSmith → **卸载 XAFSmith**（只删除软件，不会删除你的项目和数据）。

## 二、界面

- **左侧栏**：
  - 顶部是软件名与署名（Developed by Eggy & Claude Opus 5.5）和 **打开 / 新建项目** 按钮；
  - 中间是按使用流程分组的页面（组间留空）：
    1. **项目、数据登记、校准与处理**——准备；
    2. **载入谱、质量检查、能量校准、归一化、χ(k) 与 FT、小波变换**——看数据；
    3. **FEFF 路径、EXAFS 拟合、拟合历史、LCF、XANES 定量**——分析；
    4. **汇总报告、期刊出图、SI 方法**——导出；
    5. **样品设计、AI 助手、使用指南**——工具与帮助。
  - 底部是当前项目（鼠标悬停显示完整路径）和 **中文 / English** 切换（选择会被记住）。有新版本时，项目上方出现提示。
- **窗口底部**始终显示一行免责声明；点 **免责声明与引用** 查看全文并复制引用格式。
- **图**：右上角四个按钮依次是平移、框选放大、复位、保存图片；鼠标所在处的坐标显示在左上角。
- **表格**：双击单元格修改；勾选框直接点；下拉列可选值。
- **多选框**：点开后可搜索、勾选，“全选 / 清空”批量操作。
- **耗时的计算**（处理全部样品、FEFF、拟合、稳健性检查、汇总）在后台运行，窗口不会卡住；窗口顶部出现细进度条，左下角显示进度。
- 浅色 / 深色跟随 Windows 系统设置。

## 三、建立项目（每个课题一次）

一个“项目”就是一个文件夹，里面按固定格式存放原始数据、结构文件和全部结果。

1. 点左上角 **打开 / 新建项目**，在“打开或新建项目”中点 **浏览…**，选一个空文件夹（或新建一个），点 **新建项目**。
2. 以后再打开：在“最近的项目”里**双击**它；或双击项目文件夹里的 **打开图形界面.bat**。

项目文件夹里会出现：`data/raw`（原始数据）、`structures`（结构文件）、`models`（拟合模型）、`notes`（记录）、`output`（全部结果）。

打开项目后，**项目** 页显示 **流程** 六步（登记数据、校准与处理、查看与检查谱、FEFF 路径、拟合、导出）：
已完成的打 ✓，下一步用蓝框标出，点 **打开 →** 直接进入对应页面。下方是 **输出**（各结果文件夹的文件数，可直接打开）和 **本次会话**（已载入的谱、拟合数；**保存会话参数**）。

## 四、放入原始数据并登记（数据登记）

1. 每次测量（一个机时）建一个“批次”：在 **批次文件夹** 填一个名字（例如 `2026-11-05_Ta`），
   点 **选择文件并复制到批次…**，选中这次的全部原始文件（文件被复制到 `data/raw/<批次>/`，原文件不动，同名文件不覆盖）。
   **同一批次必须包含这次测的单质参比**（金属箔或粉，文件名中带 foil / powder / metal）。
   也可以直接用 Windows 资源管理器把文件复制到项目的 `data\raw\<批次>\` 文件夹。
2. 点 **扫描 data/raw，登记新文件**。下方 `data/meta.csv` 表格每个原始文件一行。
3. 检查并修改登记表（双击单元格），然后点 **保存 meta.csv**：
   - **sample**：样品名。同名的多行 = 同一样品的多次扫描，会被合并；不想合并就改成不同名字。
   - **role**：参比箔选 `reference`，标样选 `standard`，样品选 `sample`。
   - **use**：不想用的扫描选 `0`，并在 **note** 写原因。
   - **ref_file**：这条谱用哪个参比校准（默认同批次参比）。为空的谱不能处理。
4. 页面下方 **按数据标准检查 → 运行检查**。出现“错误”就按提示改，直到 0 个错误。

## 五、校准与处理（校准与处理）

**处理参数**（右上角选吸收边；每个吸收边一套参数，同一边的所有样品共用）：
- **样品中的全部元素**：用于检查干扰吸收边和可用的 k 上限（例如 `Ta, Ir, O, K`）。
- **归一化**（pre1、pre2、norm1、norm2、nnorm、E0 平滑）、**背景扣除与傅里叶变换**（rbkg、k 权重、kmin、kmax、dk、窗）。
- **S0²**（值、误差、来源）：先空着；在标样上拟合得到后再填回这里（见第八节）。

点 **保存参数**，然后在 **批量运行** 中依次点：
1. **① 质量检查**：看毛刺（glitch_E）、I0 掉束、边跳、k_snr3（信噪比可用到的 k）、荧光自吸收风险。
2. **② 按参比校准**：每个参比给出一个 ΔE，同批次所有谱加同一个 ΔE。
3. **③ 处理全部样品**：校准 → 归一化 → 合并 → χ(k) → 傅里叶变换。结果在 `output/processed` 和 `output/figs`。

## 六、查看与检查谱

**载入谱**：在 **样品** 中勾选（或选 **整条吸收边**），点 **载入**；参比会一起载入。载入的谱已校准、归一化、合并，χ(k) 与 FT 已算。
下方表格列出已载入的谱及其校准状态；可查看原始 μ(E) 与 I0 / I1 / If 通道，或把谱移出会话（不删除文件）。
“直接读入文件”（BSRF 文本 / Athena .prj / 通用列文本）用于不在 meta.csv 中的文件：必须选同批次参比。

**质量检查**：对已载入的谱运行检查（结果写入 `output/qc/qc_report.csv`）。

**去毛刺**（质量检查 页下方）：选样品（可多选，同一区间用于全部所选），看 μ(E) 与 I0 图（灰色虚线为 QC 标出的疑似毛刺，红色为已删除区间，可框选放大）。
判断标准：只占 1–3 个点、远窄于 EXAFS 振荡、常在多个样品同一能量出现、I0 同时有凹陷。
填 **删除区间**（校准后能量，如 `9984.5-9990; 10321-10327.5`）和 **理由**（必填），点 **保存并重新载入**：区间写进 `xafsmith.json` 的 `deglitch`，原始文件不动，命令行处理同样生效。
**清除所选样品的去毛刺** 可撤销。真实结构不要删。

**能量校准**：参比校准值表、已载入谱的校准状态（与参比的时间差）；可 **换参比 / 补校准**；展开“测定 / 重新测定参比 ΔE”可改表值或导数平滑后重新测定。

**归一化**：上方是全组共用的归一化参数（改动立即重算），下面四个标签：μ(E) 与边前 / 边后线、归一化叠加（可选 flattened、横轴 E − E0）、导数、合并扫描（自动剔除偏离中位谱的扫描，可手动剔除）。
页面下方 **导出**：所选谱的归一化数据（`output/gui/norm/`）和 **Athena 工程 .prj**（见第十三节）。

**χ(k) 与 FT**：rbkg、k 范围、窗、k 权重（改动立即重算）；标签：χ(k)（含窗函数）、|χ(R)| / Re（R 轴未相移校正）、背景 μ0(E)、**k 范围检查**（干扰边 → 可用 k 上限、ΔR 分辨率与 N_idp）。可导出 χ(k) 与 χ(R)。

**小波变换**：
1. 选谱、母小波（Morlet / Cauchy）、k 权重、η、σ 与显示 Rmax。页面实时显示当前分辨率（某个 R 处 k 方向与 R 方向的模糊宽度）。
2. **各 R 区间的极大值**：填 R 区间（如 `1.0-2.0; 2.0-3.6`），表格给出每个区间 |W| 极大值所在的 k 与 R，图上用白色“+”标出；比较不同样品同一区间的 k 位置，可判断该壳层中轻 / 重散射体的贡献。
3. **导出数据与图**：写入 `output/gui/wavelet/`：|W| 矩阵 `.csv`（第一行 k、第一列 R）、极大值表 `_maxima.csv`、600 dpi 的 `.png` 与 `.svg`、参数 `.params.json`。
4. 页面下方 **参数怎么调、适合分析什么**：
   - 本软件的 Morlet 定义中，图形只由乘积 ησ 决定：k 方向模糊约 ησ/(2R)，R 方向约 R/(ησ)，此消彼长；
   - k 权重越高，极大值越向高 k 移、重散射体越突出；
   - 适合区分第二壳层是 M–M 还是 M–O，判断单原子与团簇；不适合给出配位数和键长。

## 七、FEFF 路径（FEFF 路径）

1. 结构来源选 **structures/ 文件夹**（点 **添加结构文件…** 复制 CIF / POSCAR 进来），或选 **内置结构**；**内置结构导出为 CIF** 可把内置结构存到 `structures/builtin/`。
2. 选吸收原子（默认最重的元素）、吸收边、不等价位点、RMAX、NLEG。
3. **FEFF 版本**：
   - **FEFF6L**（默认）：非自洽势，几秒出结果。
   - **FEFF8L**：自洽势（SCF），约 1–3 分钟。可设 **SCF 自洽半径**（一般 4–5 Å，包含 2–3 个壳层）和 **交换势**（默认 0 = Hedin-Lundqvist）。输出目录自动加 `_feff8`，不会覆盖 FEFF6 的结果。
   - 两者路径编号一般相同，模型里把路径目录换掉即可对比；但 **ΔE0 的零点不同**（Ta L3 的 KTaO3：FEFF6 约 6.6 eV，FEFF8 约 1.2 eV），固定 e0 的模型换版本后要重新确定 e0。
4. 点 **运行 FEFF**。下方 **已有计算** 列出全部路径（距离、简并度、振幅比）；FEFF8 计算同时显示 SCF 半径、交换势和费米能；可展开查看 feff.inp。

## 八、EXAFS 拟合（EXAFS 拟合）

页面顶部 **注意事项与“拟合得好”的标准**（第一次拟合前默认展开）：拟合前要做什么、R 因子 / 残差与噪声之比 / 参数合理范围 / 误差 / 边界 / 相关性 / 稳健性各自怎样算好。

1. **数据与 FEFF**：选样品（需先载入并算出 χ(k)）和 FEFF 目录（可多选：多物相 / 多位点）。
2. **拟合范围**：kmin、kmax、dk、窗、k 权重（建议 1、2、3 同时）、Rmin、Rmax、拟合空间。页面显示 N_idp 与变量数上限。
3. **路径**：勾选要用的路径；`N` 列写数字 = 固定配位数，写参数名（如 `n1`）= 让配位数变化；
   `deltar`、`sigma2` 列写参数名，同名即共用；都可以写表达式（如 `ss1*1.5`）。
4. **参数**：`vary` 打勾 = 自由变化，不勾 = 固定为 `value`；`expr` 填了内容 = 约束。页面实时显示变量数，超过 N_idp/2 变成橙色。
5. 填模型名，点 **拟合**。结果卡片显示 R 因子、χ²_ν、N_idp、变量数、参数与误差、每条路径的 N、R、σ²、ΔE0，以及 k 空间与 R 空间（|χ(R)| 与 Re χ(R)，灰色为拟合窗口）的拟合图。
6. 满意后点 **保存结果**：模型存入 `models/`，结果进入汇总与 SI。

**拟合质量检查**（结果卡片下方，自动生成）：逐条打 ✓ / ⚠：
- R 因子（< 0.02 很好，0.02–0.05 第一壳层可接受）；
- 变量数 ≤ N_idp/2；残差 / 噪声（≤ 约 2 为已到数据极限）；
- 每个变量的误差是否可估、是否大于数值本身；参数是否停在上下限；
- |ΔE0| ≤ 10 eV；σ² 为正且不过大；|ΔR| ≤ 0.2 Å；
- 是否有 |r| > 0.9 的强相关参数对；是否只用了单一 k 权重；是否已运行稳健性检查。

这些是必要条件：新增的壳层还要通过 F 检验（拟合历史）并在稳健性检查中稳定。

**拟合诊断**：展开 **拟合诊断：残差在哪里、为什么对不上**。显示：
- 窗口内残差、白噪声估计及二者之比（≈ 1–2 已到数据极限，≫ 2 为系统误差）；
- k 空间残差图（紫色虚线标出检测到的尖峰，多为残留毛刺）；
- k 分段与 R 分段失配表，以及按残差位置给出的建议。

完整方法见“使用指南 → 拟合质量提升教程”。

**稳健性检查**：展开 **稳健性检查：改变拟合条件重复拟合** → **运行稳健性检查**。
软件依次改变 kmin ±0.5、kmax ±1、Rmax ±0.2 Å，以及单独用 k¹/k²/k³ 各拟合一次，列出每个变量的变化范围；变化超过其统计误差的标为 **不稳**。

**同一模型用于一组样品**（时间序列、电位序列）：本页顶部展开 **运行已保存的模型**，选模型，在“样品”中多选，点 **运行**：
模型依次用于每个样品（模型名自动换成该样品），结果都进入 **拟合历史**。先用结构已知的标样检验模型，再用到样品上。

**标样定 S0²**：在结构已知的标样上让 S0² 自由拟合，得到的值填回“校准与处理 → 处理参数 → S0²”。样品拟合时把 S0² 的 vary 取消勾选，value 填这个值。

## 九、比较模型（拟合历史）

上方列出本次会话的全部拟合；**全部保存到 output/fits/** 一次保存。
**F 检验（Hamilton）**：选“简单模型”和“复杂模型”（后者多了壳层或参数），点 **比较**：**p < 0.05** 才说明多出来的壳层显著。
下方 **查看拟合** 可切换到任一拟合，显示与 EXAFS 拟合页相同的结果、质量检查、诊断与稳健性检查。

## 十、线性组合（LCF）

选样品和端点标样（必须是实测标样）、空间（归一化 μ / 导数 / χ(k)）、范围、约束（权重和 = 1、0 ≤ w ≤ 1、能量平移），点 **LCF**。
同时给出“只用单一标样”的拟合与（3 个以上标样时）全部组合的比较。结果追加到 `output/lcf/lcf_results.csv`。使用非实测端点时必须在“备注”中注明为假设。

## 十一、XANES 定量（XANES 定量）

先载入样品和标样。
- **边位置与白线**：选谱，得到 E0（导数最大值）、E_half（归一化 μ = 0.5 处）、白线峰位与峰高、白线面积（E0 至 E0+30 eV 内超过 1 的面积，区间可改）。点 **保存** 写入 `output/xanes/xanes_features.csv`。
- **价态标定**：选**已知价态的实测标样**，在表格里填价态，选边位置定义（推荐 E_half），软件拟合“边位置 = 斜率 × 价态 + 截距”；再选样品得到价态估算和误差。只有配体相同、结构相近的标样才能这样用；超出标样价态范围的结果标为“外推”。
- **边前峰拟合**：选谱、拟合区间（相对 E0）、峰数、主边基线（erf / arctan），点 **拟合边前峰**。看分量图判断基线是否合理；峰贴区间边界或面积 ≈ 0 时会提示。

## 十二、期刊出图（期刊出图）

选图类型（归一化 XANES、XANES 导数、kⁿχ(k)、|χ(R)|、拟合）、谱、错开量、尺寸（单栏 85 mm / 1.5 栏 / 双栏 178 mm / 汇报 16:9）、格式（TIFF、PNG、SVG、PDF），预览按实际尺寸显示；点 **保存到 output/figs/journal/**。
图用 Arial 字体、色盲友好配色，TIFF/PNG 为 600 dpi；同名 .txt 是英文图注（含处理参数）。

## 十三、导出到 Athena（归一化 页底部）

在 **导出** 中填文件名，点 **导出 .prj**，文件在 `output/gui/athena/`。
.prj 中是已校准的能量和 μ(E)，并带上本软件用的 E0、归一化范围、rbkg、k 范围和窗函数，用 Athena 打开就能和本软件的结果逐项对比。

## 十四、汇总报告与“方法”段落（汇总报告）

点 **生成汇总**（本次会话有未保存的拟合时，可先点 **先保存本次会话的全部拟合**），得到：
- **汇总.xlsx**：样品、校准、质量检查、处理结果、拟合概要（每个模型一行）、EXAFS 每条路径参数、LCF、处理参数；
- **汇总报告.html**：上述表格 + 全部图（**在浏览器中打开报告**，可“打印 → 另存为 PDF”）。

**打开汇总文件夹** 或 **另存 汇总.xlsx…**。下方 **预览** 可逐表查看。

页面下方 **“方法”段落**：先填光源、线站、单色器、探测方式（点 **保存仪器信息**），可选只写某些样品，点 **生成方法段落**，得到中英文两段（各带 **复制** 按钮），同时保存为 `output/reports/方法段落.md`。
段落只写项目文件中有记录的事实（校准参比与 ΔE、归一化/背景/FT 参数、拟合范围、N_idp、S0² 来源、软件版本），没填的仪器信息用【方括号】占位。**这是草稿，投稿前逐句核对。**

## 十五、SI 拟合方法文本（SI 方法）

1. 在 EXAFS 拟合中拟合并点 **保存结果**（只有保存过的拟合会出现在这里）。
2. 选择要写进补充材料的拟合（可多选；同一模型用于多个样品时合并成一段），选 English 或 中文。
3. **方法** 标签：点 **复制**，直接粘贴到 SI。文字只写项目中有记录的事实：数据与吸收边、FEFF 版本与结构、k / R 范围、k 权重、窗函数、独立点数与变量数、S0² 及其来源、ΔE0 处理、每条路径的约束、误差估计方式。
4. **表 S[n]** 标签：每条路径的 N、R、σ²、ΔE0（括号内为最后一位的误差），以及 R 因子、χ²_ν、N_idp / 变量数。点 **复制（粘贴到 Excel / Word）**：粘贴到 Excel 直接成表；在 Word 中粘贴后用“文本转换成表格”。也可 **另存 .md / .csv**。
5. 文中 “Table S[n]” 的编号、结构文件来源等请按论文实际情况修改。

## 十六、样品设计

由化学式、目标元素与吸收边、压片面积、稀释剂与目标总 μt，推荐样品质量（边后总 μt、边跳 Δμt）；填了样品质量则计算实际 μt。
**干扰吸收边**：填体系中全部元素，列出扫描范围内会出现的其他吸收边。数据来自 xraydb（Elam 表）。

## 十七、接入 AI 助手（AI 助手）

XAFSmith 项目可以直接交给 AI 助手（Claude Code、Codex、Cursor 等）处理、拟合和导出。

1. **AI 助手** 页 → 点 **写入 / 更新 AI 说明文件**。项目文件夹里会写入 `AGENTS.md`（含本机 xafsmith 命令的完整路径、工作流程、拟合与导出命令、规则）和 `CLAUDE.md`。你自己写在这两个文件里的内容会保留。
2. 在项目文件夹里打开 AI 助手（页面上有各工具的打开方式），用自己的话说要做什么（页面上有可复制的示例）。
3. AI 的结果都在项目里：模型在 `models/`（EXAFS 拟合页顶部可一键重跑并查看质量检查与诊断），数值在 `output/`，记录在 `notes/`，图在 `output/figs/journal/`，报告在 `output/reports/`。

软件更新后（命令路径可能变化）再点一次“写入 / 更新”即可。

## 判读提醒

- R 空间峰位**未相移校正**，比真实键长短约 0.3–0.5 Å，键长看拟合结果。
- 变量数 ≤ N_idp/2；|ΔE0| > 10 eV、σ² ≤ 0、参数卡在边界时，拟合质量检查会标出，要检查模型。
- 加壳层要做 F 检验；p ≥ 0.05 的壳层不能说“观察到”。
- 荧光与透射的白线 / 振幅不能直接比较（自吸收、样品厚度）。
- 报告结论时区分：**实测**（谱上可见）/ **拟合**（依赖模型）/ **推测**（需其他实验）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击图标没有窗口 | 再双击一次 `installer.py` 修复安装（不会影响项目和数据） |
| 提示“还没有安装” | 再双击一次 `installer.py` |
| 登记表 ref_file 为空 | 这个批次没有参比：把同批测的金属箔文件放进该批次后重新扫描 |
| 某条谱有毛刺 | 质量检查 页下方“去毛刺”；或在登记表把这条扫描 use 设为 0（写原因） |
| 页面中出现红色错误提示 | 把提示文字发给维护者；其他页面不受影响，可继续使用 |
| 想重新开始 | 删除项目的 `output` 文件夹，在“校准与处理”中重新运行 ① ② ③，结果会全部重新生成；原始数据不受影响 |
