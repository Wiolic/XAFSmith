# XAFSmith 图形界面使用指南（只用鼠标）

> ⚠️ **免责声明**：本软件按“现状”提供，作者不对使用本软件得到的结果负责。请自行核验结果，**建议将关键结果与 Athena / Artemis 的结果对比**。
> 📖 **引用**：论文中使用本软件，请引用本仓库：Eggy & Claude. XAFSmith, https://github.com/Wiolic/XAFSmith ；同时引用 Larch 与 FEFF（软件内“⓪ 项目”页的“引用格式”可复制）。

本指南面向不写程序、不输入命令的用户：只要懂 XAFS 原理，按下面顺序点鼠标就能完成
**登记数据 → 校准 → 处理 → FEFF → EXAFS 拟合 → LCF → 汇总报告** 的全流程。
第一次做拟合、想知道每一步原理的，先读本页旁边的 **零基础拟合教程**。

---

## 一、安装（只需一次）

1. 安装 Python 3.11 或 3.12：打开 https://www.python.org/downloads/windows/ ，下载安装包，
   安装时**勾选 “Add python.exe to PATH”**，然后一路“下一步”。
2. 在 GitHub 页面 https://github.com/Wiolic/XAFSmith 点绿色的 **Code → Download ZIP**，解压到任意位置。
3. 双击解压文件夹里的 **`installer.py`**，弹出 **XAFSmith 安装向导**（中英文）：
   - **安装位置**：默认 `C:\Users\<你>\AppData\Local\Programs\XAFSmith`，可点“浏览…”改到其他磁盘；
   - **创建桌面快捷方式**、**创建开始菜单快捷方式（含卸载）**、**安装完成后立即启动**：按需勾选；
   - 勾选 **我已阅读并同意**，点 **安装**，等待进度条走完（需要联网，5–15 分钟）。
   - 如果双击 `installer.py` 没有反应或用记事本打开了：右键 → 打开方式 → Python；或者重装 Python 时确认勾选了 “Add python.exe to PATH” 与 “py launcher”。
4. 安装完成后，解压的那个文件夹可以删除。

以后每次使用：**双击桌面（或开始菜单）上的 XAFSmith**，软件在**独立窗口**中打开（不需要浏览器）；关闭窗口即退出。
卸载：开始菜单 → XAFSmith → **卸载 XAFSmith**（只删除软件，不会删除你的项目和数据）。

**界面布局**：左侧导航按流程分组（项目 → 数据处理 → 结构与拟合 → 结果与导出 → 帮助，组间留空），当前页面以蓝色高亮。侧栏底部是当前项目与 **中文 / English** 切换（选择会被记住）。“保存会话参数”在 ⓪ 项目 → 6 输出。

## 二、建立项目（每个课题一次）

一个“项目”就是一个文件夹，里面按固定格式存放原始数据、结构文件和全部结果。

1. 左侧点 **⓪ 项目** → 展开“打开 / 新建项目”。
2. 点 **📁 浏览…**，选一个空文件夹（或新建一个），再点 **新建项目**。
3. 以后再打开这个项目：在“最近的项目”里选它，点 **打开**；或双击项目文件夹里的 **打开图形界面.bat**。

项目文件夹里会出现：`data/raw`（原始数据）、`structures`（结构文件）、`models`（拟合模型）、`notes`（记录）、`output`（全部结果）。

---

## 三、放入原始数据并登记（⓪ 项目 → 1 数据登记）

1. 每次测量（一个机时）建一个“批次”：在“批次文件夹名”填一个名字（例如 `2026-11-05_Ta`），
   把这次的原始文件拖进上传框，点 **上传**。
   **同一批次必须包含这次测的单质参比**（金属箔或粉，文件名中带 foil / powder / metal）。
   也可以直接用 Windows 资源管理器把文件复制到项目的 `data\raw\<批次>\` 文件夹。
2. 点 **扫描 data/raw，登记新文件**。下方出现登记表，每个原始文件一行。
3. 检查并修改登记表（直接在表格里点选/输入），然后点 **保存 meta.csv**：
   - **sample**：样品名。同名的多行 = 同一样品的多次扫描，会被合并；不想合并就改成不同名字。
   - **role**：参比箔选 `reference`，标样选 `standard`，样品选 `sample`。
   - **use**：不想用的扫描选 `0`，并在 **note** 写原因。
   - **ref_file**：这条谱用哪个参比校准（默认同批次参比）。为空的谱不能处理。
4. 点 **2 检查 → 运行检查**。出现“错误”就按提示改，直到 0 个错误。

## 四、设定处理参数（⓪ 项目 → 4 处理参数）

每个吸收边一套参数，同一边的所有样品共用：
- **样品中的全部元素**：用于检查干扰吸收边（例如 `Ta, Ir, O, K`）。
- 归一化（pre1、pre2、norm1、norm2、nnorm）、背景扣除（rbkg）、傅里叶变换（kmin、kmax、窗、k 权重）。
- **S0²**：先空着；在标样上拟合得到后再填回这里（见第七步）。

点 **保存参数**。

## 五、一键处理（⓪ 项目 → 3 一键处理）

依次点：
1. **① 质量检查**：看毛刺（glitch_E）、I0 掉束、边跳、k_snr3（信噪比可用到的 k）、荧光自吸收风险。
2. **② 按参比校准**：每个参比给出一个 ΔE，同批次所有谱加同一个 ΔE。
3. **③ 处理全部样品**：校准 → 归一化 → 合并 → χ(k) → 傅里叶变换。结果在 `output/processed` 和 `output/figs`。

要查看或比较谱图：点 **① 数据导入**，在上方“样品”里勾选样品，点 **载入样品**（参比会一起载入），
然后用 **④ 归一化**、**⑤ χ(k) 与 FT**、**⑥ 小波变换** 页面作图。

**去毛刺（② 质量检查 页下方）**：按 meta 载入样品后，在“去毛刺”中选样品（可多选，同一区间用于所选全部样品），
看 μ(E) 与 I0 图（灰色虚线为 QC 标出的疑似毛刺，可框选放大）。判断标准：只占 1–3 个点、远窄于 EXAFS 振荡、
常在多个样品同一能量出现、I0 同时有凹陷。填“删除区间”（校准后能量，如 `9984.5-9990; 10321-10327.5`）和
**理由（必填）**，点 **保存并重新载入**：区间写进 `xafsmith.json` 的 `deglitch`，原始文件不动，命令行处理同样生效。
“清除所选样品的去毛刺”可撤销。真实结构不要删。

## 六、FEFF 路径（⑦ FEFF 路径）

1. 结构来源选 **structures/ 文件夹**（先在“⓪ 项目 → 5 结构文件”上传 CIF），或选 **内置结构**。
2. 选吸收原子、吸收边、不等价位点、RMAX。
3. **FEFF 版本**：
   - **FEFF6L**（默认）：非自洽势，几秒出结果。
   - **FEFF8L**：自洽势（SCF），约 1–3 分钟。可设 **SCF 自洽半径**（一般 4–5 Å，包含 2–3 个壳层）和 **交换势**（默认 0 = Hedin-Lundqvist）。输出目录自动加 `_feff8`，不会覆盖 FEFF6 的结果。
   - 两者路径编号一般相同，模型里把路径目录换掉即可对比；但 **ΔE0 的零点不同**（Ta L3 的 KTaO3：FEFF6 约 6.6 eV，FEFF8 约 1.2 eV），固定 e0 的模型换版本后要重新确定 e0。
4. 点 **运行 FEFF6L / 运行 FEFF8L**。下方“已有 FEFF 计算”列出全部路径（距离、简并度、振幅比），FEFF8 计算同时显示 SCF 半径、交换势和费米能。

## 七、EXAFS 拟合（⑧ EXAFS 拟合）

1. **数据**：选样品（需先在 ① 中载入）；**FEFF 目录**：选对应结构。
2. **拟合范围**：kmin、kmax、k 权重（建议 1,2,3 同时）、Rmin、Rmax。页面显示 N_idp 和变量数上限。
3. **路径表**：勾选要用的路径；`N` 列写数字 = 固定配位数，写参数名（如 `n1`）= 让配位数变化；
   `deltar`、`sigma2` 列写参数名，同名即共用。
4. **参数表**：`vary` 打勾 = 自由变化，不勾 = 固定为 `value`；`expr` 填了内容 = 约束（例如 `dr1`、`ss1*1.5`）。
   页面提示“变量数 ≤ N_idp/2”。
5. 点 **拟合**。看 R 因子、χ²_ν、参数与误差、|χ(R)| 和 Re χ(R) 的拟合图、警告。
6. 满意后点 **保存结果**：模型存入 `models/`，结果进入汇总。以后可以在本页顶部“运行已保存的模型”一键重跑。

**同一模型用于一组样品**（时间序列、电位序列）：本页顶部展开 **运行已保存的模型**，选模型，在“样品”中多选，
点 **运行**：模型依次用于每个样品（模型名自动换成该样品），结果都进入 ⑨ 拟合历史，可在那里逐个查看、F 检验、
一键保存。先用结构已知的标样检验模型（能否复现已知结果、稳健性检查是否全部稳定），再用到样品上。

**标样定 S0²**：在结构已知的标样上让 S0² 自由拟合，得到的值填回“⓪ 项目 → 4 处理参数 → S0²”。
样品拟合时把 S0² 的 vary 取消勾选，value 填这个值。

**拟合诊断**：拟合结果下方展开 **拟合诊断：残差在哪里、为什么对不上**。显示窗口内残差、白噪声估计及二者之比（≈1–2 已到数据极限，≫2 为系统误差）；k 空间残差图（紫色虚线标出检测到的尖峰及对应能量，多为残留毛刺）；k 分段与 R 分段失配表；以及按残差位置给出的建议。拟合对不严时先看这里，完整方法见“❓ 使用指南 → 拟合质量提升教程”。

**稳健性检查**：拟合结果下方展开 **稳健性检查：改变拟合条件重复拟合** → **运行稳健性检查**。
软件依次改变 kmin ±0.5、kmax ±1、Rmax ±0.2 Å，以及单独用 k¹/k²/k³ 各拟合一次，
列出每个变量的变化范围；变化超过其统计误差的标为 **不稳**。不稳的参数应报告为多种条件下的范围，或修改模型。

## 八、比较模型（⑨ 拟合历史 / F 检验）

选“简单模型”和“复杂模型”（后者多了壳层或参数），点 **比较**：**p < 0.05** 才说明多出来的壳层显著。
点 **把以上全部拟合保存到 output/fits/** 可一次保存本次的全部拟合。

## 九、XANES 线性组合（⑩ LCF）

选样品和端点标样（必须是实测标样）、能量范围、空间（归一化 μ / 导数 / χ(k)），点 **LCF**。
同时给出“只用单一标样”的拟合作对照。

## 十、XANES 定量（⑬ XANES 定量）

先在 ① 中载入样品和标样。
- **边位置与白线**：勾选谱，得到 E0（导数最大值）、E_half（归一化 μ = 0.5 处）、白线峰位与峰高、白线面积
  （E0 至 E0+30 eV 内超过 1 的面积，区间可改）。点 **保存** 写入 `output/xanes/xanes_features.csv`。
- **价态标定**：选**已知价态的实测标样**，在表格里填价态，选边位置定义（推荐 E_half），软件拟合
  “边位置 = 斜率 × 价态 + 截距”；再选样品得到价态估算和误差。只有配体相同、结构相近的标样才能这样用；
  超出标样价态范围的结果标为“外推”。
- **边前峰拟合**：选谱、拟合区间（相对 E0）、峰数、主边基线（erf / arctan），点 **拟合边前峰**。
  看分量图判断基线是否合理；峰贴区间边界或面积≈0 时会提示。

## 十一、期刊出图（⑭ 期刊出图）

选图类型（归一化 XANES、XANES 导数、k^n χ(k)、|χ(R)|、拟合）、尺寸（单栏 85 mm / 1.5 栏 / 双栏 178 mm / 汇报 16:9）、
格式（TIFF、PNG、SVG、PDF），选谱后预览；点 **保存到 output/figs/journal/**。
图用 Arial 字体、色盲友好配色，TIFF/PNG 为 600 dpi；同名 .txt 是英文图注（含处理参数）。

## 十二、导出到 Athena（④ 归一化 页底部）

展开 **导出为 Athena 项目（.prj）**，选谱，点 **导出 .prj**，文件在 `output/gui/athena/`，也可直接下载。
.prj 中是已校准的能量和 μ(E)，并带上本软件用的 E0、归一化范围、rbkg、k 范围和窗函数，
用 Athena 打开就能和本软件的结果逐项对比。

## 十三、汇总报告与“方法”段落（⑫ 汇总报告）

点 **生成汇总**，得到：
- **汇总.xlsx**：样品、校准、质量检查、处理结果、拟合概要（每个模型一行）、EXAFS 每条路径参数、LCF、处理参数；
- **汇总报告.html**：上述表格 + 全部图（双击用浏览器打开，可“打印 → 另存为 PDF”）。

点 **下载** 或 **打开汇总文件夹**。

页面下方 **自动生成“方法”段落**：先填光源、线站、单色器、探测方式（点 **保存仪器信息**），
可选只写某些样品，点 **生成方法段落**，得到中英文两段，同时保存为 `output/reports/方法段落.md`。
段落只写项目文件中有记录的事实（校准参比与 ΔE、归一化/背景/FT 参数、拟合范围、N_idp、S0² 来源、软件版本），
没填的仪器信息用【方括号】占位。**这是草稿，投稿前逐句核对。**

## 十三之二、SI 拟合方法文本（⑮ SI 方法）

1. 在 ⑧ 中拟合并点 **保存结果**（只有保存过的拟合会出现在这里）。
2. ⑮ SI 方法：选择要写进补充材料的拟合（可多选；同一模型用于多个样品时合并成一段），选 English 或 中文。
3. **方法** 标签：点 **复制**，直接粘贴到 SI。文字只写项目中有记录的事实：数据与吸收边、FEFF 版本与结构、k / R 范围、k 权重、窗函数、独立点数与变量数、S0² 及其来源、ΔE0 处理、每条路径的约束、误差估计方式。
4. **表 S[n]** 标签：每条路径的 N、R、σ²、ΔE0（括号内为最后一位的误差），以及 R 因子、χ²_ν、N_idp / 变量数。点 **复制（粘贴到 Excel / Word）**：粘贴到 Excel 直接成表；在 Word 中粘贴后用“文本转换成表格”。也可下载 .md / .csv。
5. 文中 “Table S[n]” 的编号、结构文件来源等请按论文实际情况修改。

## 十四、英文界面与检查更新

- 侧栏底部的 **中文 / English** 选 **English**，整个界面切换为英文（使用指南也换成英文版）；选择会被记住。
- “❓ 使用指南”页的 **检查更新**：可勾选“启动时自动检查新版本”（只访问 github.com），或点 **现在检查**。
  有新版本时侧栏会提示，点 **更新到最新版** 自动下载安装，完成后关闭窗口重新打开即可。

## 十五、接入 AI 助手（⓪ 项目 → 7 AI 助手）

XAFSmith 项目可以直接交给 AI 助手（Claude Code、Codex、Cursor 等）处理、拟合和导出。

1. ⓪ 项目 → **🤖 7 AI 助手** → 点 **写入 / 更新 AI 说明文件**。
   项目文件夹里会写入 `AGENTS.md`（含本机 xafsmith 命令的完整路径、工作流程、拟合与导出命令、规则）和 `CLAUDE.md`。
   你自己写在这两个文件里的内容会保留。
2. 在项目文件夹里打开 AI 助手（页面上有各工具的打开方式），用自己的话说要做什么，例如：
   “检查数据质量”“用标样确定 S0²”“把同一个模型用于整个序列并做 F 检验”“导出双栏期刊图和汇总报告”。
3. AI 的结果都在项目里：模型在 `models/`（⑧ 顶部可一键重跑并查看拟合诊断），数值在 `output/`，记录在 `notes/`，
   图在 `output/figs/journal/`，报告在 `output/reports/`。

软件更新后（命令路径可能变化）再点一次“写入 / 更新”即可。

## 判读提醒

- R 空间峰位**未相移校正**，比真实键长短约 0.3–0.5 Å，键长看拟合结果。
- 变量数 ≤ N_idp/2；|ΔE0| > 10 eV、σ² < 0、S0² 超出 0.6–1.1 时软件会警告，要检查模型。
- 加壳层要做 F 检验；p ≥ 0.05 的壳层不能说“观察到”。
- 荧光与透射的白线/振幅不能直接比较（自吸收、样品厚度）。
- 报告结论时区分：**实测**（谱上可见）/ **拟合**（依赖模型）/ **推测**（需其他实验）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击图标后窗口一直显示“正在启动” | 第一次启动较慢（约 10–30 秒）；超过 2 分钟请查看 `C:\Users\<你>\.xafsmith\app.log` |
| 提示“还没有安装” | 再双击一次 `installer.py` |
| 窗口打不开（极少数旧系统缺少 WebView2） | 安装微软 Edge WebView2 运行库（https://developer.microsoft.com/microsoft-edge/webview2/ ，选 Evergreen Bootstrapper），再双击图标 |
| 登记表 ref_file 为空 | 这个批次没有参比：把同批测的金属箔文件放进该批次后重新扫描 |
| 某条谱有毛刺 | 在登记表把这条扫描 use 设为 0（写原因）；或请会编辑配置的人在 xafsmith.json 中设去毛刺区间 |
| 想重新开始 | 删除项目的 `output` 文件夹，再点“一键处理”，结果会全部重新生成；原始数据不受影响 |
