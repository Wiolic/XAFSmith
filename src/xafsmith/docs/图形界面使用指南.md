# XAFSmith 图形界面使用指南

这份指南按使用顺序，逐页说明 XAFSmith 窗口里的每个功能：**做什么、怎么操作、看什么结果**。

- 不熟悉 XAFS 原理：先读 **XAFS 基础讲义**。
- 第一次做 EXAFS 拟合：跟着 **零基础拟合教程** 做一遍。
- 拟合对不上、想做得更好：读 **拟合质量提升教程**。

使用指南在独立窗口中打开，可以放在主窗口旁边，一边看一边操作。

## 一、开始

### 1　安装与启动

**安装（只需一次，约 15 分钟，需要联网）**

1. 安装 Python 3.11 或 3.12：打开 https://www.python.org/downloads/windows/ 下载安装包。安装时**勾选 “Add python.exe to PATH”**，然后一路“下一步”。
2. 打开 https://github.com/Wiolic/XAFSmith ，点绿色的 **Code → Download ZIP**，解压到任意位置。
3. 双击解压文件夹里的 **installer.py**，弹出安装向导：
   - **安装位置**：默认 `C:\Users\<你>\AppData\Local\Programs\XAFSmith`，可点“浏览…”改到其他磁盘；
   - 按需勾选 **创建桌面快捷方式**、**创建开始菜单快捷方式（含卸载）**、**安装完成后立即启动**；
   - 勾选 **我已阅读并同意**，点 **安装**，等进度条走完。
4. 安装完成后，解压的文件夹可以删除。

> 双击 installer.py 没有反应或用记事本打开了：右键 → 打开方式 → Python。仍不行就重装 Python，确认勾选了 “Add python.exe to PATH” 与 “py launcher”。

**启动与卸载**

- 启动：双击桌面或开始菜单里的 **XAFSmith**，几秒后窗口打开。关闭窗口即退出。
- 卸载：开始菜单 → XAFSmith → **卸载 XAFSmith**。只删除软件，不删除你的项目和数据。

### 3　建立项目

一个“项目”就是一个文件夹，原始数据、结构文件和全部结果都按固定格式放在里面。每个课题建一个。

**新建**

1. 点左上角 **打开 / 新建项目**。
2. 点 **浏览…**，选一个空文件夹（或新建一个）。
3. 点 **新建项目**。已有文件不会被覆盖。

**以后打开**：在“最近的项目”里**双击**它；或双击项目文件夹里的 **打开图形界面.bat**。

**项目文件夹里有什么**

| 文件夹 | 内容 |
|---|---|
| `data/raw/` | 原始数据（只读，按批次分子文件夹） |
| `data/meta.csv` | 数据登记表 |
| `structures/` | 结构文件（CIF、POSCAR） |
| `models/` | 拟合模型 |
| `notes/` | 分析记录 |
| `output/` | 全部结果 |

打开项目后进入 **数据登记** 页。

## 二、准备数据

### 4　数据登记

**做什么**：把原始数据放进项目，并在登记表 `data/meta.csv` 中写清每个文件是什么。后面所有步骤都按这张表来。

**步骤**

1. 每次测量（一个机时）建一个**批次**：在 **批次文件夹** 填名字，例如 `2026-11-05_Ta`。
2. 点 **选择文件，复制到批次并登记…**，选中这次的全部原始文件：
   - 文件被复制到 `data/raw/<批次>/`，原文件不动；
   - 同名文件不覆盖，会提示跳过；
   - 复制后**自动登记**到下方的 `data/meta.csv`。
3. **同一批次必须包含这次测的单质参比**（金属箔或粉，文件名中带 foil / powder / metal）。
4. 检查并修改登记表（双击单元格），然后点 **保存 meta.csv**：

| 列 | 怎么填 |
|---|---|
| sample | 样品名。同名的多行 = 同一样品的多次扫描，会被合并；不想合并就改成不同名字 |
| role | 参比箔 `reference`，已知结构的标样 `standard`，样品 `sample` |
| use | 不想用的扫描填 `0`，并在 note 写原因 |
| ref_file | 用哪个参比校准（默认同批次参比）。为空的谱不能处理 |

5. 页面下方 **按数据标准检查 → 运行检查**。出现“错误”就按提示改，直到 0 个错误。

> 用资源管理器直接放进 `data\raw\<批次>\` 的文件，点 **扫描 data/raw，登记新文件** 登记。

### 5　校准与处理

**做什么**：设定处理参数，然后一次处理全部样品。

**第一步：处理参数**（右上角选吸收边；每个吸收边一套参数，同一边的所有样品共用）

| 参数 | 说明 |
|---|---|
| 样品中所有元素 | 用于检查干扰吸收边和可用的 k 上限，例如 `Ta, Ir, O, K` |
| 归一化 | pre1、pre2、norm1、norm2、nnorm、E0 平滑 |
| 背景扣除与傅里叶变换 | rbkg、k 权重、kmin、kmax、dk、窗 |
| S0² | 值、误差、来源。先空着，在标样上拟合得到后再填回（见第 11 节） |

点 **保存参数**。

**第二步：批量运行**，依次点：

1. **① 质量检查**：毛刺（glitch_E）、I0 掉束、边跳、k_snr3（信噪比可用到的 k）、荧光自吸收风险。
2. **② 按参比校准**：每个参比给出一个 ΔE，同批次所有谱加同一个 ΔE。
3. **③ 处理全部样品**：校准 → 归一化 → 合并 → χ(k) → 傅里叶变换。

结果在 `output/processed/` 和 `output/figs/`。

## 三、看数据

### 6　载入与检查

侧栏 **载入与检查** 一页有三个标签：**载入谱**、**质量检查**、**能量校准**。在标签之间切换即可，不用回侧栏。

**标签一：载入谱**

1. 在 **样品** 中勾选，或在 **或整条吸收边** 中选一条边。
2. 点 **载入**。参比会一起载入。
3. 载入的谱已校准、归一化、合并，χ(k) 与 FT 已算好。

下方表格列出已载入的谱及其校准状态。还可以：

- **查看原始 μ(E) 与通道**：原始 μ(E) 与 I0 / I1 / If；
- **移出会话（不删除文件）**；
- **直接读入文件**（自动识别 BSRF / XDI / .xmu / XDAC / Athena .prj，也可在“格式”中手动指定，或选“通用列文本（按列号）”后填写下方列号）：用于不在 meta.csv 中的文件，必须选同批次参比。读入时若有猜测的字段（元素、吸收边、能量单位等）或列映射警告，会弹出提示，请核对。
- **列映射向导**（“读入”旁的按钮，先选好一个文件）：文件格式不被自动识别、或列名不规范时使用。窗口里先预览各列和前几行数据；指定能量、I0、It、If（可多个通道，求和）、μ 各对应哪一列（能识别的列名会预先选好）；选透射或荧光，或让软件按已指定的列判断；点 **试读** 看点数、能量范围、模式、吸收边和 μ 范围，核对无误后输入模板名，**保存为模板**。模板写入项目的 `xafsmith.json`（`formats`），之后出现在“格式”下拉框，也可写进 meta.csv 的 `format` 列。列名唯一时按名称保存（换文件、列顺序变了也能用），重名或没有列名的按列号保存。模板名不能与内置格式同名。

**标签二：质量检查**

- **检查已载入的谱**：结果写入 `output/qc/qc_report.csv`。
- **去毛刺**：
  1. 选样品（可多选，同一区间用于全部所选）；
  2. 看 μ(E) 与 I0 图：灰色虚线是检查标出的疑似毛刺，红色是已删除的区间，可框选放大；
  3. 填 **删除区间**（校准后能量，如 `9984.5-9990; 10321-10327.5`）和 **理由**（必填）；
  4. 点 **保存并重新载入**。区间写进 `xafsmith.json`，原始文件不动；**清除所选样品的去毛刺** 可撤销。

> 判断是不是毛刺：只占 1–3 个点，远窄于 EXAFS 振荡，常在多个样品的同一能量出现，I0 同时有凹陷。真实结构不要删。

**标签三：能量校准**

- **参比校准值**：每个参比的 ΔE；
- **已载入谱的校准状态**：每条谱用的参比、与参比的测量时间差；可 **换参比 / 补校准**；
- **测定 / 重新测定参比 ΔE**（展开）：改表值或导数平滑后重新测定。

### 7　归一化

- 上方：全组共用的归一化参数，改动立即重算。
- 四个标签：
  - **μ(E) 与边前 / 边后**：检查边前线、边后线是否合理；
  - **归一化叠加**：可选 flattened、横轴 E − E0；
  - **导数**；
  - **合并扫描**：自动剔除偏离中位谱的扫描，也可手动剔除。
- 页面下方 **导出**：所选谱的归一化数据（`output/gui/norm/`）和 Athena 工程 .prj（第 18 节）。

**看什么**：边前线贴着边前数据，边后线从数据中间穿过；归一化后边后区在 1 附近平稳振荡。同一边的所有样品用同一套参数。

### 8　χ(k) 与 FT

- 参数：rbkg、k 范围、窗、k 权重，改动立即重算。
- 四个标签：
  - **χ(k)**（含窗函数）；
  - **|χ(R)| / Re**：R 轴未相移校正；
  - **背景 μ0(E)**；
  - **k 范围检查**：干扰吸收边给出的可用 k 上限、ΔR 分辨率与 N_idp。
- **导出 χ(k) 与 χ(R) 到 output/gui/chi/**。

**看什么**：k²χ(k) 围绕 0 振荡，没有整体倾斜；k¹、k²、k³ 都看一遍；k 范围按全组最差的样品定，全组相同。

### 9　小波变换

**做什么**：同时在 k 和 R 上看信号，用来区分轻散射体（O 等，极大值在低 k）和重散射体（金属，极大值在高 k）。

**步骤**

1. 选 **谱（左）**。想对比时再选 **对比谱（右）**：两张图左右并排，各为 1:1，参数完全相同。
2. 选母小波（Morlet / Cauchy）、k 权重、η、σ、显示 Rmax。页面实时显示当前分辨率。
3. 需要比较绝对强度时勾选 **两图共用色标**；不勾时各自从 0 到各自的最大值。
4. **各 R 区间的极大值**：填 R 区间（如 `1.0-2.0; 2.0-3.6`），表格按样品列出每个区间 |W| 极大值所在的 k 与 R，图上用白色“+”标出。
5. **导出数据与图**：对图中的每条谱写入 `output/gui/wavelet/`：|W| 矩阵 `.csv`（第一行 k、第一列 R）、极大值表 `_maxima.csv`、600 dpi `.png` 与 `.svg`、参数 `.params.json`。

**参数怎么调**（右上角说明按钮有完整说明）

- 本软件的 Morlet 定义中，图形只由乘积 ησ 决定：k 方向模糊约 ησ/(2R)，R 方向约 R/(ησ)，此消彼长。
- k 权重越高，所有极大值越向高 k 移，重散射体越突出。只比较同一 k 权重下的 k 位置。
- 适合区分第二壳层是 M–M 还是 M–O，判断单原子与团簇；不能给出配位数和键长。

## 四、分析

### 10　FEFF 路径

**做什么**：由晶体结构计算散射路径（距离、简并度、散射振幅与相移），供拟合使用。

**步骤**

1. 结构来源：
   - **structures/ 文件夹**：点 **添加结构文件…** 复制 CIF / POSCAR 进来；
   - **内置结构**：直接选；**内置结构导出为 CIF** 可把它存到 `structures/builtin/`。
2. 选 **吸收原子**（默认最重的元素，按结构分别记住）、**吸收边**、**不等价位点**、**RMAX**、**NLEG**。
3. 选 **FEFF 版本**：

| | FEFF6L（默认） | FEFF8L |
|---|---|---|
| 势 | 非自洽 | 自洽（SCF） |
| 时间 | 几秒 | 约 1–3 分钟 |
| 额外参数 | — | SCF 自洽半径（一般 4–5 Å，含 2–3 个壳层）、交换势（默认 0 = Hedin-Lundqvist） |
| 输出目录 | `…/<结构>_<元素><边>/site0` | 末尾加 `_feff8`，不覆盖 FEFF6 结果 |

4. 点 **运行 FEFF**。

**看结果**：下方 **已有计算** 列出全部路径（距离、简并度、振幅比）；FEFF8L 计算同时显示 SCF 半径、交换势和费米能；可展开查看 feff.inp。

> FEFF6L 与 FEFF8L 的 ΔE0 零点不同（例：KTaO₃ 的 Ta L3，FEFF6 约 6.6 eV，FEFF8 约 1.2 eV）。换版本后，固定 e0 的模型要重新确定 e0。

### 11　EXAFS 拟合

**页面布局**

| 区域 | 内容 |
|---|---|
| 左栏（可单独滚动） | ① 数据与 FEFF　② 拟合范围　③ 路径　④ 参数；顶部可展开“运行已保存的模型” |
| 左栏底部（固定） | **模型名** 与 **拟合** 按钮；也可按 **Ctrl+Enter** 拟合 |
| 右栏 | 最近一次拟合：指标、k 与 R 空间拟合图；下面的标签页：参数、路径、质量检查、诊断、稳健性、完整报告 |
| 右上角 | **注意事项与“拟合得好”的标准**（独立窗口） |

两栏之间的分隔条可以左右拖动。拟合时只更新右栏，左栏的设置和滚动位置不变。

**设置拟合（左栏）**

1. **数据与 FEFF**：选数据（需已算出 χ(k)）和 FEFF 目录（可多选：多物相 / 多位点）。
2. **拟合范围**：kmin、kmax、dk、窗、k 权重（建议 1、2、3 同时）、Rmin、Rmax、拟合空间。页面显示 N_idp 与变量数上限 N_idp/2。
3. **路径**：勾选要用的路径，单击单元格修改：

| 列 | 写法 |
|---|---|
| N | 数字 = 固定配位数；参数名（如 `n1`）= 让配位数变化；留空 = FEFF 简并度 |
| s02、e0 | 参数名，通常所有路径共用 `s02`、`e0` |
| deltar、sigma2 | 参数名，同名即共用（如两条相近的 Ir–O 都写 `dr1`、`ss1`） |
| 任意列 | 可写表达式，如 `ss1*1.5` |

4. **参数**：
   - `vary` 打勾 = 自由变化，不勾 = 固定为 `value`；
   - `expr` 填了内容 = 由表达式约束；
   - `min` / `max` = 取值范围；
   - `value` 可输入任意位小数（如 σ² 写 0.00412）；
   - 页面实时显示变量数，超过 N_idp/2 变成橙色。

**拟合与看结果（右栏）**

1. 填模型名，点 **拟合**（或 Ctrl+Enter）。
2. 右栏显示 R 因子、χ²_ν、N_idp、变量数，以及 k 空间与 R 空间（|χ(R)| 与 Re χ(R)，灰色为拟合窗口）的拟合图。
3. 标签页：

| 标签 | 内容 |
|---|---|
| 参数 | 每个参数的值与误差 |
| 路径 | 每条路径的 N、R、σ²、ΔE0 |
| 质量检查 | 逐条打 ✓ / ⚠（标签上显示 ⚠ 的条数），见下 |
| 诊断 | 窗口内残差、白噪声估计及二者之比；k 空间残差图（紫色虚线标出尖峰）；k、R 分段失配表与建议 |
| 稳健性 | **运行稳健性检查**：依次改变 kmin ±0.5、kmax ±1、Rmax ±0.2 Å，并单独用 k¹/k²/k³，变化超过统计误差的参数标为“不稳” |
| 完整报告 | Larch 的 feffit 报告（含相关系数） |

4. **采纳拟合值到参数**：把本次拟合的变量值写回左栏参数表的 `value`，作为下次拟合的初值（固定与约束的参数不变）。
5. 满意后点 **保存结果**：模型存入 `models/`，结果进入报告与方法导出。

**质量检查逐条判断的内容**

- R 因子：< 0.02 很好；0.02–0.05 第一壳层可接受；
- 变量数 ≤ N_idp/2；
- 残差 / 噪声 ≤ 约 2（已到数据极限）；
- 每个变量的误差可估，且小于数值本身；参数没有停在上下限；
- |ΔE0| ≤ 10 eV；σ² 为正且不过大；|ΔR| ≤ 0.2 Å；
- 没有 |r| > 0.9 的强相关参数对；
- 是否只用了单一 k 权重；是否已运行稳健性检查。

> 这些是必要条件，不是充分条件：新增的壳层还要通过 F 检验（第 12 节）并在稳健性检查中稳定。

**两个常用做法**

- **标样定 S0²**：在结构已知的标样上让 S0² 自由拟合，把结果填回“校准与处理 → 处理参数 → S0²”。拟合样品时，`s02` 取消 vary，value 填这个值。
- **同一模型用于一组样品**（时间、电位序列）：左栏顶部展开 **运行已保存的模型** → 选模型 → “样品”中多选 → **运行**。模型依次用于每个样品，结果都进入拟合历史。先用标样检验模型，再用到样品上。

### 12　拟合历史

- 上方列出当前打开的全部拟合；**全部保存到 output/fits/** 一次保存。
- **F 检验（Hamilton）**：选“简单模型”和“复杂模型”（后者多了壳层或参数），点 **比较**。**p < 0.05** 才说明多出来的壳层显著。
- **查看拟合**：切换到任一拟合，显示与 EXAFS 拟合页右栏相同的结果与标签页。

### 13　LCF（线性组合拟合）

1. 选样品和端点标样（**必须是实测标样**）。
2. 选空间（归一化 μ / 导数 / χ(k)）、范围、约束（权重和 = 1、0 ≤ w ≤ 1、拟合能量平移）。
3. 点 **LCF**。

**看结果**：权重与误差、拟合图；同时给出“只用单一标样”的拟合，以及（3 个以上标样时）全部组合的比较。结果追加到 `output/lcf/lcf_results.csv`。使用非实测端点时，必须在“备注”中注明为假设。

### 14　XANES 定量

先载入样品和标样。三个标签：

| 标签 | 做什么 |
|---|---|
| 边位置与白线 | 得到 E0（导数最大值）、E_half（归一化 μ = 0.5 处）、白线峰位与峰高、白线面积；**保存** 写入 `output/xanes/xanes_features.csv` |
| 价态标定 | 用**已知价态的实测标样**拟合“边位置 = 斜率 × 价态 + 截距”，再估算样品价态与误差；超出标样范围的标为“外推” |
| 边前峰拟合 | 选拟合区间、峰数、主边基线（erf / arctan），点 **拟合边前峰**；峰贴区间边界或面积 ≈ 0 时会提示 |

> 价态标定只适用于配体相同、结构相近的标样与样品。

## 五、导出

### 15　报告导出

1. 有未保存的拟合时，先点 **先保存当前的全部拟合**。
2. 点 **生成报告**，得到 `output/reports/汇总_<时间>/`：
   - **汇总.xlsx**：样品、校准、质量检查、处理结果、拟合概要（每个模型一行）、每条路径参数、LCF、处理参数；
   - **汇总报告.html**：上述表格 + 全部图。图按“谱图 / 拟合 / LCF”分组排成缩略图网格。
3. 按钮：**打开报告文件夹**、**另存 汇总.xlsx…**、**在浏览器中打开报告**。下方 **预览** 可逐表查看。

**在浏览器中看图**：点击缩略图放大；滚轮缩放、拖动平移、双击复位；Esc 或点空白处关闭。需要 PDF 时用浏览器的“打印 → 另存为 PDF”。

### 16　图片导出

**设置**

1. 选图类型：归一化 XANES、XANES 导数、kⁿχ(k)、|χ(R)|、拟合（k + R）。
2. 选谱（按顺序作图）、错开量、范围。
3. **配色方案**：24 种，命名同 PeakForge，分六个家族（水域、森林、大地、天穹、山岩、原野），每种标明类型：
   - 单色渐变：适合同一系列样品（价态、时间、电位），按样品数在色带上均匀取色；
   - 多色对比、柔和期刊、色盲友好。
   - 默认 **水域 · 冰川**：样品蓝色、标样灰色。
4. **参比 / 标样**：选中的谱画成灰色、线稍细（默认选中名称含 foil / powder / metal 的谱）；清空则全部按样品配色。
5. 尺寸（单栏 85 mm / 1.5 栏 / 双栏 178 mm / 汇报 16:9）、格式（TIFF、PNG、SVG、PDF）、文件名。

预览按实际尺寸显示；下方是英文图注（随图保存为 .txt，含处理参数）。

**保存**：点 **保存到 output/figs/journal/**。Arial 字体，TIFF / PNG 为 600 dpi。

**导出 Origin 工程 (.opju)**

每条曲线写成工作表中的一对 X/Y 列（列名为图例），按统一格式作图：

| 项目 | 设置 |
|---|---|
| 图层 | 25 × 19 cm |
| 字体 | Arial 32 pt（坐标轴标题、刻度、图例） |
| 坐标轴 | 2 pt，四边框；上、右框线无刻度；刻度朝内 |
| 线 | 数据 3.5 pt，标样 3 pt；开启抗锯齿 |
| 图例 | 无边框；化学式下标写成 Origin 格式（IrO\-(2)） |
| XANES | 横轴为能量 E（eV）；错开作图时纵轴不显示刻度 |

- 本机装有 Origin（2021 及以上）：直接生成 `output/figs/journal/origin/<文件名>/<文件名>.opju`，约 10–30 秒，期间窗口暂停响应。
- 没有 Origin：只写出数据（.csv）、`spec.json` 与 `build_origin.py`。在装有 Origin 的电脑上，打开 Origin 的脚本窗口，输入 `run -pyf "<该文件夹>/build_origin.py"`，得到同样的工程（见文件夹里的 README_Origin.txt）。

### 17　方法导出

**“方法”段落**

1. 填光源、线站、单色器、探测方式等，点 **保存仪器信息**。
2. 可选：在“范围”中只选某些样品。
3. 点 **生成方法段落**，得到中、英文两段（各带 **复制** 按钮），同时保存为 `output/reports/方法段落.md`。

段落只写项目文件中有记录的事实：校准参比与 ΔE、归一化 / 背景 / FT 参数、拟合范围、N_idp、S0² 来源、软件版本。没填的仪器信息用【方括号】占位。**这是草稿，投稿前逐句核对。**

**拟合参数表（补充材料 Table S[n]）**

1. 只有点过 **保存结果** 的拟合会出现在这里。选择要写进补充材料的拟合（可多选）。
2. 表中是每条路径的 N、R、σ²、ΔE0（括号内为最后一位的误差），以及 R 因子、χ²_ν、N_idp / 变量数。
3. **复制表格**：粘贴到 Excel 直接成表；在 Word 中粘贴后用“文本转换成表格”。
4. 也可 **另存 .csv**，或 **另存 .md（含拟合说明）**：附中英文拟合方法文字（FEFF 版本与结构、k / R 范围、k 权重、窗函数、独立点数与变量数、S0² 来源、各路径约束、误差估计方式）。
5. “Table S[n]” 的编号、结构文件来源请按论文修改。

### 18　导出到 Athena

在 **归一化** 页下方的 **导出** 中填文件名，点 **导出 .prj**，文件在 `output/gui/athena/`。

.prj 中是已校准的能量和 μ(E)，并带上本软件用的 E0、归一化范围、rbkg、k 范围和窗函数。用 Athena 打开，就能和本软件的结果逐项对比。

## 六、工具与帮助

### 19　制样指导

**样品信息**（下面两个工具共用）

- **化学式**：如 IrO2、Ta2O5；非整比写成 IrCo0.2O2。
- **目标元素**：从化学式读出，默认最重的元素。
- **吸收边**：K / L3 / L2 / L1。

页面显示体系中的元素和该吸收边的能量。

**压片制样计算器**

- 输入：压片面积（φ13 mm = 1.327 cm²）、稀释剂与其质量、目标总 μt；
- 输出：推荐样品质量、边后总 μt、边跳 Δμt；
- 填了样品质量，则计算这个质量下的实际 μt。

> 透射样品：总 μt 1.5–2.6 最佳，Δμt ≥ 0.2；均匀、无针孔比 Δμt 精确匹配更重要。

**干扰吸收边筛查**

- 参与筛查的元素 = 化学式中的元素 + 稀释剂中的元素 + “其他共存元素”（可空，如杂质 K、Cl）；
- 列出扫描范围内会出现的其他吸收边及其 k 值；k 上限要取在第一个干扰边之前。

数据来自 xraydb（Elam 表）。

### 20　吸收边查询

与 Hephaestus 的周期表相同：点击元素，下面一排三张表。

| 表 | 内容 |
|---|---|
| 吸收边 | 各吸收边的能量、荧光产额、跳跃比 |
| 荧光线 | 谱线名（Siegbahn）、能量、相对强度（同一初始能级内归一）、跃迁 |
| 荧光滤片 | 选测量的吸收边和滤片厚度（吸收长度数 μx，默认 3）；列出吸收边落在“主荧光线”与“目标吸收边”之间的元素，给出厚度（μm）与主荧光线透过率 |

滤片按透过率排序，第一行通常就是 Z−1 规则的元素（例：Fe K → Mn）。

### B　判读提醒

- R 空间峰位**未相移校正**，比真实键长短约 0.3–0.5 Å；键长看拟合结果。
- 变量数 ≤ N_idp/2；|ΔE0| > 10 eV、σ² ≤ 0、参数卡在边界时，质量检查会标出，要检查模型。
- 加壳层要做 F 检验；p ≥ 0.05 的壳层不能说“观察到”。
- 荧光与透射的白线、振幅不能直接比较（自吸收、样品厚度）。
- 结论区分三类：**实测**（谱上可见）、**拟合**（依赖模型）、**推测**（需其他实验）。
