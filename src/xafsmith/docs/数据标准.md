# XAFSmith 数据标准（schema 1.0）

一个 **XAFSmith 项目** = 一个包含 `xafsmith.json` 的文件夹。所有命令、图形界面与 AI 助手都按下面的约定读写；
`xafsmith validate` 按本标准检查项目，`xafsmith new <目录>` 生成符合标准的空项目。

## 1. 目录结构

```
<项目>/
├── xafsmith.json        项目标识 + 处理参数（第 3 节）
├── project.md           体系信息与结论（人写）
├── AGENTS.md            给 AI 助手的入口说明（模板生成）
├── data/
│   ├── raw/<批次>/…     原始数据（只读）
│   └── meta.csv         数据登记表（第 2 节）
├── structures/          结构文件：CIF / POSCAR / CONTCAR / *.vasp / pymatgen JSON
├── models/              EXAFS 拟合模型 JSON（第 4 节）；文件名以 _ 开头的是模板，不检查
├── notes/               分析记录：YYYY-MM-DD_主题.md
├── scripts/             项目专用分析脚本（可选）
└── output/              全部生成结果（可删除后重新生成）
    ├── qc/              qc_report.csv
    ├── calib/           calib.json（按参比文件索引）
    ├── processed/       <样品>.nor / .chik / .chir、process_summary.csv
    ├── feff/            <结构>_<吸收原子><边>/site<i>/feff.inp、feffNNNN.dat
    ├── fits/            exafs_fits.csv、<模型>.fit_report.txt、<模型>.params.json
    ├── lcf/             lcf_results.csv
    ├── figs/            16:9 汇报图（2666×1500，图注含处理参数）
    ├── reports/<主题>/  专题分析的报告、表格、图
    └── gui/             图形界面导出与会话参数
```

规则：
1. **原始数据只读。** 任何结果都可以从原始数据 + `xafsmith.json` + `meta.csv` + `models/` 重新生成。
2. **原始数据位置**：推荐 `data/raw/<批次>/`；也可以留在项目内其他位置，只要在 `meta.csv` 中用相对项目根目录的路径登记。
3. **批次** = 一次测量（同一机时、同一单色器状态）。每个批次文件夹应包含该批次测量的**单质参比**（金属箔/粉；
   文件名含 `foil` / `powder` / `metal` 时 `init` 自动识别为参比）。
4. 所有路径用**相对项目根目录**、正斜杠（如 `data/raw/2026_Ta/Ta_foil`、`output/feff/KTaO3_TaL3/site0/feff0001.dat`）。
5. 项目根目录的确定：`--project` 参数 / 环境变量 `XAFSMITH_PROJECT` → 当前目录向上查找 `xafsmith.json` → 当前目录。

## 2. data/meta.csv

UTF-8（带 BOM），每个原始文件一行。

| 列 | 必需 | 含义 |
|---|---|---|
| `file` | ✔ | 原始文件路径（相对项目根目录） |
| `sample` | ✔ | 样品名。**同名多行 = 同一样品的多次扫描，处理时合并**（异常扫描自动剔除并记录理由） |
| `edge_key` | ✔ | `<元素>_<边>`，如 `Ta_L3`、`Co_K`；对应 `xafsmith.json` 的 `edges` |
| `mode` | ✔ | `trans`（μ = ln(I0/I1)）或 `fluo`（μ = If/I0） |
| `role` | ✔ | `reference`（校准用单质参比）/ `standard`（标样）/ `sample` |
| `use` | ✔ | `1` 使用，`0` 不用（**必须在 note 写理由**） |
| `ref_file` | ✔ | 校准这条谱用的参比文件；`init` 自动填同批次、同吸收边的参比。**为空的谱不能处理** |
| `batch` | | 批次（`data/raw/` 下第一级文件夹名） |
| `time` | | 测量时间（文件头） |
| `npts`、`emax` | | 点数、末端能量 |
| `note` | | 备注 |

命名规则：
- 新批次与已有批次重名的样品，`init` 自动加批次后缀（`KTaO3_20261105_Ta`），避免误合并。
- 编号被弄乱、或同名文件需要分开处理时，直接改 `sample` 列使每个文件独立。

## 3. xafsmith.json

```json
{
  "xafsmith": {"schema": "1.0"},
  "edges": {
    "Ta_L3": {
      "element": "Ta", "edge": "L3",
      "e_table": 9881.0, "e_table_source": "xraydb (Elam)",
      "elements_in_sample": ["Ta", "Ir", "O", "K"],
      "norm": {"pre1": -150, "pre2": -30, "norm1": 100, "norm2": -10, "nnorm": 2, "smooth_ev": 1.0},
      "bkg":  {"rbkg": 1.0, "kweight": 2},
      "ft":   {"kmin": 3.0, "kmax": 12.0, "dk": 1.0, "window": "hanning", "kweight": 2},
      "s02_recommended": {"value": 0.68, "err": 0.07, "source": "KTaO3 多壳层拟合"}
    }
  },
  "overrides":        {"样品名": {"norm": {"pre1": -70}, "ft": {"kmax": 10.5}}},
  "overrides_reason": {"样品名": "理由（必填）"},
  "deglitch":         {"样品名": [[E_lo, E_hi]]},
  "deglitch_reason":  {"样品名": "理由（必填）"}
}
```

- 每个吸收边一套参数，**同一边的所有样品用同一套参数**；个别样品必须改时写进 `overrides` 并给理由。
- `norm2 ≤ 0` 表示距数据末端的距离（eV）。
- E0 统一取一阶导数最大值。
- `deglitch` 的能量为**校准后**能量；只删处理副本中的点。

## 4. 拟合模型（models/<名称>.json）

```json
{
  "name": "KTaO3_2shell",
  "sample": "KTaO3",
  "kmin": 3, "kmax": 13, "dk": 1, "window": "hanning", "kweight": [1, 2, 3],
  "rmin": 1.0, "rmax": 4.0, "fitspace": "r",
  "params": {
    "s02": {"value": 0.68, "vary": false},
    "e0":  {"value": 0, "vary": true, "min": -15, "max": 15},
    "dr1": 0.0,
    "ss1": {"value": 0.005, "vary": true, "min": 0.0005, "max": 0.03},
    "ssT": 0.006
  },
  "paths": [
    {"file": "output/feff/KTaO3_TaL3/site0/feff0001.dat", "label": "Ta-O",  "deltar": "dr1",   "sigma2": "ss1"},
    {"file": "output/feff/KTaO3_TaL3/site0/feff0004.dat", "label": "Ta-Ta", "deltar": "2*dr1", "sigma2": "ssT", "N": "6"}
  ]
}
```

| 写法 | 含义 |
|---|---|
| `"dr1": 0.0` | 数字：自由变化，初值 0 |
| `{"value": .., "vary": false}` | 固定 |
| `{"value": .., "vary": true, "min": .., "max": ..}` | 自由变化，有界 |
| `{"expr": "ss1*1.5"}` 或直接写字符串 `"ss1*1.5"` | 约束（由其他参数计算） |
| 路径 `"N": "6"` / `"N": "n1"` | 固定配位数 / 配位数作为参数（替换 FEFF 简并度） |
| 路径中 `s02`、`e0`、`deltar`、`sigma2`、`third` | 参数名或表达式；可用 `reff`、`degen` |

- `sample` 必须是 `meta.csv` 中的样品名；数据处理参数自动取自 `xafsmith.json`。
- 同一 `label` 可用于多条路径（自动加文件号区分）。
- 变量数 ≤ N_idp/2（N_idp = 2ΔkΔR/π）；加壳层用 `xafsmith ftest`，p < 0.05 才算显著。

## 5. 结构文件（structures/）

- 文件名（不含扩展名）即结构名：`xafsmith feff --structure Ta2O5.cif --absorber Ta --edge L3`
  → `output/feff/Ta2O5_TaL3/site<i>/`（每个不等价吸收位点一个目录）。
- 支持 CIF、POSCAR/CONTCAR/*.vasp、pymatgen JSON；内置结构可用 `xafsmith structures --export` 导出为 CIF。
- 在 `project.md` 记录每个结构文件的来源。

## 6. 输出文件约定

| 文件 | 内容 |
|---|---|
| `output/qc/qc_report.csv` | 每条扫描：E0、边跳、毛刺能量、I0 掉束、噪声、k_snr3、自吸收风险 |
| `output/calib/calib.json` | `{参比文件: {e0_meas, e_table, delta_e, ref_time, time_gap_hours, …}}` |
| `output/processed/process_summary.csv` | 每个样品：所用/剔除扫描、ref_file、dE_cal、E0、边跳、FT 峰 |
| `output/fits/exafs_fits.csv` | 一行一条路径：样品、模型、N、R、σ²、ΔE0、S0²、R 因子、χ²_ν、N_idp、变量数 |
| `output/fits/<模型>.fit_report.txt` | feffit 完整报告（含相关系数） |
| `*.params.json` | 每次运行的参数记录（工具名、时间、参数） |

## 7. 陈述规范

- 结论分三类：**实测**（数据直接可见）/ **拟合**（依赖模型）/ **推测**（需进一步实验）。
- R 空间图标注“未相移校正”；峰位不是键长。
- 理论值注明来源（xraydb Elam 表、FEFF6L）；不编造数据、误差或文献值。
