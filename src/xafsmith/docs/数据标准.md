# XAFSmith 数据标准（schema 1.1）

一个 **XAFSmith 项目** = 一个包含 `xafsmith.json` 的文件夹。所有命令、图形界面与 AI 助手都按下面的约定读写；
`xafsmith validate` 按本标准检查项目，`xafsmith new <目录>` 生成符合标准的空项目。

## 1. 目录结构

```
<项目>/
├── xafsmith.json        项目标识 + 处理参数（第 3 节）
├── project.md           体系信息与结论（人写）
├── AGENTS.md            给 AI 助手的入口说明（模板生成）
├── data/
│   ├── raw/<批次>/…     原始数据（只读）
│   └── meta.csv         数据登记表（第 2 节）
├── structures/          结构文件：CIF / POSCAR / CONTCAR / *.vasp / pymatgen JSON
├── models/              EXAFS 拟合模型 JSON（第 4 节）；文件名以 _ 开头的是模板，不检查
├── notes/               分析记录：YYYY-MM-DD_主题.md
├── scripts/             项目专用分析脚本（可选）
└── output/              全部生成结果（可删除后重新生成）
    ├── qc/              qc_report.csv
    ├── calib/           calib.json（按参比文件索引）
    ├── processed/       <样品>.nor / .chik / .chir、process_summary.csv
    ├── feff/            <结构>_<吸收原子><边>/site<i>/feff.inp、feffNNNN.dat（FEFF8L 结果目录名加 _feff8）
    ├── fits/            exafs_fits.csv、<模型>.fit_report.txt、<模型>.params.json
    ├── lcf/             lcf_results.csv
    ├── xanes/           xanes_features.csv、valence_<定义>.csv、preedge_<样品>.csv
    ├── figs/            16:9 汇报图（2666×1500，图注含处理参数）
    │   └── journal/     期刊风格图（.tiff/.png/.svg/.pdf + 英文图注 .txt）
    ├── reports/<主题>/  专题分析的报告、表格、图
    └── gui/             图形界面导出与会话参数；athena/ 为导出的 .prj
```

规则：
1. **原始数据只读。** 任何结果都可以从原始数据 + `xafsmith.json` + `meta.csv` + `models/` 重新生成。
2. **原始数据位置**：推荐 `data/raw/<批次>/`；也可以留在项目内其他位置，只要在 `meta.csv` 中用相对项目根目录的路径登记。
3. **批次** = 一次测量（同一机时、同一单色器状态）。每个批次文件夹应包含该批次测量的**单质参比**（金属箔/粉；
   文件名含 `foil` / `powder` / `metal` 时 `init` 自动识别为参比）。
4. 所有路径用**相对项目根目录**、正斜杠（如 `data/raw/2026_Ta/Ta_foil`、`output/feff/KTaO3_TaL3/site0/feff0001.dat`）。
5. 项目根目录的确定：`--project` 参数 / 环境变量 `XAFSMITH_PROJECT` → 当前目录向上查找 `xafsmith.json` → 当前目录。

## 2. data/meta.csv

UTF-8（带 BOM），每个原始文件一行。

| 列 | 必需 | 含义 |
|---|---|---|
| `file` | ✔ | 原始文件路径（相对项目根目录） |
| `sample` | ✔ | 样品名。**同名多行 = 同一样品的多次扫描，处理时合并**（异常扫描自动剔除并记录理由） |
| `edge_key` | ✔ | `<元素>_<边>`，如 `Ta_L3`、`Co_K`；对应 `xafsmith.json` 的 `edges` |
| `mode` | ✔ | `trans`（μ = ln(I0/I1)）或 `fluo`（μ = If/I0） |
| `role` | ✔ | `reference`（校准用单质参比）/ `standard`（标样）/ `sample` |
| `use` | ✔ | `1` 使用，`0` 不用（**必须在 note 写理由**） |
| `ref_file` | ✔ | 校准这条谱用的参比文件；`init` 自动填同批次、同吸收边的参比。**为空的谱不能处理** |
| `batch` | | 批次（`data/raw/` 下第一级文件夹名） |
| `time` | | 测量时间（文件头） |
| `npts`、`emax` | | 点数、末端能量 |
| `note` | | 备注 |
| `format` | | 读入格式：`bsrf` / `xdi` / `athena_xmu` / `xdac` / `prj` / `columns`，或 `xafsmith.json` 的 `formats` 中的模板名；**留空 = 自动识别**（`xafsmith formats` 列出） |
| `group` | | 多组文件（Athena `.prj`）中的组名；`init` 对 `.prj` 每组生成一行 |

`format`、`group` 是 schema 1.1 新增的可选列，没有这两列的旧项目照常使用。
读入时：**`mode` 以本表为准**；文件里同时有原始通道（I0/It/If）与 μ 列时，μ 一律由通道计算（透射 ln(I0/It)，荧光 If/I0），
只有通道不全才用文件的 μ 列。列按**名称**对应，不按列号。`init` 登记时，元素、吸收边、能量单位等凡是猜的，
都会写进 `note`，请核对。

命名规则：
- 新批次与已有批次重名的样品，`init` 自动加批次后缀（`KTaO3_20261105_Ta`），避免误合并。
- 编号被弄乱、或同名文件需要分开处理时，直接改 `sample` 列使每个文件独立。

## 3. xafsmith.json

```json
{
  "xafsmith": {"schema": "1.0"},
  "edges": {
    "Ta_L3": {
      "element": "Ta", "edge": "L3",
      "e_table": 9881.0, "e_table_source": "xraydb (Elam)",
      "elements_in_sample": ["Ta", "Ir", "O", "K"],
      "norm": {"pre1": -150, "pre2": -30, "norm1": 100, "norm2": -10, "nnorm": 2, "smooth_ev": 1.0},
      "bkg":  {"rbkg": 1.0, "kweight": 2},
      "ft":   {"kmin": 3.0, "kmax": 12.0, "dk": 1.0, "window": "hanning", "kweight": 2},
      "s02_recommended": {"value": 0.68, "err": 0.07, "source": "KTaO3 多壳层拟合"}
    }
  },
  "overrides":        {"样品名": {"norm": {"pre1": -70}, "ft": {"kmax": 10.5}}},
  "overrides_reason": {"样品名": "理由（必填）"},
  "deglitch":         {"样品名": [[E_lo, E_hi]]},
  "deglitch_reason":  {"样品名": "理由（必填）"},
  "instrument":       {"facility": "光源", "beamline": "线站", "monochromator": "单色器", "detection": "探测方式 / 探测器"},
  "formats":          {"BL14W1_fluo": {"base": "columns", "energy": "Energy", "i0": "I0", "if": ["Ch1", "Ch2"], "mode": "fluo"}}
}
```

- 每个吸收边一套参数，**同一边的所有样品用同一套参数**；个别样品必须改时写进 `overrides` 并给理由。
- `overrides.<样品>.elements_in_sample`（可选）：该样品实际含有的元素，**只用于干扰边 / k 上限检查**，不改变处理结果。用于一个吸收边下各样品组成不同的情况（如 Ir L3 下只有部分样品含 Ta）；同样要在 `overrides_reason` 写理由。
- `norm2 ≤ 0` 表示距数据末端的距离（eV）。
- E0 统一取一阶导数最大值。
- `deglitch` 的能量为**校准后**能量；只删处理副本中的点。
- `formats`（可选）：保存的列映射模板，名字可写进 meta.csv 的 `format` 列；`base` 为 reader 名（通常 `columns`），其余键把角色（energy / i0 / it / if / mu）指到列名或从 0 开始的列号，`if` 可给多个通道（求和）。
- `instrument`（可选）只用于生成“方法”段落（汇总报告页底部或 `xafsmith methods`）；未填的项在段落中显示为【】占位，需人工补全。

## 4. 拟合模型（models/<名称>.json）

```json
{
  "name": "KTaO3_2shell",
  "sample": "KTaO3",
  "kmin": 3, "kmax": 13, "dk": 1, "window": "hanning", "kweight": [1, 2, 3],
  "rmin": 1.0, "rmax": 4.0, "fitspace": "r",
  "params": {
    "s02": {"value": 0.68, "vary": false},
    "e0":  {"value": 0, "vary": true, "min": -15, "max": 15},
    "dr1": 0.0,
    "ss1": {"value": 0.005, "vary": true, "min": 0.0005, "max": 0.03},
    "ssT": 0.006
  },
  "paths": [
    {"file": "output/feff/KTaO3_TaL3/site0/feff0001.dat", "label": "Ta-O",  "deltar": "dr1",   "sigma2": "ss1"},
    {"file": "output/feff/KTaO3_TaL3/site0/feff0004.dat", "label": "Ta-Ta", "deltar": "2*dr1", "sigma2": "ssT", "N": "6"}
  ]
}
```

| 写法 | 含义 |
|---|---|
| `"dr1": 0.0` | 数字：自由变化，初值 0 |
| `{"value": .., "vary": false}` | 固定 |
| `{"value": .., "vary": true, "min": .., "max": ..}` | 自由变化，有界 |
| `{"expr": "ss1*1.5"}` 或直接写字符串 `"ss1*1.5"` | 约束（由其他参数计算） |
| 路径 `"N": "6"` / `"N": "n1"` | 固定配位数 / 配位数作为参数（替换 FEFF 简并度） |
| 路径中 `s02`、`e0`、`deltar`、`sigma2`、`third` | 参数名或表达式；可用 `reff`、`degen` |

- `sample` 必须是 `meta.csv` 中的样品名；数据处理参数自动取自 `xafsmith.json`。
- 同一 `label` 可用于多条路径（自动加文件号区分）。
- 变量数 ≤ N_idp/2（N_idp = 2ΔkΔR/π）；加壳层用 `xafsmith ftest`，p < 0.05 才算显著。

### 4.1 多数据集同时拟合（`datasets`）

多个数据集（不同样品、不同温度、同一样品不同 k 范围等）共用一套参数同时拟合。有 `datasets` 键 = 多数据集模型；没有 = 上面的旧格式（原样可跑，含义不变）。

```json
{
  "name": "Cu_joint_demo",
  "kmin": 3, "kmax": 17, "dk": 4, "window": "kaiser", "kweight": 2, "rmin": 1.4, "rmax": 3.0, "fitspace": "r",
  "params": {"amp": 1.0, "del_e0": 0.0, "del_r": 0.0, "ssA": 0.005, "ssB": 0.005},
  "datasets": [
    {"id": "A", "sample": "cu_10K",
     "paths": [{"file": "output/feff/Cu/site0/feff0001.dat", "label": "Cu-Cu", "s02": "amp", "e0": "del_e0", "deltar": "del_r", "sigma2": "ssA"}]},
    {"id": "B", "sample": "cu_300K", "kmax": 14, "epsilon_k": 0.002,
     "paths": [{"file": "output/feff/Cu/site0/feff0001.dat", "label": "Cu-Cu", "s02": "amp", "e0": "del_e0", "deltar": "del_r", "sigma2": "ssB"}]}
  ]
}
```

- `params` 只有一份，所有数据集共用一个命名空间：共享的参数写同一个名字，各自的参数用不同名字（如 `e0_Ir`、`e0_Ta`）。不会自动加后缀。
- 每个数据集：`sample`（必填，meta.csv 样品名）；`paths`（必填，非空，写法同旧格式）；`id`（可选，缺省 = `sample`，模型内唯一，用于结果表与图文件名）；
  `kmin kmax dk window kweight rmin rmax fitspace`（可选，覆盖顶层）；`epsilon_k`（可选，正数，χ(k) 的噪声；缺省由 larch 从 R 15–25 Å 估计）。
- 取值顺序：数据集自己的值 → 顶层值 → 内置默认（`dk` 1、`window` hanning、`fitspace` r）。合并后 `kmin kmax rmin rmax kweight` 必须有值。
- 多数据集模型不得再有顶层 `sample` 或 `paths`。
- 统计：残差按数据集拼接，每个数据集的残差已除以自己的噪声 ε，噪声小的数据集权重大。合计 N_idp = Σ 各数据集 N_idp；R 因子、χ²、χ²_ν 为合计值；
  **所有参数的误差按合计 χ²_ν 统一缩放**——某个数据集失配大，会放大全部参数（包括只属于其他数据集的参数）的误差，此时会有警告。
  逐数据集报告 N_idp、R 因子、χ² 与 χ² 占比（不报逐数据集 χ²_ν：变量是共享的，无法分摊）。
- 同一数据当作两个数据集联合拟合，误差会被低估（同一噪声计入两次）——会有警告；不要用这种方式“缩小误差”。
- 运行：`xafsmith fit 模型名`；图形界面见使用指南“多数据集联合拟合”。

### 4.2 软约束（`restraints`）

把参数（或参数的表达式）拉向一个有独立来源的先验值。旧格式与多数据集格式都可以在模型顶层写 `restraints`；缺省或 `[]` = 没有软约束，此时拟合与 B3 之前逐位相同。
术语：**软约束（restraint）** 是加在 χ² 上的惩罚项；参数的 `expr` 是**硬约束**（等式），两者不要混用。

```json
"restraints": [
  {"name": "s02_IrO2", "expr": "amp", "value": 0.816, "sigma": 0.05, "note": "IrO2 标样拟合（IrO2_1shell_ArtemisCompare）"},
  {"name": "ss_diff",  "expr": "ssA - ssB", "value": -0.004, "sigma": 0.001}
]
```

- 每项：`expr`（必填，非空字符串，参数表达式，只能引用 `params` 里的名字）、`value`（必填，有限数字）、`sigma`（必填，有限数字且 > 0）、
  `name`（可选，缺省 `r1`、`r2`…按位置；模型内唯一）、`note`（可选，只做记录）。
- 含义：χ² 加上 c₀·tⱼ²，tⱼ = (expr − value)/sigma（偏离，pull）。**c₀ = 同一模型去掉软约束后的 χ²_ν**（先做一次无约束预拟合得到）。
  理由：larch 的数据 χ² 通常远大于 N_idp（噪声 ε 估计偏小，Cu 箔 χ²_ν ≈ 10），报告的参数误差已乘 √χ²_ν；约束项若不乘 c₀，
  先验 0.80 ± 0.01 的实际宽度会变成约 0.032，悄悄比写的弱 3 倍。乘 c₀ 后 **sigma 与 XAFSmith 报告的参数误差是同一尺度**，
  可以直接填标样拟合报告的“值 ± 误差”。（不声称与 Artemis / ifeffit 的写法等价。）
- 软约束**不增加 N_idp**，变量数规则（≤ N_idp/2）不变；R 因子只计数据残差；多数据集时 Σ chi2_i + restraint_chi2 = chi2。
- 结果：摘要多 `restraints`（每项 name、expr、value、sigma、fitted、pull、chi2 = c₀·pull²）、`restraint_chi2`、`restraint_c0`、`chi2_data`；
  CSV 多 `restraint_chi2`、`restraint_c0`、`restraints`（JSON `{name: [拟合值, 先验值, sigma, pull]}`）三列（没有软约束的行列不变）；
  |pull| > 2 给警告（数据与先验矛盾）。
- 比较模型：软约束不同的两个模型，χ² 含不同的约束项，F 检验不适用（`xafsmith ftest` 会提示）。
- 只出现在软约束里、不被任何路径或参数表达式用到的变量，larch 会把它固定，软约束对它不起作用（校验给警告）。

### 校验规则（`xafsmith validate`）

**错误** = 流程会崩溃或会悄悄算错，必须改；**警告** = 能运行，但违反本标准或可能不物理，需确认。每条结果都指向文件与位置（JSON 解析失败给出“第 N 行第 M 列”，meta.csv 给出行号与列名）。

| 对象 | 错误 | 警告 |
|---|---|---|
| xafsmith.json | JSON 语法；缺必填字段；参数不是数字（`ft.kweight` 可为数字列表）；窗函数名无法识别；`kmin ≥ kmax`、`kmin < 0`、`dk < 0`；`pre1 ≥ pre2`；`norm2 > 0` 时 `norm1 ≥ norm2`；`rbkg ≤ 0`；overrides / deglitch 无理由 | `pre2 > 0`；`norm1 ≤ 0`；`rbkg > 1.5 Å`；`bkg.kweight` 不在 0–3；缺 `elements_in_sample`；**`ft.kmax` 超过可用 k 上限**；**其他吸收边落在 [E0+pre1, E0)**（如 Ir L3 前 79 eV 的 Ta L2） |
| meta.csv | 缺必填列；`file / sample / edge_key` 为空；同一 (file, group) 重复登记；原始文件不存在；role / mode / use / format 取值非法；use=0 无理由；无参比；同名样品跨吸收边 | `npts / emax` 不是数字；吸收边不在 xafsmith.json；ref_file 不是 reference；同名样品混合透射与荧光 |
| 模型 JSON | JSON 语法；缺必填字段；k / R 范围非数字、为负或颠倒；`kweight`、`window`、`params`、`paths` 结构不对；**变量数 ≥ N_idp** | 样品不在 meta.csv；FEFF 路径文件不存在；**变量数 > N_idp/2**；**`kmax` 超过可用 k 上限** |
| 软约束（4.2，旧格式与多数据集共用） | `restraints` 不是数组；元素不是对象；缺 `expr` / `value` / `sigma`；`expr` 为空或无法解析；`value`、`sigma` 非有限数字或 `sigma ≤ 0`；`name` 为空或重复；`expr` 引用 `params` 里没有的名字或一个参数都没引用 | `expr` 只涉及固定参数（不起作用）；引用的变量不在任何路径中（larch 会把它固定） |
| 多数据集模型（4.1） | 必填 `name params datasets`；`datasets` 不是非空数组或元素不是对象；数据集缺 `sample` / `paths`；合并后缺 `kmin kmax rmin rmax kweight`；（每个数据集）范围、`kweight`、`window`、`paths` 同上；`id` 重复（含缺省 id = sample 造成的重复）或为空；同时有顶层 `sample` 或 `paths`；`epsilon_k` 不是正数；**变量数 ≥ Σ N_idp** | **变量数 > Σ N_idp/2**（全部数据集合计）；同一样品用于多个数据集；各数据集 `fitspace` 不同；（每个数据集）样品不在 meta.csv、FEFF 文件不存在、`kmax` 超过可用上限 |

- 可用 k 上限 = min(数据末端 k, 第一个干扰边 k − 0.3 Å⁻¹)，同 `xafsmith kcheck`；数据末端取参与合并的扫描（能量跨度不到最长扫描 90% 的短扫描不参与合并，也不计入）。
- 干扰边检查按样品的 `elements_in_sample`（`overrides` 优先）；同一边、同一原因的样品合并成一条警告。
- N_idp 在校验中按 2ΔkΔR/π 估算；拟合时报告的 N_idp 来自 larch，两者可能略有差别。

## 5. 结构文件（structures/）

- 文件名（不含扩展名）即结构名：`xafsmith feff --structure Ta2O5.cif --absorber Ta --edge L3`
  → `output/feff/Ta2O5_TaL3/site<i>/`（每个不等价吸收位点一个目录）。
- 支持 CIF、POSCAR/CONTCAR/*.vasp、pymatgen JSON；内置结构可用 `xafsmith structures --export` 导出为 CIF。
- 在 `project.md` 记录每个结构文件的来源。

## 6. 输出文件约定

| 文件 | 内容 |
|---|---|
| `output/qc/qc_report.csv` | 每条扫描：E0、边跳、毛刺能量、I0 掉束、噪声、k_snr3、自吸收风险 |
| `output/calib/calib.json` | `{参比文件: {e0_meas, e_table, delta_e, ref_time, time_gap_hours, …}}` |
| `output/processed/process_summary.csv` | 每个样品：所用/剔除扫描、ref_file、dE_cal、E0、边跳、FT 峰 |
| `output/fits/exafs_fits.csv` | 一行一条路径：样品、模型、N、R、σ²、ΔE0、S0²、R 因子、χ²_ν、N_idp、变量数。多数据集拟合另有 `dataset`、`n_datasets`、`rfactor_dataset`、`n_idp_dataset`、`chi2_share` 列；`sample`、`k_range`、`R_range`、`kweight` 取该行所属数据集，`rfactor`、`chi2_reduced`、`n_idp`、`nvarys` 为联合值 |
| `output/figs/<模型>_<id>_fit.png` | 多数据集拟合：每个数据集一张拟合图（图注另起一行给联合拟合的总 R 因子与总 N_idp） |
| `output/fits/<模型>.fit_report.txt` | feffit 完整报告（含相关系数） |
| `*.params.json` | 每次运行的参数记录（工具名、时间、参数） |

## 7. 陈述规范

- 结论分三类：**实测**（数据直接可见）/ **拟合**（依赖模型）/ **推测**（需进一步实验）。
- R 空间图标注“未相移校正”；峰位不是键长。
- 理论值注明来源（xraydb Elam 表、FEFF6L 或 FEFF8L）；不编造数据、误差或文献值。
