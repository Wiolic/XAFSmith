## 一、整体图景

### 0.1　XAFS 测的是什么

X 射线能量扫过某元素的吸收边（如 Ir L₃ ≈ 11215 eV）时，吸收系数 μ(E) 突然升高：内层电子被打出，成为**光电子**。吸收边附近的谱分成两段：

| 区域 | 能量范围 | 反映什么 | 看什么 |
|---|---|---|---|
| **XANES** | 边前到边后约 50 eV | 价态、配位对称性 | 边的位置、白线强度、边前峰 |
| **EXAFS** | 边后约 50–1000 eV | 周围原子的种类、数量、距离、无序度 | 振荡的频率、幅度、形状 |

EXAFS 振荡的来历：光电子波向外传播，被周围原子反射回来，与出射波干涉，使 μ(E) 出现小幅振荡。

- **频率** ← 到邻近原子的**距离 R**；
- **幅度** ← 邻近原子的**数量 N** 和**无序度 σ²**；
- **形状**（振幅、相位随 k 的变化）← 邻近原子**是什么元素**。

所以 EXAFS 拟合回答的问题是：**吸收原子周围几 Å 内，有几个什么原子、在多远、有多乱。**

### 0.2　EXAFS 方程

拟合用的就是这个方程：

$$\chi(k)=\sum_j S_0^2\,N_j\,\frac{|f_j(k)|}{k R_j^2}\,e^{-2k^2\sigma_j^2}\,e^{-2R_j/\lambda(k)}\,\sin\left[2kR_j+\delta_j(k)\right]$$

| 符号 | 含义 | 由谁提供 |
|---|---|---|
| $k$ | 光电子波矢，$k=\sqrt{0.2625\,(E-E_0)}$，单位 Å⁻¹（E 以 eV 计） | 由数据换算 |
| $N_j$ | 第 j 条路径（壳层）的配位数 | **拟合**或固定 |
| $R_j$ | 距离，$R_j = R_{\mathrm{FEFF}} + \Delta R$ | **拟合 ΔR** |
| $\sigma_j^2$ | 距离分布的方差（热振动 + 结构无序），即 Debye–Waller 因子 | **拟合** |
| $S_0^2$ | 被动电子振幅衰减因子，通常 0.7–1.0 | **用标样定**，样品中固定 |
| $\Delta E_0$ | 理论计算与实验之间的能量零点差 | **拟合**，同一样品各路径通常共用 |
| $f_j(k)$、$\delta_j(k)$、$\lambda(k)$ | 散射振幅、相移、平均自由程 | **FEFF** 由结构算出 |

一句话：**FEFF 提供“散射原子长什么样”，实验数据确定 N、ΔR、σ²、ΔE₀、S0²。**

方程里有两项决定了后面的很多做法：

- $e^{-2k^2\sigma^2}$：振荡随 k 衰减，σ² 越大衰减越快。高 k 处信号迟早被噪声淹没，这决定了可用的 k 上限。
- $S_0^2 N_j$：两者相乘，同一组数据分不开。所以 S0² 要先在已知 N 的标样上确定（第 9 章）。

## 二、准备数据

### 1　建项目、登记数据

**原理**

原始数据**只读**，每一步结果都能从原始数据重新生成，这样结果才可重复。登记表 `meta.csv` 记录每个文件是什么：哪个样品、哪个吸收边、透射还是荧光、用哪个参比校准、是否使用。后面所有步骤都按它来。

**操作**

1. 左上角 **打开 / 新建项目** → **浏览…** 选一个空文件夹 → **新建项目**。
2. **数据登记** 页：
   - 填批次名，如 `2026-11-05_Ir`；
   - 点 **选择文件，复制到批次并登记…**，选中这次测的全部文件。**必须包含同一批测的金属箔或金属粉**（参比）。
3. 检查登记表：

| 列 | 怎么填 |
|---|---|
| sample | 同名的行 = 同一样品的多次扫描，会被合并 |
| role | 参比 `reference`，已知结构的标样 `standard`，未知样品 `sample` |
| use | 不用的扫描设 `0`，并在 note 写原因 |

4. 点 **保存 meta.csv**，再点 **运行检查**，直到 0 个错误。

**检查**：每个样品的 `ref_file` 都不为空；检查结果为 0 个错误。

### 2　质量检查：这份数据能回答什么

**原理**

拟合之前必须先判断数据质量。坏数据拟合出的数字一样“好看”，但没有意义。常见问题：

| 问题 | 来源 | 后果 |
|---|---|---|
| 毛刺（glitch） | 单色器晶体在某个能量多重衍射，或突然掉束（I0 骤降） | k 空间出现尖刺，傅里叶变换后污染整个 R 空间 |
| 噪声 | EXAFS 振荡按 $e^{-2k^2\sigma^2}$ 衰减，高 k 被噪声淹没 | 决定可用的 **k 上限** |
| 边跳不合适 | 透射样品太薄或太厚 | Δμt 太小信噪比差；总 μt > 3 出现非线性，振幅被压低 |
| 荧光自吸收 | 浓样品用荧光模式测量 | 振幅和白线被压低（实测可低约 25%），不能和透射谱直接比较 |
| 干扰吸收边 | 其他元素（或本元素 L₂ 边）落在扫描范围内 | k 范围必须在它之前截止 |

**操作**

1. **校准与处理 → ① 质量检查**（或 **载入与检查 → 质量检查** 标签）。
2. 看这些列：

| 列 | 含义 |
|---|---|
| glitch_E | 毛刺位置 |
| i0_drops | 掉束 |
| edge_step_mu | 边跳 |
| k_snr3 | 信号降到 3 倍噪声时的 k，可作 kmax 的参考 |
| self_abs_risk | 荧光自吸收风险 |

3. 到 **χ(k) 与 FT → k 范围检查** 标签，看干扰吸收边给出的 k 上限。
4. 有毛刺：在 **质量检查** 标签下方 **去毛刺**，或在登记表把这条扫描设为 `use = 0`。

**检查**：知道每条谱可以用到多高的 k；有毛刺或掉束的扫描已剔除或去毛刺。

### 3　能量校准

**原理**

单色器的角度–能量对应关系会漂移零点几到几个 eV。金属箔的边位置是已知常数（表值，来源 xraydb）。所以：

1. 测出参比的边位置 $E_{0,\mathrm{meas}}$（一阶导数最大值）；
2. 校正量 $\Delta E = E_{\mathrm{table}} - E_{0,\mathrm{meas}}$；
3. 给**同一批测的所有谱**加**同一个** ΔE。

为什么不给每个样品各自校准？样品的边位置本身就包含化学信息（价态越高，边越往高能移）。如果把每个样品都“校准”到表值，这个信息就被抹掉了。

**操作**：**校准与处理 → ② 按参比校准**。结果在 **载入与检查 → 能量校准** 标签查看，每个参比一个 ΔE。

**检查**：ΔE 一般在几个 eV 以内；同一机时的几个参比给出的 ΔE 应当接近。

### 4　归一化

**原理**

原始 μ(E) 的大小取决于样品厚度、浓度和探测器增益，彼此不能比较。归一化把谱缩放成“边前 = 0、边跳 = 1”：

1. 边前区（例如 E₀−150 到 E₀−30 eV）拟合一条直线并扣除；
2. 边后区（例如 E₀+100 eV 到末端）拟合一条二次多项式，它在 E₀ 处的值就是**边跳**；
3. 用边跳去除。

E₀ 取一阶导数最大值，全项目统一用这一种定义。

**操作**：参数在 **校准与处理 → 处理参数**（每个吸收边一套，同一边的所有样品共用）。在 **归一化** 页的“μ(E) 与边前 / 边后”标签查看。

**检查**

- 边前线贴着边前数据，边后线从数据中间穿过，没有系统性偏离；
- 归一化后边后区在 1 附近平稳振荡；
- **同一边的所有样品用同一套参数**，不能为了让某个样品“好看”单独调。

### 5　扣背景，得到 χ(k)

**原理**

EXAFS 信号定义为

$$\chi(E)=\frac{\mu(E)-\mu_0(E)}{\Delta\mu_0(E_0)}$$

$\mu_0(E)$ 是“孤立原子”的光滑吸收背景，无法测量，只能用一条光滑样条曲线逼近。Larch 的 AUTOBK 方法用参数 **rbkg** 控制背景有多“软”：

| rbkg | 结果 |
|---|---|
| 约为第一壳层 FT 峰位的一半，常用 **1.0 Å** | 合适 |
| 太大 | 样条吃掉第一壳层，振幅变小 |
| 太小 | 低 R 区残留背景，出现 R < 1 Å 的假峰 |

然后把能量换成 $k=\sqrt{0.2625\,(E-E_0)}$。高 k 处振荡衰减，通常乘以 $k^2$ 或 $k^3$ 来放大。

**操作**

1. **校准与处理 → ③ 处理全部样品**。
2. **载入与检查 → 载入谱**：勾选样品，点 **载入**。
3. **χ(k) 与 FT** 页，看“χ(k)”和“背景 μ0(E)”标签。

**检查**：$k^2\chi(k)$ 围绕 0 振荡，没有整体倾斜或缓慢起伏；高 k 端噪声开始占主导的位置，就是 kmax 的候选值。

### 6　傅里叶变换：从 χ(k) 到 χ(R)

**原理**

χ(k) 是多个正弦波的叠加，每个壳层一个频率 $2R_j$。傅里叶变换按距离把它们分开，得到“径向分布”式的 |χ(R)|。

| 要点 | 说明 |
|---|---|
| k 范围 | kmin 通常 2–3 Å⁻¹，避开 XANES 区；kmax 由噪声和干扰边决定 |
| 窗函数 | Hanning，过渡宽度 dk：让数据两端平滑降到 0，减少截断旁瓣 |
| 分辨率 | 两个壳层的距离差要大于 $\Delta R \approx \pi/(2\Delta k)$ 才能分开；k = 3–12 时约 0.17 Å。**分辨率只由 Δk 决定** |
| 峰位不是键长 | 散射相移使峰比真实距离**短约 0.3–0.5 Å**（R 轴标“未相移校正”）；键长只能从拟合得到 |
| 一个峰 ≠ 一个壳层 | 峰可能来自噪声、背景残留、窗函数旁瓣或多重散射 |

**操作**

1. **χ(k) 与 FT** 页，在“|χ(R)| / Re”标签同时看 |χ(R)| 和实部 Re χ(R)。
2. k 权重 1、2、3 各看一遍：轻散射体（O）在低 k 更强，重散射体（Ir、Ta）在高 k 更强，峰的相对高度会随权重变化——这本身就是区分散射体的线索。
3. 需要时到 **小波变换** 页同时看 k 和 R：重原子的强度中心在较高 k；可选两条谱左右对比。

**检查**：选定了 kmin、kmax 并记录；同一边的样品使用同一 k 范围。

## 三、拟合

### 7　能拟合几个参数：独立点数 N_idp

**原理**

数据里能独立确定的信息量是有限的（Nyquist 定理）：

$$N_{\mathrm{idp}}=\frac{2\,\Delta k\,\Delta R}{\pi}$$

Δk 是 k 拟合范围，ΔR 是 R 拟合窗口。

**例**：k = 3–12.5 Å⁻¹，R = 1.0–2.5 Å，则 N_idp = 2 × 9.5 × 1.5 / π ≈ 9.1。

**规则**：变量数 ≤ N_idp/2（宽松一点可到 N_idp − 3）。参数比信息多时，任何模型都能“拟合得很好”，但结果没有意义。

**操作**：**EXAFS 拟合** 页左栏设好拟合范围后，页面直接显示 N_idp 和变量数上限；变量数超过上限时变成橙色。

### 8　FEFF：从结构计算散射路径

**原理**

方程里的 $f(k)$、$\delta(k)$、$\lambda(k)$ 无法从数据得到，要从一个**结构模型**出发，用 FEFF 做多重散射计算。FEFF 列出光电子从吸收原子出发、被散射后回到吸收原子的所有**路径**：

| 路径 | 说明 |
|---|---|
| 单散射 | 吸收原子 → 邻近原子 → 回来。路径长度 = 2R，简并度 = 该距离上的原子数 |
| 多重散射 | 经过两个或更多原子，如共线的 M–O–M；在外壳层中可能很强 |

FEFF 给出的 R 是**起点**：拟合时允许 ΔR 小幅调整；配位数可固定为简并度，也可拟合。结构不必和样品完全相同，只要局域环境类似，例如用 KTaO₃ 的 Ta–O 路径拟合无定形 TaOx 的第一壳层。

**操作**（**FEFF 路径** 页）

1. 结构来源选 **内置结构** → `IrO2`（自己的结构：选 structures/ 文件夹，点 **添加结构文件…**）。
2. 吸收原子 `Ir`，吸收边 `L3`，RMAX 6 Å。
3. FEFF 版本先用 **FEFF6L**，点 **运行 FEFF**。

**检查**：路径表中 IrO₂ 的前两条是 Ir–O：2 个 1.958 Å、4 个 1.996 Å，与金红石结构一致。

> FEFF8L（自洽势）的 ΔE₀ 通常更接近 0，但零点与 FEFF6L 不同。同一组样品用同一个 FEFF 版本。

### 9　用标样确定 S0²

**原理**

S0² 与 N 在方程中相乘，同一组数据分不开。办法是：

1. 先用**结构已知的标样**（N 已知）拟合出 S0²；
2. 再把它**固定**用于未知样品，从而拟合 N。

S0² 主要取决于吸收元素和吸收边，与化学环境关系不大，同一元素同一边可以通用；但测量条件要可比（同为透射，样品厚度合适）。

**操作**（**EXAFS 拟合** 页，IrO₂ 为例）

左栏依次设置：

1. **数据与 FEFF**：数据选 IrO₂，FEFF 目录选刚才算的 `IrO2_IrL3`。
2. **拟合范围**：kmin 3，kmax 12.5，dk 1，k 权重 **1、2、3 同时勾选**，Rmin 1.0，Rmax 2.5，拟合空间 `r`。
3. **路径**：勾选两条 Ir–O 路径。
   - `N` 保持 FEFF 简并度（2 和 4，固定为结构值）；
   - 两条路径的 `deltar` 都填 `dr1`，`sigma2` 都填 `ss1`：两组距离相近，作为“一个壳层”共用参数，减少变量。
4. **参数**：`s02`、`e0`、`dr1`、`ss1` 都勾选 vary。共 4 个变量，N_idp ≈ 9.1，满足 ≤ N_idp/2。
5. 点左下角 **拟合**（或 Ctrl+Enter），结果显示在右栏。

作者项目中的实际结果：**S0² ≈ 0.82，ΔE₀ ≈ 8.9 eV**（Ir L₃，透射）。

6. 把 S0² 填到 **校准与处理 → 处理参数 → S0²**，点 **保存参数**；在 EXAFS 拟合页点 **保存结果**。

**为什么同时用 k¹、k²、k³**：不同权重对低 k（轻原子、ΔE₀）和高 k（σ²、重原子）的敏感度不同。三者一起拟合，能减弱 S0²–σ²、ΔE₀–ΔR 之间的相关性。

**调参时的小技巧**：拟合后点右栏的 **采纳拟合值到参数**，把这次的结果作为下次的初值；改动参数后再点 **拟合**。整个过程不用上下翻页。

### 10　拟合未知样品

**原理**：从简单到复杂，逐步加壳层。

1. **第一壳层**（最近邻，如 M–O）：S0² 固定为标样值；N、ΔR、σ²、ΔE₀ 自由，共 4 个变量。
2. 看残差：第二个峰（如 M–M）没有被拟合，再加一个壳层。新壳层通常增加 N、ΔR、σ² 共 3 个变量，ΔE₀ 一般共用。
3. 每加一层都要检查 N_idp 是否够用，并做 F 检验（第 12 章）。

**操作**

1. **EXAFS 拟合** 左栏：选样品数据和对应的 FEFF 目录。
2. **路径**：要拟合配位数的路径，`N` 列改成参数名，如 `n1`。
   - 同一壳层的路径都写 `n1` = 共用；
   - 某条路径的 N 应是另一条的固定倍数时，写 `n1*2`。
3. **参数**：

| 要做的事 | 怎么填 |
|---|---|
| 固定 S0² | `s02` 取消 vary，value 填标样值（如 0.82） |
| 两个壳层 σ² 相同 | `ss2` 的 expr 填 `ss1` |
| 多重散射路径与单散射绑定 | 共线 M–O–M 路径的 `deltar` 填 `dr2`、`sigma2` 填 `ss2`，与对应的 M–M 路径相同 |
| 给参数设物理范围 | min / max，例如 σ² ≥ 0 |

4. 点 **拟合**；满意后点 **保存结果**：结果写入 `output/fits/exafs_fits.csv`，模型存入 `models/`，以后可一键重跑。
5. 一组样品（时间、电位序列）：左栏顶部 **运行已保存的模型** → 选模型 → 多选样品 → **运行**。

### 11　判断拟合好不好

**原理**：拟合曲线“看起来贴合”不够，要同时满足数值、图和物理意义三方面的要求。

**操作**：看右栏的 **质量检查** 标签（自动逐条打 ✓ / ⚠），以及右上角 **注意事项与“拟合得好”的标准**。

**数值标准**

| 指标 | 含义 | 参考范围 |
|---|---|---|
| R 因子 | 拟合与数据的相对差异 | < 0.02 很好；0.02–0.05 第一壳层可接受 |
| 残差 / 噪声 | 诊断标签中给出 | ≈ 1–2 已到数据极限；明显大于 2 说明还有系统偏差 |
| χ²_ν | 约化卡方，取决于噪声估计 | 只用于**同一数据**的不同模型之间比较 |
| ΔE₀ | 能量零点差 | \|ΔE₀\| ≤ 10 eV；超过时检查 E₀ 定义或模型 |
| σ² | 无序度 | 正值；室温第一壳层多为 0.002–0.010 Å² |
| S0²（标样） | | 0.6–1.1 |
| N | 配位数 | 误差常有 ±10–25%，报告时带误差 |
| 误差 | 来自协方差矩阵（已按 χ²_ν 修正） | 误差大于数值本身 = 该参数没被数据确定 |

**看图**

- |χ(R)| 和 **Re χ(R)** 都要贴合；只贴合模量不够，相位不对的拟合模量也可能很贴；
- k 空间拟合曲线要与数据同相位；残差不集中在某一段。

**参数相关性**

- ΔE₀ 与 ΔR 强相关（都改变相位），N 与 σ² 强相关（都改变振幅）；
- 完整报告标签末尾列出相关系数，|r| > 0.9 的参数对要在结论中说明；
- 所以键长差 < 0.02 Å 的结论要谨慎；比较不同样品的 N 时，用相同 k 范围、相同 S0²。

### 12　稳健性与 F 检验

**稳健性**

- **原理**：好的结论不应依赖某个特定的拟合范围。
- **操作**：右栏 **稳健性** 标签 → **运行稳健性检查**。软件依次改变 kmin ±0.5、kmax ±1、Rmax ±0.2 Å，并单独用 k¹ / k² / k³ 重复拟合。
- **判读**：变化超过统计误差的参数标为“不稳”，应以范围报告，或简化模型。

**F 检验：加不加壳层**

- **原理**：增加参数总会让 R 因子变小，哪怕新加的是噪声。Hamilton F 检验判断 R 因子的下降，是否超过“多了几个参数”本该带来的改善。
- **操作**：**拟合历史** → 选“简单模型”和“复杂模型”（复杂模型必须是在简单模型上增加参数）→ **比较**。
- **判读**：

| p 值 | 结论 |
|---|---|
| p < 0.05 | 新壳层显著，可报告为“拟合中包含该壳层，且显著” |
| p ≥ 0.05 | 不能说“观察到”该壳层，只能说“数据不排除” |

轻散射体（O、K）挨着重元素壳层时尤其难确定，需要小波变换、不同 k 权重，或其他表征（XRD、XPS、成分分析）独立佐证。

## 四、其他分析与汇报

### 13　XANES 线性组合拟合（LCF，可选）

**原理**：如果样品是几种已知物相的混合，它的归一化 XANES 约等于各标样谱的加权和，权重即各物相的比例（按吸收原子计）。

**操作**：**LCF** 页：

1. 选样品和端点标样（**必须是实测标样**）；
2. 能量范围常用 E₀−20 到 E₀+60 eV，空间选归一化 μ；
3. 点 **LCF**。软件同时给出“只用单一标样”的拟合作为对照。

**检查**

- 权重之和接近 1；
- 多标样拟合的 R 因子明显低于单一标样拟合；
- 漏掉某个物相时，结果会系统性地偏。

边位置、价态标定和边前峰拟合，见图形界面使用指南的 **XANES 定量**。

### 14　导出与写结论

**导出**

| 需要 | 页面 |
|---|---|
| 全部结果：Excel 工作簿 + 带图的 HTML 报告 | **报告导出** → 生成报告 |
| 论文图，或直接导出 Origin 文件（.opju） | **图片导出** |
| 中英文“方法”段落、补充材料的拟合参数表 | **方法导出** |

**论文中要报告的内容**

- k 范围、R 范围、k 权重、窗函数；
- N_idp 和变量数；
- S0² 及其来源（哪个标样）；
- 每个壳层的 N、R、σ²，以及 ΔE₀ 和 R 因子，均带误差。

**三种陈述要分开**

| 类型 | 例子 | 依据 |
|---|---|---|
| **实测** | “样品的白线强度比 IrO₂ 低”；“2.8–3.5 Å 处的 FT 峰随时间减弱” | 谱图上直接可见（注明“未相移校正”） |
| **拟合结果** | “Ir–O 配位数 5.6 ± 0.6，键长 1.98 ± 0.01 Å”（示意数值） | 依赖所选模型、S0² 和 k 范围 |
| **推测** | “表面形成了无定形 IrOx” | 需要多个指标共同支撑，或其他实验证实 |

### 15　新手常见错误

| 错误 | 正确做法 |
|---|---|
| 没看 χ(k) 和噪声就直接拟合 | 先完成第 2 章和第 5 章 |
| 每个样品用不同的归一化或背景参数 | 同一边的样品必须统一 |
| 把 FT 峰位直接当作键长 | 峰位未做相移校正，键长看拟合结果 |
| 让 S0² 和 N 同时自由变化 | 两者完全相关，S0² 先由标样确定 |
| 变量数超过 N_idp/2 | 减少壳层，或共用 σ²、ΔE₀ |
| 只看 \|χ(R)\| 不看 Re χ(R) | 两者都要贴合 |
| 把荧光谱和透射谱的振幅直接比较 | 自吸收会压低振幅，用桥接标样 |
| 不做 F 检验就宣称看到了外壳层 | 见第 12 章 |
| ΔE₀ 超过 ±10 eV 仍接受结果 | 检查 E₀、校准和模型 |
| 只用本软件的结果 | **用 Athena / Artemis 对关键结果做一次独立对比** |
