# 零基础 EXAFS 拟合教程：每一步做什么、为什么

> ⚠️ **免责声明**：本软件按“现状”提供，作者不对使用本软件得到的结果负责。请自行核验，**建议把关键结果与 Athena / Artemis 的结果对比**。
> 📖 **引用**：论文中使用本软件，请引用 Eggy & Claude. XAFSmith, https://github.com/Wiolic/XAFSmith ，并同时引用 Larch 与 FEFF。

本教程面向**第一次做 EXAFS 拟合**的人：不需要编程，也不需要输入命令，只要会点鼠标。
每一步分三部分：**原理**（为什么要做）→ **操作**（在软件里点哪里）→ **怎么判断做对了**。

贯穿全文的例子是 **IrO₂（Ir L₃ 边）**：结构已知（金红石型，每个 Ir 周围 6 个 O），适合用来定 S0²。
文中给出的 IrO₂ 数值来自作者项目中的实际拟合，你的数据会有所不同。

软件的“点哪里”细节见 **图形界面使用指南**；本教程重在讲清楚原理和判断标准。

## 0. 先建立整体图景

### 0.1 XAFS 测的是什么
X 射线能量扫过某元素的吸收边（如 Ir L₃ ≈ 11215 eV）时，吸收系数 μ(E) 突然升高：内层电子被打出来，变成**光电子**。

- **XANES**（边前到边后约 50 eV）：反映**价态和配位对称性**。看边的位置、白线强度、边前峰。
- **EXAFS**（边后约 50–1000 eV）：光电子波向外传播，被周围原子**反射回来**，与出射波干涉，使 μ(E) 出现小幅振荡。
  振荡的**频率**取决于到邻近原子的**距离 R**，**幅度**取决于邻近原子的**数量 N** 和**无序度 σ²**，**形状**（振幅和相位随 k 的变化）取决于邻近原子是**什么元素**。

所以 EXAFS 拟合回答的问题是：**吸收原子周围几 Å 内，有几个什么原子、在多远、有多乱。**

### 0.2 EXAFS 方程（拟合用的就是它）

$$\chi(k)=\sum_j S_0^2\,N_j\,\frac{|f_j(k)|}{k R_j^2}\,e^{-2k^2\sigma_j^2}\,e^{-2R_j/\lambda(k)}\,\sin\!\left[2kR_j+\delta_j(k)\right]$$

| 符号 | 含义 | 谁来提供 |
|---|---|---|
| $k$ | 光电子波矢，$k=\sqrt{0.2625\,(E-E_0)}$（Å⁻¹，E 以 eV 计） | 由数据换算 |
| $N_j$ | 第 j 条路径（壳层）的配位数 | **拟合**或固定 |
| $R_j$ | 距离，$R_j = R_{\text{FEFF}} + \Delta R$ | **拟合 ΔR** |
| $\sigma_j^2$ | 距离分布的方差（热振动 + 结构无序），即 Debye–Waller 因子 | **拟合** |
| $S_0^2$ | 被动电子振幅衰减因子，通常 0.7–1.0 | **用标样定**，样品中固定 |
| $\Delta E_0$ | 理论计算与实验之间的能量零点差 | **拟合**，通常同一样品各路径共用 |
| $f_j(k)$，$\delta_j(k)$，$\lambda(k)$ | 散射振幅、相移、平均自由程 | **FEFF 从结构算出** |

拟合就是：让 FEFF 提供“散射原子长什么样”，用实验数据确定 **N、ΔR、σ²、ΔE₀、S0²**。

### 0.3 全流程一览

```
原始数据 → ① 登记 → ② 质量检查 → ③ 能量校准 → ④ 归一化 → ⑤ 扣背景 χ(k) → ⑥ 傅里叶变换 χ(R)
       → ⑦ FEFF 算路径 → ⑧ 用标样定 S0² → ⑨ 拟合样品 → ⑩ 显著性检验 → ⑪ 判读 → ⑫ 汇总报告
```

## 1. 建项目、登记数据

**原理**：可重复性要求原始数据**只读**，每一步结果都能从原始数据重新生成。登记表 `meta.csv` 记录每个文件是什么（哪个样品、哪个吸收边、透射还是荧光、用哪个参比校准、是否使用），后面所有步骤都按它来。

**操作**：
1. **⓪ 项目** → “打开 / 新建项目” → **📁 浏览…** 选一个空文件夹 → **新建项目**。
2. **⓪ 项目 → 1 数据登记**：填批次名（如 `2026-11-05_Ir`），把这次测的文件拖进上传框，点 **上传**。**必须包含同一批测的金属箔或金属粉**（参比）。
3. 点 **扫描 data/raw，登记新文件**，在表格中检查：
   - `sample`：同名的行表示同一样品的多次扫描，会被合并；
   - `role`：参比填 `reference`，已知结构的标样填 `standard`，未知样品填 `sample`；
   - `use`：不用的扫描设为 `0`，并在 `note` 写原因。
4. 点 **保存 meta.csv**，再点 **2 检查 → 运行检查**，直到 0 个错误。

**做对了**：每个样品的 `ref_file` 都不为空，检查结果为 0 个错误。

## 2. 质量检查：这份数据能回答什么

**原理**：拟合之前必须先判断数据质量。坏数据拟出来的数也一样“好看”，但没有意义。常见问题：
- **毛刺（glitch）**：单色器晶体在某个能量出现多重衍射，或者光束突然掉束（I0 骤降），造成 μ(E) 上的尖峰。转换到 k 空间后变成一个尖刺，傅里叶变换后会污染整个 R 空间。
- **噪声**：高 k 处 EXAFS 振荡按 $e^{-2k^2\sigma^2}$ 衰减，迟早会被噪声淹没。噪声决定了可用的 **k 上限**。
- **边跳（edge step）**：透射模式下，边跳 Δμt ≈ 0.2–1 比较理想。太小信噪比差，总 μt 太大（> 3）会出现非线性，压低振幅。
- **荧光自吸收**：浓样品用荧光模式测时，振幅和白线都会被压低（实测可低约 25%）。荧光谱与透射谱**不能直接比较振幅**。
- **干扰吸收边**：样品中其他元素（或本元素的 L₂ 边）出现在扫描范围内时，k 范围必须在它之前截止。

**操作**：**⓪ 项目 → 3 一键处理 → ① 质量检查**，或者用 **② 质量检查** 页。

**看哪些列**：
- `glitch_E`：毛刺位置；
- `i0_drops`：掉束；
- `edge_step_mu`：边跳；
- `k_snr3`：信号降到 3 倍噪声时的 k，可以作为 kmax 的参考；
- `self_abs_risk`：荧光自吸收风险。

另外到 **⑤ χ(k) 与 FT → k 范围检查** 查看干扰边给出的 k 上限。

**做对了**：知道每条谱可以用到多高的 k，有毛刺或掉束的扫描已经剔除（`use=0`）或做了去毛刺。

## 3. 能量校准

**原理**：单色器的角度–能量对应关系在不同机时、甚至同一机时内都会漂移零点几到几个 eV。
金属箔的边位置是已知常数（表值 $E_{\text{table}}$，来源 xraydb），所以先测出参比的边位置 $E_{0,\text{meas}}$（**一阶导数最大值**），
校正量为 $\Delta E = E_{\text{table}} - E_{0,\text{meas}}$，再给**同一批测的所有谱**加上**同一个** ΔE。

为什么不给每个样品各自校准？因为样品的边位置本身就包含化学信息（价态越高，边越往高能移动）。如果把每个样品都“校准”到表值，这个信息就被抹掉了。

**操作**：**⓪ 项目 → 3 一键处理 → ② 按参比校准**。结果在 **③ 能量校准** 页查看，每个参比对应一个 ΔE。

**做对了**：ΔE 一般在几个 eV 以内；同一机时的几个参比给出的 ΔE 应当接近。

## 4. 归一化

**原理**：原始 μ(E) 的绝对大小取决于样品厚度、浓度、探测器增益，彼此不能比较。归一化把谱缩放成“边前 = 0，边跳 = 1”：
1. 在边前区（例如 E₀−150 到 E₀−30 eV）拟合一条直线，代表其他元素和其他壳层电子的吸收，然后扣掉；
2. 在边后区（例如 E₀+100 eV 到末端）拟合一条二次多项式，它在 E₀ 处的值就是**边跳**；
3. 用边跳去除。

**E₀** 采用一阶导数最大值，全项目统一使用这一种定义。

归一化之后，不同样品、不同模式的谱才能放在一起比较 XANES。

**操作**：参数在 **⓪ 项目 → 4 处理参数**（每个吸收边一套，同一边的所有样品共用）。查看在 **④ 归一化** 页的“μ(E) + 边前/边后”标签。

**做对了**：边前线贴着边前数据，边后线从数据中间穿过，没有系统性偏离；归一化后边后区在 1 附近平稳振荡。
**同一边的所有样品用同一套参数**，不能为了让某个样品“好看”单独调。

## 5. 扣背景，得到 χ(k)

**原理**：EXAFS 信号定义为

$$\chi(E)=\frac{\mu(E)-\mu_0(E)}{\Delta\mu_0(E_0)}$$

其中 $\mu_0(E)$ 是“孤立原子”的光滑吸收背景。这个背景无法测量，只能用一条光滑样条曲线来逼近。

Larch 的 AUTOBK 方法用参数 **rbkg** 控制背景有多“软”：它让样条去拟合 R < rbkg 的低频成分，并保证 R > rbkg 的结构信号不被样条吃掉。
- rbkg 通常取第一壳层 FT 峰位的一半左右，常用 **1.0 Å**；
- rbkg 太大，样条会吃掉第一壳层，振幅变小；
- rbkg 太小，低 R 区残留背景，会出现 R < 1 Å 的假峰。

然后把能量换成 $k=\sqrt{0.2625\,(E-E_0)}$。高 k 处振荡衰减，因此通常乘以 $k^2$ 或 $k^3$ 来放大，以便查看和拟合。

**操作**：**⓪ 项目 → 3 一键处理 → ③ 处理全部样品**。要查看谱图，先在 **① 数据导入** 页勾选样品、点 **载入样品**，再到 **⑤ χ(k) 与 FT** 的 “χ(k)” 和 “背景 μ0(E)” 标签。

**做对了**：$k^2\chi(k)$ 围绕 0 振荡，没有整体倾斜或缓慢起伏；高 k 端噪声开始占主导的位置，就是 kmax 的候选值。

## 6. 傅里叶变换：从 χ(k) 到 χ(R)

**原理**：χ(k) 是多个正弦波的叠加，每个壳层一个频率 $2R_j$。傅里叶变换把它们按距离分开，得到“径向分布”式的 $|\chi(R)|$。
- **k 范围（kmin–kmax）**：kmin 通常取 2–3 Å⁻¹，避开 XANES 区；kmax 由噪声和干扰边决定。
- **窗函数**（Hanning，过渡宽度 dk）：让数据在两端平滑地降到 0，减少截断带来的旁瓣假峰。
- **分辨率**：两个壳层的距离差必须大于 $\Delta R \approx \pi/(2\Delta k)$ 才能分开。例如 k = 3–12 时 ΔR ≈ 0.17 Å。**分辨率只由 Δk 决定。**
- **峰位不是键长**：每种散射原子都带有相移 δ(k)，所以 $|\chi(R)|$ 的峰比真实距离**短约 0.3–0.5 Å**（软件中 R 轴标注“未相移校正”）。真实键长只能从拟合得到。
- **一个峰不等于一个壳层**：峰可能来自噪声、背景残留、窗函数旁瓣或多重散射。

**操作**：**⑤ χ(k) 与 FT** 页，在 “|χ(R)| / Re” 标签里同时看 $|\chi(R)|$ 和实部 Re χ(R)；切换 k 权重 1、2、3 各看一遍。
轻散射体（O）在低 k 更强，重散射体（Ir、Ta）在高 k 更强。所以 k 权重改变时峰的相对高度会变，这本身就是区分散射体的线索。
需要时用 **⑥ 小波变换** 页同时看 k 和 R：重原子的强度中心在较高 k。

**做对了**：选定了 kmin、kmax，并记录下来；同一边的样品使用同一 k 范围。

## 7. 估算能拟合几个参数：独立点数 N_idp

**原理**：数据里可以独立确定的信息量是有限的（Nyquist 定理）：

$$N_{\text{idp}}=\frac{2\,\Delta k\,\Delta R}{\pi}$$

Δk 是 k 拟合范围，ΔR 是 R 拟合窗口。例：k = 3–12.5，R = 1.0–2.5 Å，则 N_idp = 2×9.5×1.5/π ≈ 9.1。

**规则**：变量数 ≤ N_idp/2（宽松一点可以到 N_idp − 3）。参数比信息多，任何模型都能“拟合得很好”，但结果没有意义。

**操作**：**⑧ EXAFS 拟合** 页设好范围后，页面直接显示 N_idp 和变量数上限；变量数超过时会出现黄色警告。

## 8. FEFF：从结构计算散射路径

**原理**：EXAFS 方程里的 $f(k)$、$\delta(k)$、$\lambda(k)$ 无法从数据中得到，需要从一个**结构模型**出发，用 FEFF 做多重散射理论计算。
FEFF 读入原子坐标，列出光电子从吸收原子出发、被一个或多个原子散射后回到吸收原子的所有**路径**：
- **单散射路径**：吸收原子 → 邻近原子 → 回来。路径长度 = 2R，简并度 = 该距离上的原子数。
- **多重散射路径**：经过两个或更多原子，例如共线的 M–O–M。这类路径在外壳层中可能很强。

FEFF 给出的 R 是**起点**。拟合时允许 ΔR 小幅调整，配位数可以固定为简并度，也可以拟合。
结构不必和样品完全相同，只要局域环境类似即可，例如用 KTaO₃ 的 Ta–O 路径去拟合无定形 TaOx 的第一壳层。

**操作**：**⑦ FEFF 路径**：
1. 结构来源选 **内置结构** → `IrO2`（自己的结构把 CIF 放进 **⓪ 项目 → 5 结构文件**）；
2. 吸收原子 `Ir`，吸收边 `L3`，RMAX 6 Å；
3. 点 **运行 FEFF6L**。

**做对了**：路径表中 IrO₂ 的前两条是 Ir–O：2 个 1.958 Å、4 个 1.996 Å，与金红石结构一致。

## 9. 用标样确定 S0²

**原理**：S0² 与配位数 N 在方程中是**相乘**关系，同一组数据无法把两者分开。
解决办法是先用**结构已知的标样**（N 已知）来拟合 S0²，再把这个值**固定**用于未知样品，从而拟合 N。
S0² 主要取决于吸收元素和吸收边，与化学环境关系不大，所以同一元素同一边可以通用。
但要求测量条件可比：同为透射，样品厚度合适。

**操作（IrO₂ 例子）**：**⑧ EXAFS 拟合**：
1. **数据** 选 IrO₂；**FEFF 目录** 选刚才算的 `IrO2_IrL3`。
2. **拟合范围**：kmin 3，kmax 12.5，dk 1，k 权重 **1, 2, 3 同时勾选**，Rmin 1.0，Rmax 2.5，空间 `r`。
3. **路径表**：勾选两条 Ir–O 路径。`N` 保持 FEFF 简并度（2 和 4，固定为结构值）。
   两条路径的 `deltar` 都填 `dr1`，`sigma2` 都填 `ss1`：两组距离相近，作为“一个壳层”共用参数，减少变量。
4. **参数表**：`s02`、`e0`、`dr1`、`ss1` 都勾选 `vary`。共 4 个变量，N_idp ≈ 9.1，满足 ≤ N_idp/2。
5. 点 **拟合**。

作者项目中的实际结果：**S0² ≈ 0.82，ΔE₀ ≈ 8.9 eV**（Ir L₃，透射）。
把得到的 S0² 填到 **⓪ 项目 → 4 处理参数 → S0²**，点 **保存参数**。

**为什么同时用 k¹、k²、k³**：不同权重对低 k（轻原子、ΔE₀）和高 k（σ²、重原子）的敏感度不同。三者一起拟合，可以减弱 S0²–σ²、ΔE₀–ΔR 之间的相关性。

## 10. 拟合未知样品

**原理**：从简单到复杂，逐步加壳层。

1. **第一壳层**（最近邻，如 M–O）：S0² 固定为标样值；N、ΔR、σ²、ΔE₀ 自由。共 4 个变量。
2. 看残差：如果第二个峰（如 M–M）没有被拟合，再加一个壳层。新壳层通常再增加 N、ΔR、σ² 共 3 个变量，ΔE₀ 一般共用。
3. 每加一层都要检查 N_idp 是否够用，并做 F 检验（第 11 节）。

**操作**：
1. **⑧ EXAFS 拟合**，选样品数据和对应的 FEFF 目录。
2. **路径表**：把要拟合配位数的路径，`N` 列改成参数名，例如 `n1`。同一壳层的路径都写 `n1` 表示共用；如果某条路径的 N 应当是另一条的固定倍数，可以写 `n1*2`。
3. **参数表**：
   - **固定 S0²**：`s02` 行取消勾选 `vary`，`value` 填标样值，例如 0.82。
   - **共用 / 约束**：在 `expr` 列填表达式，该参数就由表达式计算，不再是独立变量。
     - 例 1：让 `ss2` 的 `expr` 等于 `ss1`，表示两个壳层 σ² 相同。
     - 例 2：共线多重散射路径 M–O–M 的 `deltar` 填 `dr2`，`sigma2` 填 `ss2`，即与对应的 M–M 单散射绑定。
   - **min / max**：给参数设物理范围，例如 σ² ≥ 0。
4. 点 **拟合**；满意后点 **保存结果到 output/fits/exafs_fits.csv**，模型会同时存入 `models/`，以后可以一键重跑。

**怎么判断拟合好不好**：

| 指标 | 含义 | 参考范围 |
|---|---|---|
| R 因子 | 拟合与数据的相对差异 | < 0.02 很好，< 0.05 可接受 |
| χ²_ν | 约化卡方，取决于噪声估计 | 主要用于**同一数据**的不同模型之间比较，不看绝对值 |
| ΔE₀ | 能量零点差 | \|ΔE₀\| < 10 eV；超过时检查 E₀ 定义或模型 |
| σ² | 无序度 | 正值；第一壳层通常 0.002–0.015 Å² |
| S0²（标样） | | 0.6–1.1 |
| N | 配位数 | 误差往往有 ±10–25%，报告时带误差 |
| 误差 | 来自协方差矩阵（已按 χ²_ν 修正） | 误差大于数值本身说明该参数没有被确定 |

**还要看图**：$|\chi(R)|$ 和 **Re χ(R)** 都要贴合，只贴合模量是不够的；k 空间的拟合曲线要与数据同相位。软件会对 |ΔE₀| > 10 eV、σ² < 0 和超范围的 S0² 发出警告。

**参数相关性**：ΔE₀ 与 ΔR 强相关（两者都改变振荡的相位），N 与 σ² 强相关（两者都改变振幅）。完整拟合报告（feffit_report）末尾列出了相关系数，> 0.9 要注意。
所以：
- 键长差 < 0.02 Å 的结论要谨慎；
- 比较不同样品的 N 时，最好在相同 k 范围、相同 S0² 下比较。

**稳健性**：拟合结果下方点 **运行稳健性检查**，软件会稍微改变 k、R 范围和 k 权重重复拟合。
变化超过统计误差的参数标为“不稳”，应以范围报告，或简化模型。

---

## 11. 加不加壳层：F 检验

**原理**：增加参数总会让 R 因子变小，哪怕新加的是噪声。Hamilton F 检验判断 R 因子的下降是否超过“多了几个参数”本该带来的改善。

**操作**：**⑨ 拟合历史/F检验** → 选“简单模型”和“复杂模型”（复杂模型必须是在简单模型上增加参数）→ **比较**。

**判读**：
- **p < 0.05**：新壳层显著，可以报告为“拟合中包含该壳层，且显著”；
- **p ≥ 0.05**：不能说“观察到”该壳层，只能说“数据不排除”。

轻散射体（O、K）挨着重元素壳层时尤其难确定，需要用小波变换、不同 k 权重，或其他表征（XRD、XPS、成分分析）独立佐证。

---

## 12. XANES 线性组合拟合（LCF，可选）

**原理**：如果样品是几种已知物相的混合，它的归一化 XANES 约等于各标样谱的加权和，权重即各物相所占的比例（按吸收原子计）。

**操作**：**⑩ LCF**：选样品和端点标样（**必须是实测标样**）、能量范围（常用 E₀−20 到 E₀+60 eV）、空间（归一化 μ），点 **LCF**。软件会同时给出“只用单一标样”的拟合作为对照。

**判读**：
- 权重之和接近 1；
- 多标样拟合的 R 因子应当明显低于单一标样拟合；
- 漏掉了某个物相时，结果会系统性地偏。

边位置、价态标定和边前峰拟合见图形界面使用指南的 **⑬ XANES 定量**。

## 13. 生成汇总报告

**操作**：**⑫ 汇总报告** → **生成汇总**，得到：
- `汇总.xlsx`：样品、校准、质量检查、处理参数、每个模型的拟合概要和各路径参数、LCF；
- `汇总报告.html`：表格加全部图，可以打印为 PDF。

写论文时需要报告这些内容：
- k 范围、R 范围、k 权重、窗函数；
- N_idp 和变量数；
- S0² 及其来源（哪个标样）；
- 每个壳层的 N、R、σ²，以及 ΔE₀ 和 R 因子，均带误差。

## 14. 如何写结论：三种陈述要分开

| 类型 | 例子 | 依据 |
|---|---|---|
| **实测** | “样品的白线强度比 IrO₂ 低”；“2.8–3.5 Å 处的 FT 峰随时间减弱” | 谱图上直接可见（注明“未相移校正”） |
| **拟合结果** | “Ir–O 配位数 5.6 ± 0.6，键长 1.98 ± 0.01 Å”（示意数值） | 依赖所选模型、S0² 和 k 范围 |
| **推测** | “表面形成了无定形 IrOx” | 需要多个指标共同支撑，或其他实验证实 |

## 15. 新手常见错误清单

1. 没看 χ(k) 和噪声就直接拟合 → 先完成第 2 节和第 5 节。
2. 每个样品用不同的归一化或背景参数 → 同一边的样品必须统一。
3. 把 FT 峰位直接当作键长 → 峰位未做相移校正，键长看拟合结果。
4. 让 S0² 和 N 同时自由变化 → 两者完全相关，S0² 必须先由标样确定。
5. 变量数超过 N_idp/2 → 减少壳层，或者共用 σ²、ΔE₀。
6. 只看 |χ(R)| 不看 Re χ(R) → 相位不对的拟合，模量也可能贴得很好。
7. 把荧光谱和透射谱的振幅直接比较 → 自吸收会压低振幅。
8. 不做 F 检验就宣称看到了外壳层 → 第 11 节。
9. ΔE₀ 超过 ±10 eV 仍然接受结果 → 检查 E₀、校准和模型。
10. 只用本软件的结果 → **用 Athena / Artemis 对关键结果做一次独立对比。**
