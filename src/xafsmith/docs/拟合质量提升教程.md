# 拟合质量提升教程：怎样在 XAFSmith 里把 EXAFS 拟合做到“尽可能好”

> 适合已经能跑通一次拟合（见《零基础拟合教程》）、但拟合曲线和数据**对不严**的人。
> 本教程全部在图形界面里完成，不需要写代码。操作位置用左侧栏的页面名称标注。

---

## 0. 先弄清“完美”是什么意思

拟合曲线和数据**每个峰都严丝合缝**，通常**做不到，也不应该追求**：

1. **数据有噪声和系统误差**：单次扫描、毛刺、背景扣除、样品不均匀。曲线贴合到噪声以下，就是在拟合噪声。
2. **结构是分布，模型是几个高斯壳层**：真实样品（尤其是无序、多相、纳米材料）里每个距离都是一个分布，几条路径只能近似。
3. **信息量有限**：独立点数 N_idp = 2ΔkΔR/π，k 3–11、R 1–4 Å 时只有约 15 个。参数越多，每个参数越不可靠。
4. **R 因子能被“刷”下去**：多加几条路径、放开 N 和 σ²，R 因子一定会下降，但参数会失去意义。

所以“尽可能好”的正确定义是同时满足四条：

| 目标 | 怎么判断 | 在哪里看 |
|---|---|---|
| ① 残差已接近数据极限 | 窗口内残差 ÷ 噪声 ≈ 1–2；或至少与同一批测量的标样相当 | EXAFS 拟合结果 → **拟合诊断** |
| ② 残差里没有可以消除的“系统结构” | k 残差没有局部尖峰、没有某一段特别大；R 残差没有集中在某个峰 | 拟合诊断的 k 分段 / R 分段表 |
| ③ 每个参数都物理、稳健 | σ² > 0、ΔE0 在 ±10 eV、不贴边界；稳健性检查全部“稳定” | 拟合结果表、**稳健性检查** |
| ④ 每条路径都“挣到了”自己的位置 | 加入时 F 检验 p < 0.05 | 拟合历史 |

**先满足 ③④，再追求 ①②。** 参数不稳的“好拟合”比 R 因子稍大的稳健拟合更糟。

## 1. 第一步永远是“诊断”，不是“加路径”

EXAFS 拟合页拟合完成后，结果下方展开 **“拟合诊断：残差在哪里、为什么对不上”**。

### 1.1 三个数字

| 数字 | 含义 | 怎么读 |
|---|---|---|
| 窗口内残差 RMS | 拟合窗口内 \|χ(R)数据 − χ(R)拟合\| 的均方根 | 越小越好，但要和下一项比 |
| 白噪声估计 | 数据在 R 15–25 Å 的 \|χ(R)\|（那里没有结构信号） | 随机噪声水平 |
| **残差 / 噪声** | 两者之比 | **≈ 1–2**：已到极限，停止；**2–5**：还有系统误差，值得排查；**> 5**：明显的系统问题 |

> 白噪声估计**低估**了真实误差（它看不到背景、毛刺、样品不均匀这类系统误差），所以比值 > 1 几乎总会出现。
> 更实用的标尺：**同一模型用在同一批测的已知标样上**得到的比值。样品的比值和标样相当，就说明残差主要来自理论与处理本身，而不是你的样品模型错了。

### 1.2 k 空间残差图

图中黑线为数据，蓝线为残差 k^w·(数据 − 拟合)，紫色虚线标出检测到的尖峰。看三件事：

| 你看到的 | 最可能的原因 | 去第几节 |
|---|---|---|
| 某个 k 处一上一下的尖锐小峰（宽 1–3 个点） | **残留毛刺** | 2.1 |
| 低 k 段（kmin 起的第一段）残差明显大 | 背景扣除、近边效应、E0、理论势 | 2.3、2.4 |
| 高 k 段残差大且是锯齿状 | 噪声 | 2.2 |
| 整段残差是平滑、有规律的振荡 | 模型缺路径 / 距离或 σ² 不对 | 3 |

### 1.3 k 分段表与 R 分段表

- **k 分段**：“相对中位数” > 1.5 的段就是问题段。
- **R 分段**：“局部失配” = Σ\|Δχ(R)\|² / Σ\|χ(R)\|²。
  - 第一壳层段应 < 0.05；外壳层段 0.1–0.3 是常见水平；> 0.3 说明该处模型不够或数据有问题。
  - **注意谷底**：两峰之间的谷底数据强度小，局部失配天然偏大，不要据此加路径。看“数据强度”一列判断。
  - **窗口外**失配大是正常的，那里不参与拟合。

### 1.4 一个重要规律：毛刺会在 R 空间变成“一串等间距的小峰”

k 空间 k₀ 处的一个尖锐尖峰，傅里叶变换后在 R 空间是**周期约 π/k₀ 的振荡**，铺满整个 R 范围（包括窗口外）。
所以如果你看到 R 残差呈等间距波纹（例如 k₀ ≈ 5 Å⁻¹ 时间隔约 0.6 Å），并且窗口外 \|χ(R)\| 不衰减，**先查毛刺，不要加壳层**。

## 2. 按来源排查（从数据到模型，顺序很重要）

### 2.1 数据：毛刺（最常见、最容易修）

**操作**：质量检查 → 页面底部 **去毛刺**。

1. 选样品，看 μ(E) 和 I0/中位数 的叠图。QC 检测到的毛刺能量画成灰色虚线。
2. 判断标准（三条同时满足才删）：
   - 宽 1–3 个点；
   - 多个样品**在同一能量**出现；
   - **I0 在同一位置有凹陷**（单色器毛刺）。
3. **区间要包含所有偏离平滑趋势的点**，不只是最尖的那个点：
   - 放大看尖峰两侧，毛刺通常是“前面偏高、后面偏低”（或反过来）的一对；
   - 只删中间、留下两侧偏离点，χ(k) 中仍会残留一上一下的尖峰。
4. 填“删除区间”（如 `9983-9991`，多个用分号）和**理由（必填）** → **保存并重新载入**。
5. 回到 EXAFS 拟合重新拟合，再看诊断：尖峰提示应消失，k 残差在该处应变平。

**不要做的**：
- 区间超过约 10 eV；
- 删白线、边前峰附近的点；
- 只在一个样品上删而在同批其他样品上不删同一毛刺；
- 为了降 R 因子而删“不好看”的振荡。

> 注意：删除尖峰后 R 因子**不一定**下降。尖峰的大部分功率在拟合窗口外的高 R 处，删除后拟合参数也会重新收敛。判断依据是 k 残差图在该处是否变平，而不是 R 因子。

### 2.2 数据：噪声与 k 上限

- 质量检查表里的 **k_snr3** 是信噪比降到 3 的 k 值。kmax 不要明显超过同一序列中**最差样品**的 k_snr3。
- 同一序列的所有样品**必须用同一个 k 范围**，否则 σ² 不能比较。
- 噪声真正的解药是**多次扫描合并**（① 中同名样品自动合并）。软件里的任何参数都替代不了这一点。

### 2.3 处理：背景、E0、kmin

| 现象 | 调什么（在哪里） | 注意 |
|---|---|---|
| R < 1 Å 有明显残余峰 | ⑤ 页 rbkg（常用 1.0；可试 0.9–1.2） | 同一序列所有样品用同一个 rbkg，写进 `xafsmith.json` |
| 低 k 段残差大 | 先做 **稳健性检查**（kmin ±0.5） | 看参数是否随 kmin 变化。变化在误差内 → 低 k 残差不影响结论，可保留 kmin；超出误差 → 提高 kmin，并对**所有样品**统一提高 |
| ΔE0 > ±10 eV | ④ 页 E0 定义 | 全项目统一一种 E0 定义（默认一阶导数最大值） |
| 不同样品 ΔE0 差很多 | 能量校准 | ③ 页看各样品 ΔE；没有同步参比时要特别小心 |

**kmin 的取舍**：提高 kmin 通常能降低 R 因子（去掉近边区域），但会损失 N_idp 和轻元素信号。规则是：**能用稳健性检查证明结论不依赖 kmin，就不必提高**；报告时写清用的 kmin。

### 2.4 理论：FEFF6L vs FEFF8L

FEFF 路径页 → **FEFF 版本**：

- **FEFF6L**：非自洽 muffin-tin 势，几秒。
- **FEFF8L**：自洽势（SCF），1–3 分钟。对低 k 区和 ΔE0 通常更准确。

建议做法：
1. 同一结构分别算 FEFF6L 和 FEFF8L（FEFF8L 输出目录自动加 `_feff8`，不会覆盖）。
2. 同一模型把路径目录换成 `_feff8`（在模型 JSON 中替换路径前缀，或在 EXAFS 拟合页改选 FEFF 目录后按同样设置建模），在标样和样品上各拟合一次。
3. 比较 R 因子与参数：
   - 参数在误差内一致 → 结论与理论选择无关（这本身就是一条稳健性证据）；选 R 因子低的报告，写明 FEFF 版本。
   - 参数不一致 → 理论误差不可忽略，用两者的差异作为系统误差报告。
4. **换版本后 ΔE0 零点会变**（常差几 eV）。把 e0 固定为某个值的模型（例如为了解除 ΔE0–ΔR 相关）必须用新版本重新确定 e0。

其他理论设置：
- **SCF 半径**：一般 4–5 Å（包含 2–3 个壳层，30–60 个原子）。更大只会更慢，改进有限。
- **结构是否正确**：路径的 reff 来自你给的结构。用错晶型、错位点，任何参数都救不回来。多个不等价位点要分别计算（⑦ 页“不等价位点”）。

### 2.5 振幅：S0² 与样品均匀性

- S0² 必须来自**同一吸收边、已知结构的标样**拟合（`xafsmith.json` 里的 `s02_recommended`），样品中固定。
- 如果所有壳层的振幅都系统性偏低、σ² 却正常 → 怀疑样品不均匀（针孔、厚度起伏）或荧光自吸收，而不是结构变化。比较中程有序时可用“外壳层峰 ÷ 第一壳层峰”这种比值抵消整体振幅。

## 3. 模型：什么时候、怎样加路径

只有在第 2 节都排查过、诊断仍显示**平滑、有规律**的残差集中在某个 R 区时，才考虑改模型。

### 3.1 先找“候选路径”

⑦ 页“已有 FEFF 计算”表按距离列出所有路径和**振幅比（amp_ratio）**：

- 拟合窗口内、振幅比 > 约 10% 的路径都应该**考虑**（用或不用都要有理由）。
- 多重散射（nleg 3–4）不能忽略：例如共线 M–O–M 链的多重散射振幅常常比单散射还大。
- 同一几何（同一条直线链、同一个三角形）上的路径要共用 ΔR、σ²。

### 3.2 加路径时少加变量：用约束

| 约束 | 写法（路径表 deltar / sigma2 / N 列） | 依据 |
|---|---|---|
| 各向同性膨胀 | `deltar = dr1*reff/1.994`，或定义 `alpha`，`deltar = alpha*reff` | 立方或近立方结构 |
| 几何关系 | 例：钙钛矿中 ΔR(B–A) = √3·ΔR(B–O) → `dr1*sqrt(3)` | 晶格几何 |
| 多重散射 ΔR / σ² 绑定 | 拟合页“多重散射绑定…”（`xafsmith msbind`）按路径几何给建议：共线路径与远端单散射共用 `ssT`；三角路径的 σ² 是每根独立键的系数平方相加（如 Ir-O-Ir 为 `0.5*ss1 + 0.25*ss2`），不要照抄 ΔR 的系数 | 规则见《XAFS处理规范》第 5 节第 8 条；建议写进路径 `note` |
| 固定配位数 | `N = 6` | 结构已知时固定 N，只放开 σ² |
| 弱散射体 σ² 固定 | 用标样拟合值，如 `ssK = 0.020` 固定 | 轻元素信号弱，σ² 与 N 无法同时定 |

> **N 与 σ² 强相关**（振幅 ∝ N·exp(−2k²σ²)）。在有限 k 范围内“配位数减少”和“无序增大”往往分不开：一次只放开一个，另一个固定，并在报告中说明。

### 3.3 每加一样东西都要过 F 检验

1. 在 EXAFS 拟合页先拟合“小模型”，再拟合加了路径/参数的“大模型”，两者都进入 拟合历史。
2. 拟合历史页选两个拟合 → **F 检验**。p < 0.05 才保留；p ≥ 0.05 的路径不能报告为“观察到”。
3. 只加路径、不加变量（全部用约束）时 F 检验不适用，看 χ²_ν 是否下降、参数是否仍稳健。
4. 新路径先在**标样**上试：在结构已知的标样上不能改善拟合的路径，加到样品上也不可信。

### 3.4 常用“高级”手段与其代价

| 手段 | 什么时候考虑 | 代价 / 注意 |
|---|---|---|
| 三阶累积量 c3（路径 `third`） | 第一壳层不对称（无序、热振动强）、R 有系统偏移 | +1 变量；c3 与 ΔR 相关 |
| 扩大 Rmax、加外壳层 | 窗口外仍有清晰的峰且你想解释它 | N_idp 增加，但要加的路径通常更多 |
| 两个物相 / 两个位点 | 有独立证据（XRD、XANES LCF）表明是混合物 | 变量翻倍；用分数参数 x 和 (1−x) 绑定 N |
| 多 k 权重同时拟合（1,2,3） | 默认就应该用 | 抑制 N–σ²、ΔE0–ΔR 相关 |
| 键长分裂（两个 Ta–O 子壳层等） | 两个距离差 > ΔR = π/(2Δk) 时才可能分辨 | 小于分辨率时只会得到不稳定的结果 |

## 4. 稳健性检查：判断结果能不能信

EXAFS 拟合结果下方 **稳健性检查** → 运行。软件依次改变 kmin ±0.5、kmax ±1、Rmax ±0.2 Å 和单独的 k¹/k²/k³，重复拟合。

- “离散度/误差 > 1”记为**不稳**：该参数随你的主观选择变化超过统计误差，不能单独解读。
- 全部“稳定”是拟合可以报告的必要条件。
- 对系列样品：**结论（例如某参数的趋势）要在所有条件下都成立**。只在一个条件下成立的趋势不能写成结论。

## 5. 什么时候停

按顺序打勾，全部满足就停，不要再“优化”：

1. [ ] 去毛刺完成，k 残差图上没有尖峰提示；
2. [ ] 所有样品同一套处理参数（E0 定义、归一化、rbkg、k 范围、窗函数）；
3. [ ] 模型先在标样上验证过，标样参数合理；
4. [ ] 变量数 ≤ N_idp/2；
5. [ ] 每条路径的加入都通过了 F 检验（或全部由约束给出、不增加变量）；
6. [ ] 稳健性检查全部“稳定”；
7. [ ] 残差/噪声与同批标样相当，或 ≤ 2–3；
8. [ ] \|χ(R)\| **和 Re χ(R)** 在窗口内都跟得上主要特征；
9. [ ] （可选）FEFF6L 与 FEFF8L 结果在误差内一致。

**还没“严丝合缝”但已满足上面全部条件时**，剩下的残差就是数据和理论的极限。正确做法是如实报告 R 因子、χ²_ν 和残差水平，而不是继续加参数。

## 6. 常见误区

| 误区 | 为什么错 | 正确做法 |
|---|---|---|
| 一直加路径直到 R 因子 < 0.01 | 参数失去意义，误差变大，稳健性检查不过 | 每条路径过 F 检验；R 因子 0.02–0.05 对多壳层是正常的 |
| 看到 R 空间小峰就加壳层 | 小峰可能来自噪声、毛刺（等间距波纹）、窗函数旁瓣、谷底失配 | 先做诊断；用小波（⑥）和不同 k 权重确认 |
| 不同样品用不同 k 范围或 rbkg 来“各自拟合最好” | σ² 等参数不再可比 | 系列样品一套参数，个别例外写进 overrides 并给理由 |
| 只看 \|χ(R)\| | \|χ(R)\| 对相位不敏感 | 同时看 Re χ(R) 和 k 空间 |
| 去毛刺越宽越好 | 删掉真实信号；> 10 eV 的空洞会扭曲 χ(k) | 只删偏离趋势的点，区间写理由 |
| 换了 FEFF 版本还沿用固定的 e0 | 两版本 ΔE0 零点不同，键长会偏 | 重新确定 e0 |
| 用标样的“最佳 R 因子”作为样品的目标 | 无序、多相样品的模型天然更粗 | 以“残差/噪声与标样相当”为目标 |

## 7. 推荐的完整工作顺序（速查）

1. 质量检查 → 看 k_snr3、毛刺列 → **去毛刺**（区间 + 理由）。
2. ④⑤ 统一处理参数；⑤ 看 k¹/k²/k³ 的 χ(k) 和 FT。
3. ⑦ 对标样结构算 FEFF6L 和 FEFF8L。
4. EXAFS 拟合：在**标样**上建模 → 拟合 → **拟合诊断** → 稳健性检查 → 保存模型。确定 S0²。
5. EXAFS 拟合页顶部“运行已保存的模型”把同一模型批量用于全部样品。
6. 对每个样品看**拟合诊断**：有尖峰 → 回到 1；低 k 偏大 → 稳健性检查看 kmin 影响；平滑残差集中在某处 → 第 3 节，候选路径 + F 检验。
7. 拟合历史页 F 检验确认每一步；稳健性检查确认结论。
8. 报告导出、图片导出，图注写明 FEFF 版本、k/R 范围、k 权重、S0² 来源、扫描次数。
