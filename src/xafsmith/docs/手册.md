# XAFSmith 操作手册（给人和任何 AI 助手）

> 目录与文件格式见 **数据标准.md**；处理与拟合的科学规范见 **XAFS处理规范.md**。
> 本手册只讲怎么用。不需要读源码，按下面的命令走即可，每一步的输出都列出来了。

## 0. 安装

```
python -m venv .venv
.venv\Scripts\python -m pip install git+https://github.com/Wiolic/XAFSmith.git     # 或本地：pip install -e <XAFSmith 目录>
```

安装后有命令 `xafsmith`（在 venv 中：`.venv\Scripts\xafsmith`）。FEFF6L / FEFF8L 随 xraylarch 安装，无需另装。
Windows 安装包：命令行程序是安装目录里的 `xafsmith-cli.exe`（默认 `%LOCALAPPDATA%\Programs\XAFSmith\`），与 `xafsmith` 等价。

## 1. 标准流程

```
xafsmith new <项目目录>          # 1. 新建项目（已有项目跳过）
                                 # 2. 原始数据放进 data/raw/<批次>/（每个批次带单质参比）
xafsmith init                    # 3. 登记 → data/meta.csv、xafsmith.json（不覆盖已有修改）
                                 # 4. 检查 meta.csv：sample 合并是否正确、role、ref_file；xafsmith.json 的 elements_in_sample
xafsmith validate                # 5. 按数据标准检查（有“错误”必须先改）
xafsmith qc                      # 6. 质量检查：毛刺、掉束、边跳、自吸收风险、k_snr3
xafsmith kcheck --edge Ta_L3     # 7. 干扰边 → k 上限；与 k_snr3 一起决定 ft.kmax
xafsmith calib                   # 8. 每个参比一个 ΔE
xafsmith process                 # 9. 校准→归一化→合并→χ(k)→FT
xafsmith feff --structure X.cif --absorber Ta --edge L3          # 10. FEFF 路径（加 --code feff8 用 FEFF8L 自洽势，输出目录加 _feff8）
                                 # 11. 快速拟合（只拟合第一壳层，自动判定）：xafsmith quickfit <标样> --feff <文件夹> --standard → S0²
                                 #     xafsmith quickfit <样品…> --feff <文件夹> --s02-from <标样模型>（≥ 2 个样品自动联合拟合）
                                 # 12. 需要多壳层 / 多重散射 / 自定义约束：写 models/<名>.json → xafsmith fit <名>；加壳层用 xafsmith ftest
xafsmith diagnose <模型>          #     拟合诊断：残差/噪声、毛刺定位、分段失配；xafsmith robust <模型> 稳健性
xafsmith lcf --sample S --standards A B                          # 13. XANES 线性组合
xafsmith figure --kind chir --samples A B --size double   # 14. 期刊图（xanes/deriv/chik/chir/fit）
xafsmith summary                 # 15. 报告导出（Excel + HTML）；xafsmith methods 方法段落；export-prj 导出 Athena
                                 # 16. 记录：notes/YYYY-MM-DD_主题.md（模型、命令、结论、下一步）
```

## 3. 快速拟合与精细拟合

EXAFS 拟合有两种做法，图形界面侧栏 **EXAFS 拟合** 页顶部用分段开关 **快速拟合 | 精细拟合** 切换（每次进入默认快速拟合）：

| | 快速拟合（`xafsmith quickfit`） | 精细拟合（`xafsmith fit` + 模型 JSON） |
|---|---|---|
| 拟合什么 | 只拟合第一壳层（N、R、σ²、ΔE0，标样用途另拟合 S0²） | 任意路径与参数：多壳层、多重散射、表达式约束、软约束、σ²(T) 模型 |
| 谁来决定 | 用户只选样品、FEFF 文件夹、用途（标样 / 样品）、Rmax、S0² | 用户写路径表与参数表（原 v1.3.1 的拟合页，只改了名字） |
| 判定 | 自动，带建议（见下） | 质量检查（R 因子、N_idp/2、误差、强相关……）与诊断，由用户判断 |

**建议流程**：先快速拟合第一壳层；判定“可信”后，若结构需要第二壳层或多重散射，用结果页的 **在精细拟合中继续** 把模型载入精细拟合再加路径（快速拟合写的就是普通模型 JSON，两边通用）。

### 3.1 快速拟合怎么做

1. **标样**：`xafsmith quickfit <标样> --feff <FEFF 文件夹> --standard`。N 固定为 FEFF 第一壳层的简并度之和，拟合 S0²、ΔE0、ΔR、σ²。
2. **样品**：S0² 固定，拟合 N、ΔE0、ΔR、σ²。S0² 二选一：`--s02-from <标样模型名>`（命令行只取**已保存**的拟合：`output/fits/exafs_fits.csv` 里与样品同一吸收边、S0² 为拟合量的标样拟合；来源 `{model, value, stderr}` 写入模型的 `s02_source`），或 `--s02 0.85`（手填，判定里提示“没有标样依据”，`s02_source` 记为手动）。
3. **≥ 2 个样品（样品用途）= 自动联合拟合**：公共 k 窗（各样品处理 k 窗的交集，不足 6 Å⁻¹ 报错）与 R 窗、共享 ΔE0、共用 S0²；每个样品各自的 N、R、σ²。样品必须同一吸收边。标样用途只能给一个样品。
   - **混合相（第二相）**：样品由两个相混合（如金属 Ir + IrO2）时再给一个 FEFF 文件夹（`--feff2`，GUI：“第二相 FEFF”），两相各拟合第一壳层：相 1 的 `n1`、`dr1`、`ss1`，相 2 的 `n2`、`dr2`、`ss2`，ΔE0 共用，S0² 固定；N 初值各为 N_ref 的一半，范围 [0, 2·N_ref]。联合拟合时每个样品只有自己的 `n1_<id>`、`n2_<id>`，`dr1`、`ss1`、`dr2`、`ss2` **全批共享**（两相的 N 与 σ² 强相关，共享才稳）。两相吸收原子须相同，只用于样品用途（标样只用单相）。Rmax 缺省 3.0 Å（单相 2.5 Å）；自动 Rmin 按距离较短的一相找第一峰（上端 = 较短的 R_CIF − 0.2 Å），不被金属峰带偏；Rmax 处残余只作提示（较长一相的第一峰较宽）。判定对两相各做 R 与 CIF 之差、N / N_ref；数据第一峰与任一相的结构第一壳层相符即通过；各相比例（N / N_ref）只作提示，仅供参考。趋势表每个数据集出两行（Ir–O、Ir–Ir first shell）。
4. 窗口：k 窗取样品的处理设置（`xafsmith.json` 的 `ft`，个别样品覆盖也算）；k 权重默认 1、2、3 同时；**Rmax** 默认 2.5 Å；**Rmin 自动**：|χ(R)|（k²）在 0.7 Å 到第一峰之间的极小位置，且不低于 R_peak − 0.6 Å、不低于 0.7 Å，没有极小则取 1.0 Å 与 R_peak − 0.6 Å 中较大者；`--rmin`、`--kweight` 只用于测试 / 核对。
5. 判定（Verdict）：整批 + 逐样品两层，每项通过 / 需注意（附一句建议）/ 提示：
   - R 因子：< 0.02 很好，0.02–0.05 对第一壳层可接受，> 0.05 需注意；
   - Stern 准则：变量数 ≤ N_idp 通过（> N_idp 需注意），变量数 > N_idp/2 只给提示“信息量偏少”（精细拟合的检查则按变量数 ≤ N_idp/2）；
   - 每个变量误差可估、不大于数值，不停在上下限；|ΔE0| ≤ 10 eV；σ² 为正且 ≤ 0.03 Å²；|ΔR| ≤ 0.2 Å；没有 |r| > 0.9 的强相关参数对；
   - 拟合 R 与 CIF（FEFF 第一壳层按简并度加权的平均 Reff）相差 ≤ 0.15 Å；
   - 样品的 N ≤ 1.5 × N_ref（超出多半是 N 与 σ² 互相补偿，或标样 S0² 不适用）；
   - Rmax 处 |χ(R)| ≤ 第一峰的 30%（否则窗口可能切进第二壳层）；
   - 数据第一峰位置与结构第一壳层对应：R_p − R_CIF 在 −0.8 … +0.1 Å（FT 峰比真实距离短，对不上说明结构与样品不符，例如金属相样品配了氧化物 FEFF）。
   手填 S0²、第一层还有别的元素（未考虑）、联合拟合各样品 dk / 窗函数不一致，只作提示，不判失败。
6. 输出：屏幕打印结果表（样品、N、R、σ²、ΔE0、S0²、R 因子、判定）与逐项判定；联合拟合另打印趋势表。**默认不写任何文件**；`--save` 才写 `models/<名>.json`（模型名缺省 `QF_<样品>`，联合 `QF_joint_<首>__<末>`；已存在则报错不覆盖，用 `--name` 换名）、拟合记录与图，联合拟合另写 `output/fits/<名>_trend.csv`。

```
xafsmith quickfit IrO2_std --feff output/feff/IrO2_IrL3/site0 --standard --save            # 标样：S0² 写入拟合记录
xafsmith quickfit IrTa_A --feff output/feff/IrO2_IrL3/site0 --s02-from QF_IrO2_std --report   # 样品：S0² 取自标样拟合；另写汇报包
xafsmith quickfit IrTa_t1 IrTa_t2 IrTa_t3 --feff output/feff/IrO2_IrL3/site0 --s02 0.85 --save   # ≥ 2 个样品：联合拟合 + 趋势 CSV
xafsmith quickfit IrTa_t1 IrTa_t2 IrTa_t3 --feff output/feff/IrO2_IrL3 --feff2 output/feff/Ir_IrL3 --s02 0.8   # 混合相（Ir–O + Ir–Ir）：Rmax 缺省 3.0
```

### 3.2 图形界面

**EXAFS 拟合 › 快速拟合**：① 选样品（可多选）与 FEFF 文件夹（页内显示第一壳层摘要：吸收–散射元素、数量、距离范围、N_ref、R_ref）；② **用途**（样品 / 标样）、S0²（样品用途必填：点 **选取标样值…** 从标样拟合取，或手填；手改数值则来源变为“手动”）、**Rmax (Å)**、模型名；③ **开始拟合**。结果卡 **4 结果**：窗口、整批判定（联合时）、结果表（点一行看该样品的 |χ(R)| 数据与拟合图及逐项判定）、页内趋势图（联合时；下拉选 N / R (Å) / σ² (Å²)，带 1σ 误差棒）。按钮：

- **保存**：与命令行 `--save` 相同（模型、拟合记录与图、参数文件；联合另写趋势 CSV）；模型已存在时先确认覆盖。
- **去图片导出**（联合拟合才可用）：打开 **图片导出 › 趋势图** 并选中这次拟合；那里可多选导出哪些量（N、R、σ²、ΔE0、边位置）。
- **在精细拟合中继续**：把模型载入 **精细拟合**（路径表、参数表、窗口、模型名），精细拟合里已有内容时先确认覆盖。

标样拟合完成后即进入会话历史，样品用途下的 **选取标样值…** 立即可选，不必先保存（图形界面同时列出本会话与已保存的标样拟合）。

### 3.3 精细拟合

精细拟合 = 原来的拟合页（路径表 + 参数表，设置见《图形界面使用指南》第 11 节），路径表的列序为 use、label、N、deltar、sigma2、e0、s02、third、note、reff、degen、nleg、amp_ratio、dir（旧版保存的草稿 / 会话里的路径表打开时自动按新顺序排列）。命令行形式是 `xafsmith fit`（见下一节的模型写法）。模型 JSON 的 `s02_source`、`quickfit` 键只做记录，不影响计算（数据标准 4）。

## 4. 拟合模型写法

见数据标准第 4 节。模板：项目中的 `models/_模板.json`。要点：
- 数字 = 自由变化；`{"value": x, "vary": false}` = 固定；字符串或 `{"expr": ...}` = 约束。
- 路径 `"N"` 写数字固定配位数，写参数名让它变化。
- 共线多重散射路径的 σ² 用表达式绑定到单散射路径，并在 notes 中说明；`xafsmith msbind 模型名` 按路径几何给出 ΔR / σ² 绑定建议（规则见《XAFS处理规范》第 5 节第 8 条）。
- 多温度数据：σ² 可写成 `sigma2_debye(tempK, thD1)` / `sigma2_eins(tempK, thE1)`，每个数据集写 `temperature`（数据标准 4.3）；`xafsmith sigma2` 直接算 σ²(T)。
- 键长分散大的低对称结构：先试“单条有效路径 + N 固定”，再和全部 CIF 路径的模型比较；σ² 贴下限 0 说明结构模型内含的分散过大。
- 多数据集同时拟合（如同一体系多个温度共享 ΔR、各自 σ²）：模型里写 `datasets` 列表，见数据标准 4.1，用 `xafsmith fit` 运行。
  所有参数的误差按合计 χ²_ν 统一缩放，一个数据集失配大会放大全部误差（会有警告）；同一数据不要登记两次来“缩小误差”。
  序列样品：`meta.csv` 填 `seq`，`xafsmith trend 联合模型名` 输出趋势表（N、R、σ²、ΔE0 的 1σ 误差与实测边位置）；完整步骤见《多样品联合拟合指南》。
- 软约束（restraint，把参数拉向有独立来源的先验，如标样的 S0² = 0.816 ± 0.05）：模型里写 `restraints`，见数据标准 4.2；约束项乘无约束拟合的 χ²_ν，sigma 按报告误差的尺度填；|偏离| > 2σ 会有警告，软约束不同的模型不做 F 检验。

## 5. 判读规则（必须遵守）

1. 拟合前看 N_idp；变量数 ≤ N_idp/2，最好 ≤ N_idp − 3。
2. |ΔE0| > 10 eV、σ² < 0、S0² 超出 0.6–1.1 → 命令会警告，需检查模型或 E0，不能直接报告。
3. 加壳层必须 `ftest`；p ≥ 0.05 的路径不能说“观察到”。
4. R 空间峰位未相移校正，比真实键长短约 0.3–0.5 Å。
5. 荧光与透射的白线/振幅不能直接比较（自吸收、厚度效应）；跨模式只比较比值与谱形。
6. **校准**：每条谱与同批次单质参比一起处理，同一参比下所有谱加同一个 ΔE；不逐谱校准；不同批次不共用参比。
   没有同步参比通道时，参比与样品测量时间差（calib.json 中记录）可能带来 ~0.x eV 漂移。
7. ΔE0 与 ΔR、N 与 σ² 强相关：报告趋势时做约束检验（例如固定 ΔE0 后键长是否仍变化）。
8. 结论分 实测 / 拟合 / 推测；不编造数据、误差或文献值。

## 6. 个别样品改参数、去毛刺

## 7. 图形界面

`xafsmith gui`：PySide6 原生桌面窗口（代码在 `src/xafsmith/qt/`）。侧栏按流程分组：
项目、数据登记、校准与处理（处理参数 + 批量运行）→ 载入谱（直接读文件时**必须同时选参比**）、质量检查（含去毛刺）、能量校准、
归一化（可导出 .prj）、χ(k) 与 FT、小波变换（可导出数据）→ FEFF 路径、EXAFS 拟合（快速拟合：第一壳层 + 判定 + 趋势；精细拟合：路径表 / 参数表 vary/expr、拟合质量检查、诊断、稳健性检查）、
拟合历史（F 检验）、LCF、XANES 定量 → 报告导出、图片导出（含 Origin 工程）、方法导出 → 制样指导、吸收边查询、AI 助手、使用指南（独立窗口，含 XAFS 基础讲义）。侧栏“流程与本项目”悬停显示流程进度。
界面文字中英文成对写在代码里（`T("中文", "English")`）；新增界面文字时两种语言都要写。
按 meta.csv 载入的样品与命令行处理结果完全相同；拟合保存后模型写入 `models/`。
图形界面自动测试：`python tests/test_qt.py`（默认用公开数据的演示项目 `tests/data/demo_project`；`--project <项目目录>` 测自己的项目；无窗口运行，逐页构建并执行主要操作，中英文各一遍；`--quick` 跳过 FEFF8L 与稳健性检查）。单元测试与数值基准：`python -m pytest tests/unit tests/benchmark`。软件结构见仓库的 `ARCHITECTURE.md`。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| `meta.csv 未指定参比 ref_file，不能校准` | 批次缺参比：放入同批参比后 `init`，或手动填 `ref_file` |
| `meta.csv 中没有可用的样品 X` | 样品名不一致（`xafsmith list`） |
| 合并时扫描被剔除 | 见 `process_summary.csv` 的 `scans_rejected`（RMS 异常或能量范围不完整） |
| FEFF 无路径 / 报错 | 结构是否含吸收原子；RMAX 不宜 > 8 Å |
| 找不到项目 | 在项目目录内运行，或加 `--project`；`xafsmith paths` 查看 |
