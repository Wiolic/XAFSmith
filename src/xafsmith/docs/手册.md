# XAFSmith 操作手册（给人和任何 AI 助手）

> 目录与文件格式见 **数据标准.md**；处理与拟合的科学规范见 **XAFS处理规范.md**。
> 本手册只讲怎么用。不需要读源码，按下面的命令走即可，每一步的输出都列出来了。

## 0. 安装

```
python -m venv .venv
.venv\Scripts\python -m pip install git+https://github.com/Wiolic/XAFSmith.git     # 或本地：pip install -e <XAFSmith 目录>
```

安装后有命令 `xafsmith`（在 venv 中：`.venv\Scripts\xafsmith`）。FEFF6L 随 xraylarch 安装，无需另装。

## 1. 标准流程

```
xafsmith new <项目目录>          # 1. 新建项目（已有项目跳过）
                                 # 2. 原始数据放进 data/raw/<批次>/（每个批次带单质参比）
xafsmith init                    # 3. 登记 → data/meta.csv、xafsmith.json（不覆盖已有修改）
                                 # 4. 检查 meta.csv：sample 合并是否正确、role、ref_file；xafsmith.json 的 elements_in_sample
xafsmith validate                # 5. 按数据标准检查（有“错误”必须先改）
xafsmith qc                      # 6. 质量检查：毛刺、掉束、边跳、自吸收风险、k_snr3
xafsmith kcheck --edge Ta_L3     # 7. 干扰边 → k 上限；与 k_snr3 一起决定 ft.kmax
xafsmith calib                   # 8. 每个参比一个 ΔE
xafsmith process                 # 9. 校准→归一化→合并→χ(k)→FT
xafsmith feff --structure X.cif --absorber Ta --edge L3          # 10. FEFF 路径（加 --code feff8 用 FEFF8L 自洽势，输出目录加 _feff8）
                                 # 11. 写 models/<标样>.json（S0² 自由）→ xafsmith fit <标样> → S0² 写入 xafsmith.json
                                 # 12. 样品拟合：S0² 固定；加壳层用 xafsmith ftest
xafsmith lcf --sample S --standards A B                          # 13. XANES 线性组合
                                 # 14. 记录：notes/YYYY-MM-DD_主题.md（模型、命令、结论、下一步）
```

## 2. 命令速查

| 命令 | 作用 | 输出 |
|---|---|---|
| `new <目录>` | 新建标准项目 | 目录结构与模板 |
| `init` | 登记 data/raw | `data/meta.csv`、`xafsmith.json` |
| `validate [--quick]` | 按数据标准检查 | 屏幕（有错误时退出码 1） |
| `paths` | 显示项目目录 | 屏幕 |
| `list` | 样品汇总 | 屏幕 |
| `qc [--edge E]` | 逐条质量检查 | `output/qc/qc_report.csv` |
| `kcheck --edge E` | 干扰吸收边 → k 上限 | 屏幕 |
| `calib` | 参比一阶导数最大值校准 | `output/calib/calib.json` |
| `process [--edge E] [--nofig]` | 处理全部样品 | `output/processed/`、`output/figs/` |
| `structures [--export]` | 列出结构；导出内置结构为 CIF | `structures/builtin/` |
| `feff --structure F \| --builtin N --absorber X --edge L3 [--rmax 6] [--site i]` | FEFF6L 路径 | `output/feff/<结构>_<X><边>/site<i>/` |
| `fit <模型名或路径> [--nosave]` | EXAFS 拟合 | `output/fits/`、`output/figs/<模型>_fit.png` |
| `ftest <小> <大>` | 嵌套模型 F 检验 | 屏幕 |
| `lcf --sample S --standards A B [--emin --emax --space norm/dmude/chik --free]` | 线性组合拟合 | `output/lcf/`、`output/figs/` |
| `plan --formula F --element X --edge E [--diluent BN --mass-diluent 100]` | 样品设计 | 屏幕 |
| `robust <模型>` | 稳健性检查：kmin ±0.5、kmax ±1、Rmax ±0.2、单一 k 权重 | `output/fits/<模型>_robustness*.csv` |
| `xanes --samples A B [--valence A=2 B=3] [--position E_half]` | 边位置、白线、价态标定 | `output/xanes/` |
| `export-prj --samples A B [--out F.prj]` | 导出 Athena 工程（含本软件的处理参数） | `output/gui/athena/` |
| `methods [--samples A B]` | 方法段落草稿（中英文，只写项目中有记录的事实） | `output/reports/方法段落.md` |
| `update [--check]` | 检查 / 安装 GitHub 新版本 | 屏幕 |
| `gui` | 图形界面（独立桌面窗口） | — |
| `docs` | 文档位置 | 屏幕 |

所有命令都可加 `--project <目录>`。内置结构：Ir、Ta、Co_hcp、Co_fcc、IrO2、CoO、Co3O4、KTaO3。

## 3. 拟合模型写法

见数据标准第 4 节。模板：项目中的 `models/_模板.json`。要点：
- 数字 = 自由变化；`{"value": x, "vary": false}` = 固定；字符串或 `{"expr": ...}` = 约束。
- 路径 `"N"` 写数字固定配位数，写参数名让它变化。
- 共线多重散射路径的 σ² 用表达式绑定到单散射路径，并在 notes 中说明。
- 键长分散大的低对称结构：先试“单条有效路径 + N 固定”，再和全部 CIF 路径的模型比较；σ² 贴下限 0 说明结构模型内含的分散过大。

## 4. 判读规则（必须遵守）

1. 拟合前看 N_idp；变量数 ≤ N_idp/2，最好 ≤ N_idp − 3。
2. |ΔE0| > 10 eV、σ² < 0、S0² 超出 0.6–1.1 → 命令会警告，需检查模型或 E0，不能直接报告。
3. 加壳层必须 `ftest`；p ≥ 0.05 的路径不能说“观察到”。
4. R 空间峰位未相移校正，比真实键长短约 0.3–0.5 Å。
5. 荧光与透射的白线/振幅不能直接比较（自吸收、厚度效应）；跨模式只比较比值与谱形。
6. **校准**：每条谱与同批次单质参比一起处理，同一参比下所有谱加同一个 ΔE；不逐谱校准；不同批次不共用参比。
   没有同步参比通道时，参比与样品测量时间差（calib.json 中记录）可能带来 ~0.x eV 漂移。
7. ΔE0 与 ΔR、N 与 σ² 强相关：报告趋势时做约束检验（例如固定 ΔE0 后键长是否仍变化）。
8. 结论分 实测 / 拟合 / 推测；不编造数据、误差或文献值。

## 5. 个别样品改参数、去毛刺

```json
"overrides":        {"样品名": {"norm": {"pre1": -70}, "ft": {"kmax": 10.5}}},
"overrides_reason": {"样品名": "Ta L2 边位于 Ir L3 边前 −79 eV"},
"deglitch":         {"样品名": [[11355.5, 11368.5]]},
"deglitch_reason":  {"样品名": "11357 eV 单色器毛刺（多个样品同一能量，I0 凹陷）"}
```

先看 `qc_report.csv` 的 `glitch_E` 和原始 I0，确认是仪器问题再删；比较删前删后的拟合。

## 6. 图形界面

`xafsmith gui`：项目 → 数据导入（**必须同时选参比**）→ 质量检查 → 能量校准 → 归一化（Athena，可导出 .prj）→ χ(k)/FT → 小波 →
FEFF（structures/ 文件夹、内置结构或上传）→ EXAFS 拟合（Artemis，参数表 vary/expr，稳健性检查）→ 拟合历史/F 检验 → LCF →
样品设计 → 汇总报告（含方法段落）→ XANES 定量 → 期刊出图。侧栏可切换英文界面（i18n.py：中文界面文字 → 英文对照表；
新增界面文字时请在 `i18n.EN` 中补充英文）。
按 meta.csv 载入的样品与命令行处理结果完全相同；拟合保存后模型写入 `models/`。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| `meta.csv 未指定参比 ref_file，不能校准` | 批次缺参比：放入同批参比后 `init`，或手动填 `ref_file` |
| `meta.csv 中没有可用的样品 X` | 样品名不一致（`xafsmith list`） |
| 合并时扫描被剔除 | 见 `process_summary.csv` 的 `scans_rejected`（RMS 异常或能量范围不完整） |
| FEFF 无路径 / 报错 | 结构是否含吸收原子；RMAX 不宜 > 8 Å |
| 找不到项目 | 在项目目录内运行，或加 `--project`；`xafsmith paths` 查看 |
