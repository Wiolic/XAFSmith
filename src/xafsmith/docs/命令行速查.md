# 命令行速查（会用命令行 / 批处理 / macOS 与 Linux）

> 使用图形界面的用户不需要本页，请看 [快速上手](../../../QUICKSTART.md) 与 [图形界面使用指南](图形界面使用指南.md)。
> 命令行与图形界面读写同一个项目文件夹，两者可以混用。

## 1. 安装

**Windows 安装包**：命令行程序是安装目录里的 `xafsmith-cli.exe`（默认 `%LOCALAPPDATA%\Programs\XAFSmith\xafsmith-cli.exe`），用法与下文的 `xafsmith` 完全相同；可把安装目录加入 PATH，或在“AI 助手”页写入说明文件（其中会写明这个完整路径）。

**从源码安装**（Python 3.11 / 3.12；macOS、Linux 只能用这种方式）。Windows：

```
python -m venv .venv
.venv\Scripts\python -m pip install git+https://github.com/Wiolic/XAFSmith.git
.venv\Scripts\xafsmith --help
```

macOS / Linux：把 `.venv\Scripts\` 换成 `.venv/bin/`。下文 `xafsmith` 指这个环境中的命令（或先激活环境）。
FEFF6L 与 FEFF8L 随 xraylarch 一起安装，不需要另装。开发安装：`git clone` 后 `pip install -e .`。

## 2. 新建项目

```
xafsmith new D:\XAFS\my_project
cd D:\XAFS\my_project
```

生成 `xafsmith.json`、`project.md`、`AGENTS.md`、`data/`、`structures/`、`models/`（含模板）、`notes/`、`output/`，
以及双击打开图形界面的 `打开图形界面.bat`。在项目目录里运行命令时不必写 `--project`。

## 3. 放入原始数据

每次测量一个文件夹，**带上该批次的单质参比**（文件名含 `foil` / `powder` / `metal`）：

```
data/raw/2026-11-05_Ta/
    Ta_foil          ← 参比
    KTaO3            ← 标样
    sample_A  sample_A_2  ...
```

## 4. 登记、检查、校准、处理

```
xafsmith init                 # → data/meta.csv、xafsmith.json
xafsmith validate             # 按数据标准检查
xafsmith qc                   # → output/qc/
xafsmith kcheck --edge Ta_L3  # 干扰吸收边 → k 上限
xafsmith calib                # → output/calib/calib.json
xafsmith process              # → output/processed/、output/figs/
```

`data/meta.csv`：同名 `sample` 合并；`role` 为 reference / standard / sample；`ref_file` 为空的谱不能处理。
`xafsmith.json`：填 `elements_in_sample`；去毛刺写 `deglitch` 与 `deglitch_reason`（见 [数据标准](数据标准.md)）。

## 5. FEFF 与拟合

```
xafsmith feff --structure KTaO3.cif --absorber Ta --edge L3                     # FEFF6L；或 --builtin KTaO3
xafsmith feff --builtin KTaO3 --absorber Ta --edge L3 --code feff8 --scf 4.5   # FEFF8L 自洽势，输出目录加 _feff8
```

复制 `models/_模板.json` 为 `models/KTaO3_1shell.json`，改 `sample` 与路径文件，然后：

```
xafsmith fit KTaO3_1shell                 # → output/fits/、output/figs/
xafsmith ftest 小模型 大模型              # Hamilton F 检验，p < 0.05 才显著
xafsmith robust KTaO3_1shell              # 稳健性检查
```

模型写法：参数写数字 = 自由；`{"value": 0.68, "vary": false}` = 固定；字符串 `"dr1"`、`"ss1*1.5"` = 约束；
路径 `"N": "6"` 固定配位数，`"N": "n1"` 浮动。变量数 ≤ N_idp/2。

## 6. 其他命令

```
xafsmith lcf --sample S --standards A B          # 线性组合拟合
xafsmith xanes --samples A B --valence A=2 B=3   # 边位置 / 白线 / 价态估算
xafsmith plan ...                                # 制样指导（μt、边跳、压片质量）
xafsmith diagnose 模型名                          # 拟合诊断：残差/噪声、毛刺定位、分段失配、建议
xafsmith figure --kind chir --samples A B --size double   # 期刊图：xanes/deriv/chik/chir/fit → output/figs/journal/
xafsmith figure --kind fit --model 模型名 --size double    # 拟合图（k + R 空间）
xafsmith summary                                 # 汇总报告（Excel + HTML）→ output/reports/
xafsmith si --fits "样品|模型" --lang en          # SI 拟合方法文本 + 参数表（--list 列出可选拟合）
xafsmith export-prj --samples A B                # 导出 Athena 工程
xafsmith methods                                 # “实验方法”段落草稿
xafsmith agent [--write]                         # 接入 AI 助手：显示命令路径；--write 写入 AGENTS.md、CLAUDE.md
xafsmith gui | docs | cite | paths | formats | inspect <文件> | list | update [--check]
```

`xafsmith <命令> --help` 查看每个命令的参数。

## 7. 交给 AI 助手

在项目目录里让 AI 先读 `AGENTS.md`，再运行 `xafsmith docs` 找到 [手册](手册.md) 与 [数据标准](数据标准.md)。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| `未指定参比 ref_file，不能校准` | 放入同批参比后 `xafsmith init`，或在 meta.csv 手填 `ref_file` |
| `meta.csv 中没有可用的样品 X` | 样品名不一致（`xafsmith list`） |
| 结果写到了别处 | `xafsmith paths` 查看；在项目目录内运行或加 `--project` |
| FEFF 无路径 | 结构是否含吸收原子；RMAX 不宜 > 8 Å |
