# 通用 XAFS 数据处理与拟合工具

> 用途：放在项目根目录，作为 CLAUDE.md 使用。适用于任何体系、任何吸收边、透射或荧光数据（同步辐射 XAFS：XANES + EXAFS）。
> 具体体系的信息（样品、边、结构模型、已有结论）不写在本文件里，写在项目的 `project.md`。
> 工具的目录与文件约定以 **数据标准.md** 为准（本文第 3 节为早期版本的示意）。

---

## 1. 目标

1. 提供一套**可复现、可比较、可追溯**的 XAFS 处理与拟合流程：原始数据 → 校准 → 归一化 → χ(k) → FT → 拟合 / LCF → 结果表与图。
2. 帮用户在测试前做样品设计（μt、边跳、叠层、干扰边检查），在测试后做质量评估和分析。
3. 所有结论分清"实测 / 拟合 / 推测"，不夸大数据能支持的内容。

## 2. 工具模块（由 Claude 在 `scripts/` 中实现，每个模块独立、可单独运行）

| 模块 | 功能 |
|---|---|
| `io` | 读入束线文件（BSRF、SSRF、Athena .prj、通用列文本），统一成内部格式；记录列定义与模式（透射 / 荧光 / 电子产额） |
| `qc` | 数据质量检查：噪声、毛刺、能量漂移、总 μt 与边跳、谐波、多次扫描一致性、荧光自吸收风险；输出 `qc_report.csv` |
| `calib` | 用参比箔做能量校准（一阶导数最大值），记录每条谱的 ΔE |
| `normalize` | 合并扫描、边前/边后拟合、归一化、E₀ 定义 |
| `autobk` | 背景扣除（rbkg、k 权重、spline 参数可设），得到 χ(k) |
| `ft` | k 空间窗函数（Hanning/Kaiser）、傅里叶变换、反变换；输出 |χ(R)|、Re/Im；画图时标注"未相移校正" |
| `wavelet` | 小波变换（Morlet/Cauchy），用于区分轻/重散射体、重叠壳层 |
| `feff_wrap` | 由 CIF 或手写结构生成 FEFF 输入（可调吸收边、RMAX），运行 FEFF6/8，读入 feffNNNN.dat |
| `fit_exafs` | EXAFS 拟合：路径、参数绑定、约束、多 k 权重同时拟合、R 空间或 k 空间；输出参数、误差、R 因子、χ²_ν |
| `fit_lcf` | XANES / EXAFS 线性组合拟合：端点、权重约束、误差、与单一标样比较 |
| `mut_planner` | 样品设计：由成分、面密度、基体算总 μt 与边跳，推荐叠层数或压片质量；检查邻近吸收边干扰 |
| `report` | 汇总结果表、图、方法说明；图注自动写明数据来源与处理参数 |

规则：模块之间只通过文件（CSV / npy / json）交换结果；脚本头部写用途与参数；每次运行把参数写入同目录的 `*.params.json`。

## 4. 数据处理规范

1. **原始数据只读**，任何处理都从 `data/raw/` 重新生成。
2. **能量校准**：每个吸收边同时测对应参比箔，以其一阶导数最大值校准，写明参比箔与标准能量（来源：xraydb 或 Bearden/Thompson 表）。
3. **扫描合并**：先逐条检查再平均，记录剔除的扫描及理由；不同样品的扫描次数要在 `meta.csv` 中列出。
4. **归一化**：边前、边后拟合范围用同一套参数；边跳记录入表；换样品不换定义。
5. **E₀**：全项目统一一种定义（一阶导数最大值或半高点）。
6. **背景扣除**：rbkg、kmin、k 权重在样品之间保持一致；调参要有理由并记录。
7. **FT**：先定义 k 范围（按信噪比，高 k 噪声大就截断），窗函数 dk；k¹ / k² / k³ 都要看。
8. **k 与分辨率**：k = √(0.2625(E − E₀))；ΔR = π/(2Δk)；独立点数 N_idp = 2ΔkΔR/π。拟合前先算 N_idp。
9. **邻近吸收边**：用 xraydb 列出目标边之后在扫描范围内出现的所有吸收边（同一元素的 L₂/L₁，共存的其他元素），换算成 k，确定可用的 k 上限。没有这个检查不得选 k 范围。
10. **模式差异**：透射 μ = ln(I₀/I₁)；荧光 μ = If/I₀。荧光要评估自吸收（总 μt 是否远小于 0.2），必要时做校正（如 FLUO / Booth），并用透射标样做桥接比较。

### 样品设计（透射）

- 目标：总 μt 约 1.5–2.6（1–3 可接受），边跳 Δμt ≥ 约 0.2。
- 总 μt = Σ（各元素质量面密度 × 该能量下质量吸收系数）；边跳只取目标元素跨过吸收边的变化。
- 样品之间不必精确匹配 Δμt，因为归一化会消除它；真正重要的是线性区间（总 μt 合适）、均匀无针孔、测量与处理参数一致。边跳只影响噪声。
- 不均匀（针孔、厚度起伏）会压低白线和 EXAFS 振幅，要在测前检查。

## 5. 拟合规范

1. **先写清模型**：路径、配位数固定还是浮动、σ² 如何绑定、ΔE₀ 共用还是分开，记录在 `notes/`。
2. **参数数量**：不得多于独立点数的一半，最好 ≤ N_idp − 3。
3. **加壳层要做显著性检验**：比较 R 因子、χ²_ν 和 F 检验；不显著的路径不能报告为"观察到"。
4. **S₀²**：先在结构已知的标样上拟合确定，样品中固定或限定范围。
5. **ΔE₀**：超过 ±10 eV 要怀疑 E₀ 定义或模型；ΔE₀ 与 ΔR 相关，键长结论要谨慎。
6. **同时看 |χ(R)| 与 Re χ(R)**，必要时多 k 权重同时拟合。
7. **误差**：由协方差矩阵得到，并乘 χ²_ν 修正；用多次扫描的差异作独立估计。
8. **多重散射**：线性 M–O–M 等路径与单散射壳层共线时，σ² 应绑定；说明绑定方式。
9. **轻散射体**（如 K、O 外壳层）信号弱，在重元素壳层旁边很难独立确定，需要小波、不同 k 权重或其他表征（XPS、XRF 成分）的独立约束。
10. **XANES 分析**：LCF 的端点必须是实测标样；使用非实测端点（如模拟谱）要明确标注为假设；报告 R 因子与权重误差，并与"只用单一标样"的拟合比较。
11. 输出 CSV：样品、路径、N、R、σ²、ΔE₀、S₀²、R 因子、χ²_ν、N_idp、参数个数，一行一个拟合。

## 6. 报告与作图

- 每张图注明：样品、边、模式、扫描次数、处理参数（E₀、rbkg、k 范围、窗函数、k 权重）。
- R 空间图标注"未相移校正"，拟合图同时给 |χ(R)| 与 Re χ(R)，并标出拟合窗口。
- 区分三种陈述：**实测**（数据直接可见）、**拟合结果**（依赖模型）、**推测**（需进一步实验）。
- 模拟或预期的图必须标注"SIMULATED — illustrative expected outcome, not measured data"，并在图注写明假设。
- 汇报用图：16:9，分辨率 ≥ 2666×1500；论文用图按期刊要求另出。

## 7. 通用经验（来自实际数据分析的教训）

1. **一个峰不等于一个壳层**：R 空间的单个小峰可能来自噪声、背景扣除残余、窗函数旁瓣或多重散射。声称某壳层存在，必须配合拟合、显著性检验和独立证据。
2. **FT 峰位 ≠ 真实键长**：没有相移校正的峰位比真实距离短约 0.3–0.5 Å；校正量与散射体有关。
3. **分辨率只由 Δk 决定**，不随壳层数变化；真正的困难是相近距离的不同散射体叠在一起（如金属–金属与金属–轻元素）。
4. **荧光与透射数据不能直接并列比较**：自吸收会压低白线和振幅（实测中白线可低约 25%）；用桥接标样在两种模式下都测一遍。
5. **首次扫描、毛刺、能量漂移**常常使个别扫描异常，平均前必须检查。
6. **标样的结构质量要先确认**：纳米晶或部分无序的标样不会表现出理想晶体的 σ²；"标样"拟合差不一定是模型错，也可能是标样本身。
7. **重构、无定形化等定性结论**应同时用多个指标支撑：近边形状、第一壳层 CN 与 σ²、外壳层整体强度的变化趋势，而不是只看某一个峰的消失。
8. **模拟图只是预期**：起点、无序度、时间常数等假设值要写清楚，不要让别人以为是数据。
9. 样品设计里，**总 μt 和均匀性**比 Δμt 是否精确匹配更重要。

## 8. 给 Claude 的工作规则

1. 新项目先读 `project.md` 和 `data/meta.csv`；缺失就引导用户补全，不要猜。
2. 开始分析前先说明"这份数据能回答什么、不能回答什么"（质量评估在前，分析在后）。
3. 不确定的归属要写明依据和局限，不能直接当作结论。
4. 发现自己之前说错，要明确指出并更正，并说明对已有结论的影响。
5. 不编造数据、误差或文献值；用到的理论值（边能量、吸收系数、散射振幅）要注明来源（xraydb、FEFF 版本）。
6. 每次分析结束：保存脚本与参数、更新 `notes/`，给出 1–2 句结论和一个下一步。
7. 批量操作前先确认文件列表；不修改原始文件。
8. 与 Athena/Artemis 的结果对照时，以 Larch 结果为主，两者不一致要说明原因。

## 9. 环境

- 推荐 conda 新建环境（Python 3.11–3.13）：`pip install xraylarch lmfit numpy scipy matplotlib pandas xraydb`。
- FEFF：xraylarch 自带 `feff6l`（`larch/bin/<平台>/`），也可用 FEFF8L。
- 已知问题：在 Linux 云容器里 `pip install xraylarch` 可能因 `bibtexparser` 编译失败而装不全；此时可只取其中的 `feff6l` 可执行文件，并用 numpy/scipy 自行实现 FT 与拟合（FEFF 路径文件的列：k、real[2φ_c]、|f_eff|、φ_eff、red factor、λ、Re[p]；相位 = real[2φ_c] + φ_eff，振幅 = |f_eff| × red factor）。
- 在用户本机应优先尝试完整安装。

## 10. 启动清单（首次使用）

1. 建环境，确认 `feff6l` 和 larch（或备用实现）可用；
2. 让用户填写 `project.md`；
3. 将原始数据放进 `data/raw/`，生成 `meta.csv` 并运行 `qc`；
4. 用一个结构已知的标样跑通全流程（校准 → 归一化 → χ(k) → FT → FEFF 拟合），确定 S₀²，并与 Athena/Artemis 结果对照；
5. 再处理未知样品，按第 4–6 节的统一参数批量运行。
