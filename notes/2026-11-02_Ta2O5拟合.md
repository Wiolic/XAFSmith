# 2026-11-02 Ta2O5 标样 EXAFS 拟合（Ta L3，透射）

结构：用户提供 `Ta2O5.cif`（pymatgen 生成，P1 写法；对称性分析为 C2/c，单一 Ta 位点，多重度 8），
副本存于 `feff/Ta2O5_TaL3/Ta2O5.cif`。FEFF6L（larch 自带），RMAX 5 Å。

## 1. 数据（实测）
- 文件 data/raw/Ta/Ta2O5，1 次扫描，2026/5/1 23:40，与 Ta powder 参比相差 0.06 h
- 校准 ΔE = −0.72 eV（Ta powder，同边统一值）；E0 = 9884.24 eV；边跳 Δμt = 0.44
- QC：2 个毛刺 9937.5/9939.9 eV（k≈3.7，影响小）；k_snr3 = 14.45；扫描范围内无干扰边
- χ(k) 在 k > 9 Å⁻¹ 后振幅很小 → 无序度大
- FT（k² ，3–12）：第一壳层峰 1.47 Å，第二区域 2.76 / 3.10 Å（未相移校正）

## 2. CIF 中 Ta 的近邻

Ta–Ta ×8：3.342, 3.560, 3.661×2, 3.712×2, 3.765×2 Å；其间夹有 Ta–O 外层（3.44–3.65）与多重散射。

- Ta–O：N = 6（固定），R = 1.921 ± 0.013 Å，σ² = 0.0086 ± 0.0008 Å²，ΔE0 = 1.9 ± 1.6 eV，R 因子 0.011
- N 浮动时 N = 6.2 ± 0.9，与 6 一致（F 检验 p = 0.82，浮动 N 不显著改善）
- 对照 KTaO3（同参数）：R = 1.953 Å，σ² = 0.0056 Å²

## 4. 判断
- （拟合）第一壳层 6 个 O，平均 Ta–O 1.92 Å，σ² 明显大于 KTaO3（键长分布宽）。
- （拟合）用 CIF 的六个不同键长建模时 σ² 降到 0：CIF 内含的键长分散（0.31 Å）大于数据所示，
  说明这份 CIF 的第一壳层几何与实际样品不完全一致。
- （推测）有效单壳层模型对不对称的键长分布会给出偏短的 R，因此 1.92 Å 与 CIF 平均 2.00 Å 的差别
  不能直接解读为键长缩短。
- （实测 + 拟合）2.7–3.2 Å（未校正）区域有明显信号，但三种 Ta–Ta 模型的 F 检验均不显著（p ≥ 0.07），
  不能报告为"观察到 Ta–Ta"。可能原因（推测）：实际 Ta2O5 试剂的物相/无序度与该 C2/c 结构不同
  （商用 Ta2O5 常为正交 L/β 相，结构高度无序），第二壳层是多种 Ta–Ta / Ta–O / 多重散射的叠加。
- 代码修正：`fit_exafs.build_paths` 中同名 label 的路径会被 larch 互相覆盖，已改为自动加文件号。
  之前的标样模型 label 均不重复，S0² 结论不受影响（IrO2 回归：S0² 0.80，ΔE0 9.2，不变）。
